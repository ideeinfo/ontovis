# 模型批量核验与中断恢复切片

2026-10-25，Q-09 的本机命令行切片。现有 20 型 40 份 GLB 是直接使用者；逐份调用原 `model_probe.py`，补充批次进度、取消、失败隔离和中断恢复。本切片不增加产品页面、HTTP 服务、数据库、模型上传格式或工程写入。

## 1. 输入与预算

`tools/model_probe_batch.py start --manifest <JSON> --output <新目录>` 接受如下清单：

```json
{
  "schemaVersion": 1,
  "models": [
    {
      "id": "fixture-model-full",
      "source": "models/source.glb",
      "sha256": "由独立清单提供的64位小写SHA256"
    }
  ]
}
```

字段固定，不接受额外处理参数。`source` 为本机绝对路径或相对原清单目录的路径；不解析 URI、不下载资源。`id` 是最多 64 字符的 ASCII 字母、数字、下划线或短横线，首字符须为字母或数字；同批 id 和路径不能重复。它只标识核验项，不作为构件或工程身份。

清单至多 256 KiB，1—100 份文件；单文件沿用原核验工具的 200 MiB 本机读取预算，同批源文件至多 1 GiB。单个报告或属性目录至多 64 MiB才可收录为完成结果。串行运行一个工作子进程，`--timeout-seconds` 默认 120 秒，可设 1—600 秒。以上均为离线工具预算，不修改产品上传上限，也不代表生产 CPU、内存或多进程能力。

只接受普通文件，拒绝符号链接、父目录链接及硬链接。启动前核对每份源文件的声明 SHA；新目录拒绝覆盖。解析后的绝对路径、SHA、字节数和超时预算冻结为 `plan.json`，其实际 SHA 及两份处理器源码 SHA 写入 `checkpoint.json`。批次目录为 0700，文件为 0600；内部工作输出仍含来源属性，应保持私有。首次初始化若不完整，保留该目录，改用新目录启动。

批处理本批只接受源 GLB。原有派生映射、控制点和前版身份候选继续使用[单文件工具](模型属性与源身份核验切片.md)，不引入新的任务参数平台。

## 2. 进度、取消与失败

控制台逐行输出 JSON 进度，只含当前 id、状态、计数和 `releaseEligible:false`；完整属性写入私有报告，不打印到控制台。检查点原子替换，先 fsync 文件、再替换并 fsync 所在目录。保存失败时不把内存中的成功结果当作已提交结果。

每项状态为 `pending/running/passed/failed`，每次尝试单独存入 `items/<序号>/attempt-<次数>/`。技术失败保留报告并记 `failed`，继续下一份；工作者崩溃或超时留下半份 JSON 时也记录当前项失败、保留原字节并继续。失败项不会因 resume 自动重复运行，需要明确选择源清单并用新目录另开一批。

取消方式为 `cancel --output <批次目录>`，或给运行主进程发送 SIGINT/SIGTERM。取消请求单独写入目录；运行者终止并回收工作子进程，保留半份输出，把当前项退回 pending、尝试标记 cancelled，再保存批次 cancelled。完成后的 cancel 为无操作。显式 resume 会清除上次取消标记；恢复期间新收到的取消仍生效。

工作子进程同时监控时间上限及主进程保持打开的管道；主进程被 SIGKILL 后，管道 EOF 会使工作者退出。批次文件锁由工作者继承，防止旧工作者尚未退出时另一进程接管。使用 POSIX 文件锁，仅在当前 macOS/Linux 本机工作流运行，不是生产多机调度。

## 3. 恢复与结果复用

`resume --output <批次目录>` 先核对冻结计划、两份处理器源码、所有源文件和已完成报告/属性目录的实际字节 SHA。任一不一致即拒绝复用，不修改旧检查点、修补源输入或静默替换报告。

已完成项按原路径复用，原报告和 mtime 保持。检查点中遗留的 running 尝试改记 interrupted，保留其全部旧文件，再用新尝试目录重跑该项；即使旧目录恰好已有完整报告，也不将它提升为完成。强制终止或报告落盘后检查点保存失败均遵循同一规则。若新尝试目录已有非预期文件则拒绝覆盖。

批次结束状态为 passed、failed 或 cancelled。退出码分别为 0、1、130；输入/检查点错误或批次被占用返回 1，控制台保留具体错误码。硬终止沿用系统信号退出，不伪造取消检查点。检查点是该批汇总报告，各项原报告与目录继续按已有 schema 导出。

## 4. 验收与剩余范围

验收覆盖真实进程取消、SIGTERM、SIGKILL、超时、占用拒绝、半份报告、报告先落盘后检查点失败、输入在处理中变化、输出/计划/处理器变更、链接和预算拒绝，以及完成项字节与 mtime 不变。另用已有 40 个私有源文件进行整批取消/恢复及逐节点原始属性核对，与前次报告按内容比较，时间戳单列。

成功仅表示原工具范围内的本机技术核验通过，`releaseEligible` 和原报告的 `releaseReadiness.eligible/G2Passed` 始终为 false。已有源身份缺口、属性来源权威、几何对应、工程 UID、物理关系与绑定迁移均不由本批确认。
