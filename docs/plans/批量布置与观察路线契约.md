# Q-07 批量布置与观察路线契约

2026-10-23。承接Q-06受限单机测试部署及原MagicPath场景三栏工作区。本批增加场景编辑和镜头编排；不改变OntoBase对象、安装身份、物理关系或精度事实。Q-07仍进行中，生产实现和验收分批留证。

## 1. 页面状态与操作

- 原内容列表增加实例复选框；Shift点选支持增减，普通点选及命名组选中整个组。选择和吸附偏好只在本次编辑会话保留，不改变共享修订。
- 右栏沿用原三栏，在属性旁增加“批量布置”“视点与路线”；窄屏沿用抽屉并提供关闭按钮。保留原导航、原Logo、深浅灰绿、13px正文/11px说明和中英文。
- 编组为单层、互不重叠的场景实例集合，至少2个成员；先解组再重新编组。组内设备关联仍各自独立。移除实例时同步移出组，不足2个成员的组解散；保留引用该实例的视点为失效状态供修复。
- 平面批移输入ΔX/ΔZ及各实例朝向增量。平移在当前显示坐标系X/Z平面进行；朝向只改变每个实例自身朝向，不绕组中心旋转。贴地实例全部重新采样当前固定网格；绝对高程和局部相对高度保留。一个锁定、无权、失效、越界、缺测或过时响应使整批不提交，显示对应成员/原因；成功为一次撤销/重做。
- 连续放置选定同一固定模型版本后逐点添加；Esc/取消/退出布置结束。每次成功位置独立进入撤销记录；每个新实例使用新ID、无设备/构件关联。失败不添加，不消耗“成功一次”的记录；资源/地形/权限变化按现有校验拒绝。保留现有容量上限。
- 网格候选关闭/1/5/10m，角度关闭/5/15/30/45/90°。新增和单实例移动按位置吸附；批移对位移量吸附以保留成员间偏移；朝向增量按角度吸附。吸附是布置辅助，不是现场精度证明。
- 命名视点保存当前实际镜头eye/target、坐标系修订、视点类别和可选固定模型目标；远眺默认停留3秒，内部构件默认2秒。名称是用户标注，不能由视点创建/确认工程事实。
- 路线由有序视点引用组成；每步分别编辑飞行和停留，支持增删及上下移动。可在浏览模式预览；编辑、保存、换版和新预览在播放期间禁用。暂停冻结飞行/停留；继续沿剩余时间运行；后台不计时；取消/Esc恢复预览前镜头；正常结束停在末视点。手动转动/缩放停止路线并保留接管后的镜头。
- 预览只移动镜头，不替换分析对象、空间宿主或图纸。无几何子设备仍保留自身身份和自身图纸。隐藏模型不因路线永久改显隐，路线不写场景修订。切场景、退出、撤权、资源或坐标系变化时停止并清理计时及镜头控制，丢弃迟到回调。

## 2. 保存白名单

复用现有场景读取/预检/保存接口、项目权限、expectedSceneRevision、资源固定引用、幂等键、事务和审计。不给批量动作另开绕过保存的接口。快照增加可选`organization`；旧快照缺失即空集合，读取旧修订不回写或制造新修订，未知字段继续拒绝。

| 字段 | 形状及约束 |
|---|---|
| `organization.groups` | 最多16项；`groupId`为规范UUID，`displayName`为1—80字符；`instanceIds`至少2项、无重复、均在同一快照内；一个实例最多属于一个组 |
| `organization.viewpoints` | 最多32项；`viewpointId`为UUID，`displayName`为1—80字符，`kind`为`component`或`overview`；`view:{eye,target}`为有界有限三维向量且不重合；`frameRevision`为捕获时坐标系修订；`modelTarget`为null或`{sceneModelInstanceId,modelVersionId}`，均为规范UUID |
| `organization.routes` | 最多8项；`routeId`为UUID，`displayName`为1—80字符；`steps`最多32项，可为空草稿；每项`stepId`为本路线唯一UUID、`viewpointId`必须存在、`flightSeconds`为0.2—30、`dwellSeconds`为0—300的有限数值 |

各集合ID唯一，名称允许用户同名，以ID区分。字段严格白名单；bool不作为数字；现有1MiB快照预算仍适用。可保存失效模型目标或旧frameRevision以保留可修复草稿，但播放前必须逐项检查：frameRevision与当前一致；目标实例存在且modelVersionId一致；资源与本人场景读取仍有效。构件视点必须有模型目标；失效视点显示“需重存”，禁止直接跳转和路线播放，不能静默使用新的几何。

删除被路线引用的视点须先移出路线。重存视点沿用原ID并替换实际镜头/坐标修订/目标，保留引用和用户编辑的停留时间；新添步骤才按视点类别填默认值。锚定/地形换版沿用原几何服务，只保留组织元数据；旧视点因frameRevision变化失效，不自动推断其工程含义或精度。

`modelTarget`仅用于失效检测与用户定位提示，不是设备绑定、工程授权或读取原文的凭据。服务不会依赖前端名称/分组声明工程事实。所有新增元数据随原场景版本条件与后端授权保存，写入失败整份快照不变。

## 3. 分批实现与验证

1. 同一MagicPath原工作台追加可评审交互，保留完整字体/品牌及其他画面。原型仍为合成SVG和本页内存保存；不等于真实Three镜头、后端权限或持久化验收。
2. 后端白名单与往返、前端类型/纯状态实现先落地；验证旧快照不变、超限/无效字段/伪造引用、事务/权限/冲突、元数据在GIS与换版路径保留。
3. 正式工作台接入多选/组/批移/连续放置/吸附；验证不同实例身份、锁定与缺测整批失败、地理坐标采样、一次撤销和迟到响应。
4. 接入实际镜头捕获、命名视点和路线控制；验证飞行/停留默认值、暂停/继续/取消、手动接管、后台恢复、版本失效、卸载清理、原三柜/子设备/图纸回归。
5. 适用检查通过后再生成测试候选；部署前重核当前运行状态，按B0/B1保全、新目录恢复规则处理。Q-06上线版本在Q-07候选验收前保持可追溯；本机参考Demo不进入包。

设计修订、测试数量和实际产物见[执行记录](开发执行记录.md)及[统一任务队列](统一任务队列.md)。视频缺成片仍单列Q-29；设备停用退役Q-28继续暂缓。
