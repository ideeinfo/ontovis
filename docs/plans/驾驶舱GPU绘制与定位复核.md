# 驾驶舱GPU绘制与定位复核

2026-11-03，用户授权执行下一阶段。承接d4e7bb9已发布版本，前一批4K隔离短样本p95约35ms、目标约33.4ms未达到；定位API约3.7秒但源端现已更新，需重新测量。

## 本批范围

1. 在隔离副本中使用异步GPU时间查询；扩展不支持或发生disjoint时明确缺测，不使用CPU提交时间冒充GPU耗时。分别测绘制规模、透明材质与抗锯齿成本。诊断开关与采样只存在output本地构建。
2. 按实测选取保留模型、透明度、光照、颜色、图像比例及DPR的最小修复。预计涉及SceneViewport、sceneRenderer及回归。若尝试抗锯齿方案，须核对细线、边缘、贴花文字、源色影像与双主题，不以缩小分辨率或隐藏构件达到数字目标。
3. 按源端当前生效版本复核报警定位与完整页面就绪。源端a7b19ad已含初始密码哈希比较复用，先验收，不重复修改旧本机主工作区；新发现的源端变更只读审阅后再继续部署。

## 实施决定

- 本批生产改动仅为SceneEngineeringValidator场景打开的有界并行读取及其回归、缓存契约。最多四条独立证明、原顺序合并、冲突拒绝和保存串行均验证；不减权限或修订复查。8轮候选报警页面就绪中位约2.72秒，接口中位约2.28秒。
- GPU查询已取得有效样本；CPU提交阶段低，4K查询区间与帧间隔仍偏高。关闭抗锯齿仅用于诊断，不采用。SMAA试验有着色器编译与画面丢失，未通过视觉核验，全部留在output诊断构建，正式前端保持d4e7bb9及原画质，不宣称4K流畅度改善。
- 源端外部更新a7b19ad→1433e6→da30712。只读核对新增差异集中于受限图纸识别及预算/结果处理，相关资料、设备与项目权限契约未变；15张工程表和5项模型配置摘要一致。不发布或回退OntoBase。

## 验证边界

- 同一Mac、相同场景/视角/模拟，精确3840×2160与1920×1080对照；短样本、长样本和实体显示器证据区分。
- 行为变化先做定向回归，再完整前端检查；真实项目的往返、选择/隔离/恢复、暂停/恢复、分析与资料预览复核。
- 复用备份前重验正式业务/文件及独立恢复，天气缓存单列；无新工程保存、AI生成或源数据库写入。保留源端他人工作与本机受保护修改。
- 用户沿用自主部署授权。完成候选验收后发布、正常公网登录复核、对账及临时环境清理；未达指标如实登记。
