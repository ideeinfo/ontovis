## 2. 已有设计继续约束的接入顺序

[统一实施方案§5](场景管理与模型实例统一实施方案.md#5-地形文件和坐标处理)已区分高程、独立影像和矢量；[SC-08](场景管理与模型实例统一实施方案.md#后续批次与原开发计划衔接)要求来源/许可/坐标/覆盖与固定版本，延续[WBS17](WBS01-19范围明细.md)的同一地形来源链。无需重做场景管理或地图产品。

首个公开来源已读得实际格式、波段/色彩、CRS/轴序、像元与覆盖、采集时间和来源声明。优先固定近期RGB裁片及SCL，沿用私有文件资源流程；本批不依赖商业瓦片、Key或新增费用。后续若接服务入口，再核对瓦片矩阵、坐标、缓存/署名及访问方式。由文件可以取得的元数据不要求用户手工填写；工程精度用途及新增费用仍按实际业务决定处理。

随后在同一MagicPath项目、原资源页/场景三栏冻结以下增量，再实施服务与渲染：

- 资源分别显示高程、影像、道路和范围类型，保留来源、时间、固定版本及覆盖/缺测状态。影像颜色与地形高程来自各自明确资源。
- 场景图层引用固定资源版本和当前坐标修订；投影、裁切和掩膜使用Q-02固定地形来源链，贴地高度消费既有高度面。NoData与覆盖外准确降级，不建立第二套高度真值。
- 上传、私有内容读取、保存与换版沿用项目授权/资源固定引用、场景版本条件、幂等和审计。工程道路/边界按来源表达，图层不确认设备安装身份或用地事实。
- 验证坐标/覆盖、缺测、透明区、显隐、固定旧修订、换版影响、读者/撤权、资源释放及原模型/三柜/子设备流程。合成反例与真实来源联调分别留证。

首批可执行契约以已读的原生10米RGB/SCL及2021年度后备为输入，继续同一地形来源链；当前已实现的20米概览及公开传输保留项见顶部记录，10米源输入与20米显示网格分列。
