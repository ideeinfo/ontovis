## 页面与范围

资源面板增加“影像”，支持私有8位RGB/RGBA、北向上GeoTIFF。坐标与像元从文件读取；来源、许可、采集日期、署名和质量说明随不可变版本保存。首切支持EPSG:4326及WGS84 UTM，64MiB、4096×4096像素、20版本/1GiB库上限。非兼容文件明确拒绝，不猜波段或生成地物。2021 WorldCover原uint16年度合成保留来源后备，不伪称本首切原生支持。

已定位地形的场景可采用一个影像固定版本、更换、移除或切换显隐。编辑模式将显隐随场景保存；浏览模式仅改变本人显示。影像透明/缺测/覆盖外露出原地形，部分覆盖明确提示；没有交集时拒绝采用。影像只提供颜色，贴地和高程仍消费原固定地形网格，不增设高度面。显示期间保留日期、概览用途和署名。

MagicPath仅为合成交互预演，文件不上传、外观不是实际影像。相同组件10项本机交互与类型检查通过，云端构建及初始列表预览已检查；不将其记为真实服务验收。

## 服务与保存

沿用本人会话、项目读取/管理员写入、Origin/CSRF、no-store、内容SHA和取消/迟到结果边界。所有路径位于现有工作台服务；不增加外部影像代理、浏览器Key或持续外部瓦片依赖。

| 动作 | 固定路径/条件 |
|---|---|
| 上传 | `POST /api/workbench/imagery/upload`，`image/tiff`及base64 `X-Imagery-Metadata`；`expectedSessionRevision`、`clientRequestId`、名称/来源/许可/日期/署名/质量/rightsDeclared。限一个受限处理进程，处理前后及提交边界重验权限。相同请求与字节幂等返回，相同ID不同内容409 |
| 列表 | `POST /api/workbench/imagery`；当前项目最多20项，可按名称搜索，不返回路径 |
| 版本 | `POST /api/workbench/imagery/version`，固定`imageryVersionId`；返回原文件SHA、内容修订、报告SHA、PNG摘要及坐标/覆盖/掩膜报告 |
| 纹理内容 | `POST /api/workbench/imagery/content`，固定版本/内容修订/PNG SHA，返回私有`image/png`及会话/SHA头，每次重验授权 |
| 场景 | 原check/save/open契约增加可选`imagery: {imageryVersionId, expectedContentRevision, expectedReportSha256, visible}`，或null；只适用于已有地形的projected_site。旧快照缺此字段保持原样；新引用写入不可变的历史使用记录 |

影像保存与场景保存分别使用既有权限边界；场景采用/更换经原check/save、场景修订、幂等及审计落库。未保存选择只在当前草稿。旧修订保持旧资源，不追随外部目录或新上传。渲染用地形固定顶点转至影像CRS并按像元角点仿射求UV，轴序始终经度/纬度；不以外包框拉伸替代坐标转换。
