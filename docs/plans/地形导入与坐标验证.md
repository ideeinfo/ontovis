# Q-02地形导入与坐标验证记录

2026-10-22。按[Q-01实施基线](场景页面与服务契约冻结.md)推进[统一任务队列](统一任务队列.md)中的Q-02。本文只记录已经验证的服务端切片；场景编辑、浏览器经纬度往返、首次锚定保存、换地形及性能闭环仍需Q-03—06，不以命令行处理成功替代产品完成。

## 1. 处理范围

[区域坐标](../../apps/api/terrain_coordinates.py)按固定WGS84 UTM投影进行米制换算，锁定分区、半球与50km半径。显示轴为X网格东、Y上、Z网格南，不称严格ENU；朝向以真北顺时针并校正网格方向差。没有垂直格网转换，EGM2008/EGM96正高与WGS84椭球高不能混用；未知基准仅允许明确的相对布置。锚定函数只返回完整变换预览，不写场景。

[地形处理器](../../apps/api/terrain_validation.py)只接收本地普通GeoTIFF原件，首切支持单波段、北向上且无旋转的EPSG:4326或WGS84 UTM；其他CRS/旋转源明确拒绝。检查文件签名、字节/像元/波段预算、横纵坐标、单位/比例与基准冲突、覆盖及缺测；不能通过VRT、URL、侧车文件或GDAL远程驱动读取外部内容。PROJ联网关闭。

源像元中心按四个有效邻点做双线性采样，生成有界投影网格；低分辨率网格不得跨过源缺测区。显示和贴地使用同一固定网格三角面，缺测或覆盖外拒绝，不填0。原件、报告和每个制品分别固定指纹；采样还核验网格结构和高程一致性。源面到降采样网格的近似误差尚未测得，不以float32接触误差代替源精度。

## 2. 限额与运行环境

| 项目 | 本批处理器边界 |
|---|---|
| 原件 | 处理器≤256MiB；实际HTTP入口可降低，候选测试部署100,000,000字节并由limits返回；≤1600万像元；单波段 |
| 区域网格 | ≤501×501顶点，≤50万三角形；NoData单元不生成三角形 |
| 子进程 | CPU≤30秒、墙钟≤60秒、Linux地址空间≤512MiB；输出文件另有限额 |
| 输入/输出 | 私有目录；高程扫描以256×256窗口进行，不整读高程矩阵；缺测保护一次读取≤1600万像元的有效掩膜（约16MiB） |
| 原件元数据 | 必须记录来源、用途许可、水平CRS、高程基准与米制单位；声明冲突拒绝 |
| 源精度 | Copernicus GLO-30为DSM，包含植被/建筑等影响；没有现场控制点精度承诺 |

GIS依赖单独配置于[可选处理器依赖](../../apps/api/requirements-terrain.txt)。测试服务器使用隔离目录及解释器，不修改运行中的工作台环境；CPython3.12.3、rasterio1.5.2/GDAL3.12.2/PROJ9.8.1、numpy2.5.4。一般工作台不需要在启动时导入GIS库；实际地形任务必须指向已配置的处理器，缺依赖返回不可用，不假成功。

本机默认Python没有GIS依赖。复验需要使用任务输出中登记的GIS解释器；可在独立环境安装上述固定依赖后执行：

```sh
python -m unittest tests.test_terrain_coordinates tests.test_terrain_validation -v
python -m apps.api.terrain_validation INPUT.tif NEW_PRIVATE_OUTPUT --vertical-datum EGM2008 --height-unit m --source '来源说明' --license '用途许可说明'
```

输入覆盖超过区域半径时，明确指定`--aoi west south east north`，不能静默裁到中点附近。Mac不宣称Linux地址空间限制已生效。

## 3. 验证与剩余

已用现有夏李数据检验原始1°GLO-30与裁切文件，均放任务私有输出目录，原件不入Git。实际样本为12,960,000像元/约42.4MiB和727,111像元/约1.8MiB；原始1°文件采用明确AOI，裁切为EPSG:4326并有EGM2008来源记录。输入属于既有本机导航参考数据，不把风机配准坐标当工程控制点。

最终版本在服务器隔离目录通过68项检查：坐标20项、GeoTIFF/网格26项、任务库22项，无跳过。数值检查使用真实GIS；任务库用真实SQLite、后台线程及受控处理器，覆盖幂等/容量、退出或撤权、排队/处理中取消、终态竞态、重启不领取半成品、落盘失败回滚与制品篡改。降采样跨NoData洞、三角索引与报告原点篡改均有回归。

| 实际输入 | 像元 | 子进程墙钟 | 峰值RSS | 有效网格三角形 |
|---|---:|---:|---:|---:|
| 夏李既有裁切 | 727,111 | 0.748秒 | 124,872KiB | 477,660 |
| 原始1°文件＋明确AOI | 12,960,000 | 2.152秒 | 186,396KiB | 477,656 |

CPU30秒、墙钟60秒、地址空间512MiB在这两次Linux进程中实际生效。显示顶点接触高程量化差最大约0.000031米；此数字只反映同一网格f64/f32的差异，源面降采样近似误差仍为未测、现场精度仍未知。一次单机运行不是并发/P95或浏览器帧率承诺，也不保证所有限额内输入都能在限时内成功，超时会明确失败。

另将两份真实输入通过TerrainLibrary后台队列处理并登记ready，核对全部6项私有原件/制品的指纹、可信报告摘要及固定三角面采样；ready后取消保持真实终态，关闭重开后版本仍可读。两任务合计约3.69秒；授权为合成当前权限闭包，不是真实OntoBase账号。结果与日志见[本批证据](../../output/q02-terrain-20261022/README.md)。

## 4. 源表面近似与前后端数值补证（2026-10-23）
