# 模型属性与源身份核验切片

2026-10-25，Q-09 的本机只读切片。沿用 `tools/model_probe.py`，面向现有模型支持与换版前核验；不增加上传格式、服务端任务、绑定写入或产品页面。

## 1. 输入与固定范围

- `--source` 是当前静态自包含 GLB；原有 `--derived/--mapping` 继续用于几何派生核验。
- 可选 `--previous-source` 提供上一来源版本，配合 `--previous-source-sha256` 固定参考指纹；后者不能脱离前者使用。当前版本仍用 `--source-sha256`。三份输入的指纹分别核对，不混用来源版本与渲染派生版本。
- 仍只读本机输入，不访问属性中的 URI，不连接 OntoBase，不修改文件、模型版本、场景或工程身份。输出必须是新目录，输入错误产生失败报告及非零退出码。

## 2. 属性目录

`components.json` 保持 `source`、可选 `derived` 数组，另可含 `previous`。覆盖文件声明的全部节点，以 `activeScene` 区分默认场景；不只导出有网格的节点。

原 `componentKey = 文件SHA256:node:节点索引` 和 `keyStability:version_local` 保持。新增 `sourceExtrasPresent` 与 `sourceExtras`，保留原始 JSON 类型、字符串大小写及空白，包括未采用的身份声明；不存在与显式 null 可区分。属性只是来源数据，不解析 URI、不执行内容、不转换成 OntoBase 的权威属性。

`sourceIdentityState` 取值：

| 状态 | 条件 |
|---|---|
| `missing` | 没有 `extras.ontoVis` 声明 |
| `incomplete` | 声明是对象，已提供字段有效，但缺三元组字段 |
| `invalid` | 声明不是对象，或已提供字段不是非空字符串 |
| `unverified_claim` | 三字段完整且在文件所有节点中唯一 |
| `collision` | 完整三元组在同一文件重复；默认场景外的重复也计入 |

三字段固定为 `sourceModelKey/sourceElementId/placementId`，精确比较原值，不修剪、折叠大小写或用名称、旧 ObjectID、节点索引补齐。残缺及错误字段另列 `sourceIdentityMissingFields/sourceIdentityInvalidFields`。节点级重复即列冲突；本切片不推断多个节点是否属于同一语义组。所有行的 `sourceIdentityVerified` 始终为 false。

## 3. 两版候选

`identity-candidates.json` 固定前后两个文件 SHA，列出完整三元组并集：双方唯一且都在默认场景的条目为 `candidate`；重复为 `collision`；仅前版/仅当前版为 `previous_only/current_only`；非活动节点为 `inactive`。没有完整声明的节点另列 `unavailable`，不得静默丢弃。

候选列出双方版本内构件键、节点号与原名称，并提示原始 extras 是否改变；布尔、数字、数组和对象的类型不会被字符串化后混同。名称或节点顺序变化不影响精确三元组候选；相同名称或相近位置不构成候选。

候选状态始终为 `review_required`，`sourceIdentityVerified/geometryCorrespondenceVerified/bindingMigrationApproved` 均为 false。它不确认稳定来源约定、几何对应、工程 UID、现场关系或绑定迁移。完整声明缺失时如实输出零候选，不生成替代 ID。

报告记录目录及候选文件的实际 SHA256；技术检查失败时不导出候选文件。技术成功与身份可用性分开：缺失/冲突仍可完成只读报告，但工程发布资格继续为 false。原几何映射通过不等于源身份核实。
