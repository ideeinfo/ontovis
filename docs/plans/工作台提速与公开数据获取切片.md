## 区域获取合同

入口为场景的“模型资源→获取公开地形与影像”。中心WGS84经纬度可输入或在当前可见公开地图点击；半径0.5–10km，纬度−79.8°至83.8°，不跨日期变更线。地名查询为明确外链，本页不内建Nominatim地名服务。地图当前视口遵循[OSM瓦片政策](https://operations.osmfoundation.org/policies/tiles/)，不批量离线下载；地图不可达仍可输入坐标。

| 动作 | 已实现的精确入口与条件 |
|---|---|
| 启动 | POST /api/workbench/public-geodata/start；expectedSessionRevision、clientRequestId、name、longitude、latitude、radiusKm、terrain、imagery。当前项目管理员及访问版本重核，返回持久任务，不等待下载 |
| 查询 | POST /api/workbench/public-geodata/job；jobId或空正文（会话条件除外）读取本人最近一次任务，不能查询他人任务。恢复中心、半径和勾选 |
| 取消 | POST /api/workbench/public-geodata/cancel；jobId、expectedJobRevision，锁内重读后判断版本，不用旧轮询结果覆盖新意图 |
| 资源采用 | 下载在受限GIS子进程完成，复用原TerrainLibrary/ImageryLibrary导入固定私有版本；完成只进入资源库。用户再采用地形/影像并保存场景，不自动移动旧场景或写OntoBase项目事实 |

固定[Earth Search v1](https://github.com/Element84/earth-search)目录、[GLO-30 DSM](https://registry.opendata.aws/copernicus-dem/)及[Sentinel-2 COG](https://registry.opendata.aws/sentinel-2-l2a-cogs/)；不接受用户提供的URL。DSM含建筑/植被，EGM2008高程双线性派生30m UTM；RGB原生10m平均为20m，20m SCL最近邻映射后保守排除0/1/3/7/8/9/10/11类，保留透明缺测。选同日低云量组合，裁圆形范围；没有来源/质量合格项时明确失败，不跨日期拼成虚构单景。源日期、原生/派生网格、变换、完整署名随任务/资源保留，非工程定位精度。

任务一并发、最多保留200条、32MiB单输出、读源240秒、CPU/FD/文件上限与Linux512MiB地址空间。GDAL禁.netrc和gdalrc、仅GTiff、PROJ禁联网；STAC不跟重定向。固定可信S3路径的GDAL底层行为没有被记成全链路禁重定向或网络总字节硬预算。停用原服务仅回环的IP限制是本需求必要部署变更，其余身份/沙盒/服务资源限制保持；不改路由器、DNS或边缘策略。
