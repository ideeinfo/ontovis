## 4. 必须保留的设计约束

这些是当前提案的关键边界；接口和页面状态仍需在实施前核定。

1. OntoBase 管设备事实和物理层级；ONTOVis 管模型、场景与绑定。不由模型树、名称、RDS 切分或电气接线自动确认物理父子关系。
2. 柜体几何绑定柜级设备；无几何子设备通过已确认祖先柜体定位。分析对象与空间定位对象分列，代理精度明确可见。
3. MVP 采用自包含 GLB 2.0，可附 JSON/CSV 来源清单。IFC 等先离线受控转换，不宣称已有任意 CAD 在线导入。
4. 构件源身份使用 `sourceModelKey + sourceElementId + placementId`，场景中的整模放置另用实例标识；nodeIndex、名称、Three 运行时 ID 不是跨版本身份。
