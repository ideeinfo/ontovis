## 首批服务契约

以下为本轮实现的ONTOVis同源服务路径。部署状态以[记录](公网演示部署记录.md)为准，不以本机代码存在推断公网已连接。工程权威读取使用已部署OntoBase API，不复制其JWT签名密钥、数据库或权限主数据。

| 路径 | 契约 |
|---|---|
| POST `/api/session/login` | 本人username/password及隐藏的expectedSessionRevision；仅发往部署固定的OntoBase连接，成功后生成新的不透明会话cookie。账号错误统一401；服务失败502/504，不存密码 |
| GET `/api/session` | 返回未登录/有效/失效、当前本人用户名及当前项目可读状态；不返回上游令牌、密码、真实对象清单或无权计数；仅由实际交互触发的activity=1更新空闲时间，普通轮询不续期 |
| POST `/api/session/logout` | 当前会话修订＋同源检查；销毁ONTOVis服务端会话和cookie，取消未完成读取，不影响其他用户 |
| GET `/api/demo/context` | 延续现有演示读取，先核验当前会话/项目成员，再读取固定7号范围及五个安装角色 |
| GET `/api/demo/locate` | 延续entityUid/unitLabel/contextEpoch输入；真实身份/同安装范围/完整assumed父链/修订核对，不能用客户端自报能力或父链 |

后台会话边界（不放入登录表单）：

- 浏览器只持Secure、HttpOnly、SameSite=Strict的不透明cookie；上游令牌仅服务进程内存，不进入浏览器存储。退出或服务重启使本服务会话失效；不声称撤销OntoBase其他客户端的登录。
- 无操作30分钟或最长8小时失效，上游401优先失效。每次工程请求重新核对当前用户/项目授权；权限不足403并清数据。登录成功但项目无权时可保留本人身份，工程目录和定位保持拒绝。
- 登录/退出限定HTTPS同源，防会话固定；退出比较服务端会话修订。首批服务器按来源IP限制每分钟10次登录，不新增账号锁号策略，拒绝时返回429及重试提示。
- 登录/读取均绑定会话与请求上下文；取消、退出、换机位或新会话后，旧响应不能恢复选择。退出/失效同步清理本会话其他标签页的工程数据，后续请求拒绝旧会话。
- 首批只限Demo-PDS、7号演示安装范围、三柜和一个无几何子对象；公网上没有工程写入、正式发布或原文下载入口。项目角色由OntoBase管理，登录不自动分配成员。
- 应用服务使用独立受限进程，固定回环API连接；不持有SSH root、数据库或Cloudflare凭据。源/派生模型与假定关系/候选代理标签继续保留。

此提案不引入SSO平台、多连接器框架、Redis集群或新Worker。首批只建立实际会话/API/Web模块和定向测试；需要扩容时另按实际使用量处理。
