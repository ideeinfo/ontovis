## 1. 场景HTTP首切

同一[工作台服务](../../apps/api/workbench_server.py)已实现以下同源POST。共同要求当前本人会话和`expectedSessionRevision`；项目成员可读，当前项目管理员可创建/保存。通过项目授权读取，不依赖部署默认7号的安装上下文；客户端不能指定项目、用户或上游URL。

| 路径 | 当前真实能力 |
|---|---|
| `/api/workbench/scenes` | 搜索、稳定分页、当前授权及目录快照绑定游标 |
| `/api/workbench/scenes/create` | 创建局部平面空场景及首个固定修订 |
| `/api/workbench/scenes/open` | 请求开始的头修订，或明确指定的保留修订 |
| `/api/workbench/scenes/head` | 只通知是否有新修订，不替换打开内容 |
| `/api/workbench/scenes/save` | 整体保存模型放置、位置/朝向、默认显隐、位置锁定及初始视角 |

本批能力响应明确为`scope=local_plane_unbound`、`existingUploadedModelVersionsOnly=true`。只接受已有私有上传版本、局部米制位置和相对高度；根设备关联、内部构件关联、地理坐标、地形引用及复杂换版影响当前返回`SCENE_SCOPE_UNSUPPORTED`。不能静默丢字段再保存；不能将未来丰富快照降级成空白局部场景。原20MiB GLB接口及旧演示关联仍独立，尚未迁移。

[SceneLibrary](../../apps/api/scene_library.py)在既有私有SQLite中新增独立表。完整不可变快照、头、资源引用、幂等结果及审计同事务提交；当前会话/权限和私有文件指纹在提交前复核。保存带UUID请求ID和期望场景修订；项目＋本人＋动作范围内同载荷重放不增加修订，换会话可重试，相同键不同业务载荷拒绝。保留旧修订和共享文件引用，移除放置不代表设备退役。

模型引用固定`sha256`及纯内容修订，不跟随旧版本的工程关联修订。锁定对象先解锁才可改变位置/资源或移除；移除过的实例标识不能重新挪用。旧头提交、并发写入、授权变化、非法资源或范围外字段整次回滚。资源使用去向内核可区分当前实例、保留实例及保留修订引用数，尚未暴露为项目资源HTTP。

[HTTP边界](../../apps/api/session_http.py)仅把场景save放宽到1MiB；其他场景/旧工作台JSON仍16KiB，登录/退出4KiB。重复JSON键、非有限值、过深载荷、短请求体、重复长度/来源/主机头和跨站来源拒绝。最多100个实例、名称200字符，局部坐标范围见响应limits；本切片内部构件关联限额为0，不能把候选1000条限制写成实际已开放能力。

验证：29项真实SQLite内核与23项真实HTTP检查通过；工程授权为合成夹具，HTTP使用真实回环服务、私有文件、SQLite与线程。与直接相关的旧模型/工作台/会话63项合并共115项通过。涵盖并发/幂等、跨项目、撤权/退出迟到、文件篡改、固定旧修订、独立绑定修订、无默认机组与实际限额；不宣称公网本人账号或实际OntoBase联调通过。

## 2. 地形处理与后续

地形坐标、处理器及实际样本验证见[Q-02记录](地形导入与坐标验证.md)。代码`d08ecb6`已接通以下同源POST，仍未部署：

| 路径 | 当前真实能力 |
|---|---|
| `/api/workbench/terrains/upload` | `image/tiff`原字节，成功接收返回202与真实任务ID；未就绪不能采用 |
| `/api/workbench/terrains/job` | 读取排队、处理中或明确终态，不伪造百分比 |
| `/api/workbench/terrains/job/cancel` | 管理员带期望任务修订/UUID取消；与ready竞态时返回真实终态 |
| `/api/workbench/terrains/version` | 固定报告/制品清单及数据库保存的可信报告摘要 |
| `/api/workbench/terrains/content` | 清单内私有原件/制品，按`artifactId`与期望指纹读取，返回长度和指纹头 |

管理员上传/取消，项目成员读取；每步按原本人会话、当前项目授权修订和角色检查，后台启动/登记也重查；令牌与授权闭包只在内存。不是后台接收一次授权后永久放行。配置可信`--terrain-python`才启用，未配置返回503；客户端不能选择解释器、命令、源URL或服务器路径。处理队列最多2个未完成任务（含处理中）、单进程并发1，20个固定版本/2GiB私有总量，原件与派生一起计数并预留暂存。

**本切片实际上传元数据**：`X-Terrain-Metadata`为base64 UTF-8 JSON，头≤8192字节/解码≤6144字节。必需`expectedSessionRevision, clientRequestId, displayName, sourceNote, licenseNote, rightsDeclared=true, verticalDatum, heightUnit=m`；可选`aoi=[west,south,east,north]`，未知相对基准另需`relativeReferenceId`。原件必须嵌入受支持的水平CRS；当前不接受`suppliedCrs`覆盖，缺失水平CRS或未声明高程基准明确拒绝。基准声明只补来源，不能覆盖文件冲突。此处比Q-01目标上传表收紧，后续UI使用本段实际字段，不能发送拟议别名或跳过许可记录。

原件≤256MiB、已知Content-Length；重复/非法头、Transfer-Encoding、短字节流、任意路径与未列制品均拒绝。版本报告固定可信摘要；原件/制品另有大小与摘要，不能靠旁路静态URL读取。管理员会话退出/失效或撤权使未完成任务不能成功登记；ready后取消不会删除已就绪版本。进程中断时未完成任务不继承旧内存身份或领取半成品，重启明确失败可重新上传；没有物理删除入口。

地形HTTP用实际HTTP/SQLite/线程与受控处理器验证，GIS实际数据另列。锁序修复后的合并158项通过（地形HTTP21、任务22、场景HTTP23、场景内核29、旧接口63）；完整证据见[地形HTTP报告](../../output/q03-terrain-http-20261022/README.md)。独立并发复核发现并关闭会话锁/SQLite写锁倒置：同库业务写入不再持会话锁等待数据库，捕获身份用短锁，提交前回调重核、返回前再检查。一个真实并发测试覆盖场景创建/保存、GLB上传/关联四种写入，竞争时另一会话仍可读取/退出。最后授权检查到本地commit间仍有极小窗口，不宣称跨OntoBase事务原子性；退出后的迟到响应拒绝。数据库长期繁忙的任务恢复见下一节。

## 3. 共享库并发与验证边界

地形后台与前台共用私有测试库；并发恢复代码`e3351a6`。短时SQLite锁竞争以每次250ms、累计约3秒可中断退避重试，复用已生成报告，不重复GIS；超过窗口记录`TERRAIN_STORAGE_BUSY`，其他存储操作错误记录`TERRAIN_STORAGE_UNAVAILABLE`。数据库仍不可写时保留待收尾状态和私有工作，等终态真正落库后才清理，不能先删除文件再声称失败。队列读取、最终登记/rename回滚、关闭时持锁及重启恢复均包含回归；单个任务不能使后台线程退出。此处不是多进程调度或生产存储承诺。

真实GeoTIFF另走通Linux完整HTTP→后台GIS→SQLite→固定版本/6项私有原件及派生读取，两输入合计约3.76秒；核对全部长度/摘要、无默认安装对象读取、退出后拒绝私有版本。上游项目授权仍用合成夹具，不记公网或实际OntoBase账号验收；[实际HTTP结果](../../output/q02-terrain-20261022/linux-real-http.json)。最终Linux相关后端合并212项通过（含地形任务30项），详见[执行记录§26](开发执行记录.md#26-地形http及共享库并发恢复2026-10-22)。
