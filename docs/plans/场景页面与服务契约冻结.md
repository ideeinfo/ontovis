# 场景页面与服务契约实施基线

**Q-01 · 2026-10-22。** 承接[场景方案V2](场景管理与模型实例统一实施方案.md)和[统一任务队列](统一任务队列.md)，将其默认方案落实为可演练页面、服务合同及后续估算。本文的“冻结”是本批实现基线；新增服务仍为拟议，真实地形处理、场景持久化及多实例三维由Q-02—06逐项实现与验证。活动设计继续使用MagicPath项目`463127505021321216`、工作台组件`463127544821075968`，已完成修订`463844606216380416`。

## 1. 本批采用的决定

沿用用户已明确的方向：创建场景、上传GeoTIFF、重复放置已上传模型、拖拽及经纬度设置、每次放置独立关联设备和内部对象。普通场景点击保存后供有权项目成员查看；不增加发布审批。原导航、紧凑三栏、灰绿双主题、中英文、透明原Logo和默认收缩导航继续使用。

同一文件的资源版本可共享；场景中的每次放置拥有独立标识、名称、位置和设备关联。界面使用“场景”“模型资源”“关联设备”“内部构件”等业务名称，不将安装上下文、修订令牌或数据库术语放进普通操作表单。项目对象分类、物理设备层级和场景内容组织仍各司其职。

场景关联与现场事实分开：实际OntoBase对象和假定关系继续准确标识，用户可预览待核实场景；保存不能把代理几何或假定父链升级为已确认工程事实。停用、退役继续暂缓。

## 2. 页面与动作

| 页面 | 默认内容与主操作 | 按需内容及完成边界 |
|---|---|---|
| P-S01 场景列表 | 名称、模型数量、最近保存；创建和打开 | 搜索、空态、加载、失败重试、只读；列表不展示其他项目名称 |
| P-S02 场景编辑 | 左侧内容/资源/项目对象；中间一个视口；右侧所选模型属性 | 浏览/布置明确；同一资源重复添加、复制、位置、朝向、贴地、撤销/重做、显隐/锁定 |
| P-S03 资源核对 | 名称、用途、版本、处理状态、尺寸/单位/基点/朝向 | 可用后放置；当前/历史使用去向；换版先预览影响、可取消，不自动跟最新 |
| P-S04 地形导入 | 选文件、来源与处理结果、使用版本 | 实际检查扩展名和文件大小；坐标/缺测/预算错误有明确状态；原型不上传文件或解析真实高程 |
| P-S05 设备及内部关联 | 选择整设备；需要内部定位时在同一视口进入其构件 | 当前实例持续可见；三柜各选本设备对象；独立变压器不受三柜限制；返回恢复场景视角 |
| P-S06 版本与保存 | 保存、未保存标识；打开时固定已保存修订 | 旧修订提交拒绝；失败保留草稿；别人更新只提示，主动重载；换设备/模型/地形的影响先核对 |

桌面沿用三栏比例，正文13px、说明11px、统一间距；工程名称允许换行。窄屏通过页签或抽屉访问内容和属性，避免三栏同时挤窄。页面只常驻当前对象、操作状态及会影响判断的精度/关系信息，预演控制与原理说明放帮助或折叠区域。

### 放置与关联主路径

1. 创建空场景；没有地理参考时用米制平面整理模型，显示“未设置位置”，经纬度操作不可用。
2. 核对资源可用版本，从资源栏重复加入两个风机模型和一个变压器模型；每次放置生成独立ID。
3. 在布置模式拖动、精确输入或重新贴地；复制后重新选择落点，设备UID、内部关联及测点引用清空。
4. 为不同实例分别选择设备；内部构件只能关联该设备自身或其完整子树中的对象。改变根设备时一次清空受影响内部关联后保存。
5. 从项目对象选择无几何子设备，场景范围寻找直接表示或最近有效祖先；详情与图纸保留该子设备自身身份。
6. 保存并重新打开；实际持久化及当前权限由后端保证，不能以原型内存状态代替。返回细模前视角，构件间从当前镜头直接平滑切换。

## 3. 必须可检查的状态

| 状态 | 页面行为 | 服务端/实施要求 |
|---|---|---|
| 未接入/设计预演 | 帮助与结果说明数据和文件边界 | MagicPath只有合成数据；不收集真实凭据、工程文件或UID |
| 列表空、读取中、读取失败 | 对应空态、进度或重试；不显示旧项目数据 | 项目分页、取消及迟到响应清理 |
| 无读权限/退出 | 清空场景与详情、私有文件引用和高亮 | 当前授权逐请求检查，不能只禁用按钮 |
| 只读/写权失效 | 允许当前有权读取；编辑/保存拒绝 | 提交前再次授权，保存整笔回滚；有效读取权内保留本地草稿 |
| 未保存/离开页面 | 清晰标记；继续编辑或放弃修改离开 | 原型刷新清空；产品离开/刷新提示，不把本地草稿当共享保存 |
| 保存中/失败/版本冲突 | 禁止重复提交；失败保留草稿；冲突先读取变化 | 幂等键与期望修订校验；同键异体拒绝，无自动覆盖或静默合并 |
| 有新修订 | 继续显示打开时版本；主动重新载入 | 不在查看过程中换资源或移动设备；草稿存在先处理未保存修改 |
| 资源处理未完成/失败 | 不可放置；查看报告、在允许范围重试 | 处理状态与校准通过均满足后可用，文件内容固定 |
| 资源已被使用 | 显示当前/历史使用去向 | 保留修订仍引用时不能清理私有内容；不泄露无权场景名称 |
| 首次地理锚定 | 局部点、经纬度锚点与朝向预览后确认 | 未确认不改布局、不生成假经纬度；确认一次提交完整变换 |
| 覆盖外/缺测 | 贴地拒绝；选有效点或明确指定高程 | 缺测不当0米；地形隐藏仍可采样；不能从画面网格猜测地表 |
| 地形更换 | 预览高度差，选择保持高程或重新贴地 | 指定高程默认保持；基准不同需显式转换或拒绝 |
| 模型换版 | 展示几何、位置及关联影响；取消恢复 | 固定旧版；稳定身份仅生成候选，同名/同键不能自动确认新绑定 |
| 隐藏/位置锁定 | 隐藏定位可临时显示并恢复；锁定仍可查看/关联 | 浏览显隐临时；布置默认显隐与锁定随修订保存；锁定不充当权限 |
| 多表示/断链/最近关联失效 | 明确选择或停止定位，保留所选对象 | 不因上次实例选中限定全场搜索，不越过失效近层祖先找更远设备 |
| 无几何子设备 | 显示自己的详情与图纸，宿主另列 | 工程资料读取不要求几何成功；不得用祖先柜体资料冒充 |

## 4. 服务与坐标基线

详细字段、拟议HTTP路径、权限、错误响应、修订和可测试示例见[场景资源与多实例服务契约](../contracts/场景资源与多实例服务契约.md)。现有20MiB静态GLB接口是可复用切片，新资源/地形/场景路由不能写成已上线能力；迁移后资源内容身份与场景关联修订分开。

首切使用锁定的区域投影米制坐标进行编辑，Three显示X东、Y上、Z南；不将其称为严格ENU。经纬度交换为WGS84、`[经度, 纬度]`，拖动和字段输入经同一转换。朝向以真北0°顺时针，处理投影网格方向差；设备安装朝向与运行偏航/叶轮转速分开。

高程保持原基准：贴地固定地形版本、采样位置/结果和偏移；指定高程明确数值与基准；未知高程基准只允许明确标注的相对布置，不提供工程绝对量测。GLO-30的EGM2008正高不能直接作椭球高；后续地球/ECEF衔接需补已验证的垂直转换。

预算仍按两步冻结：Q-01确定候选和拒绝/恢复状态，Q-02在代表样本与目标硬件实测后冻结运行上限。候选GeoTIFF≤256MiB、输入≤1600万像元，另限定波段、任务时间、内存、并发和输出三角形。模型20MiB限额独立。坐标数值往返误差、地形采样误差和现场源精度分别报告；没有控制点不能承诺现场厘米级精度。

Q-06拟定20实例性能验收、100实例探限、整体浏览30fps目标。Q-02需登记硬件、网络、样本几何/纹理、冷/热缓存与帧时间预算；这三个数字当前是验收候选，不是已达到的产品指标。
