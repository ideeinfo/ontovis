# 关联图纸首切页面与服务评审

2026-10-21 · **待选择版本策略并冻结新切片；尚未实现以下新API或正式页面。**

前置的[全部项目旧读取授权](受保护证据与旧入口授权评审.md)已在OntoBase测试环境部署，空间导航Demo保持本机参考。本稿承接原MagicPath工作台，为正式ONTOVis准备所选子对象的关联图纸读取，不扩大公开Demo或确认现场工程事实。

## 本次需要决定

建议先做**当前内容快照的受保护预览**：列举资料时固定当前文件摘要、对象/来源修订；打开时重新核验权限及相同内容。文件或引用改变就拒绝打开，回到清单由用户明确选择，不悄悄打开最新版。这不提供历史文件永久归档或任意历史回放。

另一方案是先完成历史文件归档、保留策略和不可变版本服务，再开放原文。它能在来源更新后继续打开已归档旧版，但需要独立的存储/资料生命周期工作；不把它假定为已有能力。

两种方案都遵守当前授权。已下载到外部的历史副本不能由接口召回。本稿建议先完成当前版本闭环，历史归档另排，不降低工程绑定/发布的版本与证据要求。

## 页面与来源边界

沿用MagicPath项目`463127505021321216`的工作台`463127544821075968`，只增补右侧“证据”页签及其关联图纸弹窗，其他三个画面不改。当前候选修订`463633480128040960`已远端构建，云端初始页、本机同源码30项交互及严格类型检查通过；验证记录见[设计索引](../design/MagicPath交互设计.md)。

- 登录仍只有用户名和密码。来源、连接和权限状态不进入登录表单。
- 选择子对象后，证据显示该子对象的直接来源或其明确固定的型号定义来源；不会用CN等空间宿主的资料补空。
- 弹窗分列“分析对象”和“空间定位”，型号来源明确标注“用于同型号参照；现场安装关系仍待核实”。父链不完整时可保留合法的来源读取，但空间定位显示未知。
- 展示文件名称、固定内容版本、页码和区域。只有来源锚点可证明属于相同文件内容时才显示区域，否则降为整页；不把旧bbox贴到未核实的新文件上。
- 保留加载、无关联、无权、版本变化、原文缺失和读取失败。无权时不显示文件名称、数量、路径或上次预览；无资料与请求失败分开。
- 版本变化后，重新读取只更新清单，必须再次选择才能打开另一版本。关闭、退出、失效、撤权、对象/机位变化立即关闭旧原文，丢弃迟到结果。
- 原文提供缩放与适合窗口；图示只是合成交互预演，正式实现复用成熟阅读组件与已有对象URL清理方式。首批不新增下载、分享或资料上传。

MagicPath内的九种资料状态仅供设计评审，不是浏览器自报权限或服务返回值。原图为合成SVG示意，没有上传私人图纸、对象UID或第三方模型；正式服务尚未接通。确认绑定和工程发布仍禁用。

## 首批服务契约提案

以下是**拟议路径**，不是已部署能力。由OntoBase自身后端实现，ONTOVis通过本人会话访问；不直连数据库/对象存储，不使用SSH root代替应用授权。

| 拟议请求 | 受限行为 |
|---|---|
| POST `/api/v1/projects/{project_code}/object-evidence/resolve` | 输入所选entityUid、installationContextId和expectedEntityRevision。按当前项目成员及实际安装归属核验，再列举直接证据或固定型号定义来源，最多20项；超量明确返回范围超限，不能截断后声称完整。 |
| POST `/api/v1/projects/{project_code}/object-evidence/content` | 输入相同对象/安装范围、evidenceRef、期望对象/来源修订和内容摘要。服务端重新解析关联与实际文件归属，返回相同内容的一页PDF/受限图片；客户端不能指定存储地址或任意URL。 |

1. 首批仅同项目图纸、同一台7号演示实例及其已存在的子对象来源；跨项目引用不自动开放。三柜缺乏真实来源关联就保持未关联，不根据柜名、几何或电气连线生成证据。
2. 型号来源携带`sourceRelation=template_definition`、sourceEntityUid和固定sourceTemplateRevision，分析对象UID保留。原定义发生合并/变更、安装归属变化或版本不符时409，不能自动跟随新身份/版本；不把旧对象元数据冒充历史快照。
3. 来源结果包含evidenceRef、来源类别、可读标题/页码、对象与来源修订、`versionMode=current_content_snapshot`、服务器计算的文件摘要、页级/区域级精度。来源记录摘要与文件摘要分列；现有`snapshot_only`证据记录不等于已归档原文。
4. 内容读取再次核实当前活跃账户、项目成员、对象/安装归属、来源关联、修订及文件摘要。缺对象或无权统一拒绝；版本变化、合法引用但原文缺失、存储失败分别给出明确状态。没有版本匹配就不打开替代文件。
5. 一次只打开一个关联页；首批单页内容上限20MiB，超限明确拒绝，复杂转换另排。不增加全项目批量下载或通用文件代理。
6. 所有响应no-store；令牌不进入URL，不永久缓存正文。服务端拒绝与客户端状态清理配套，退出/撤权后的迟到内容不能重新显示。

端点采用独立object-evidence名称，避免与现有支持斜杠UID的`objects/{entity_uid:path}`解析路径冲突。具体DTO、状态码和定向测试在此版本策略获确认后随实现冻结；不能把本文路径当成当前可调用API。

## 确认后的首批任务

| 任务 | 仓库及验收 |
|---|---|
| OB-05a 来源解析 | OntoBase：一条真实子对象→固定型号定义→关联图纸；验证无来源、归属变化、来源变更与跨项目拒绝。保留unknown/needs_review等真实类型状态。 |
| OB-05b 内容读取 | OntoBase：服务器摘要与打开前重查；缺可信区域显示整页；文件变化拒绝，缺原文不回退。隔离测试与真实只读样本分列。 |
| OV-06a 正式只读页面 | ONTOVis：依据现有MagicPath接入工程对象、定位宿主与关联图纸；简单登录不变。空间Demo只作交互参考，不直接作为产品构建包。 |
| QA 来源闭环 | 一对象、一合法来源页，验证有/无区域、两用户/跨项目、撤权、退出、机位变化和迟到响应。工程发布仍阻断，不运行OntoBase冻结识别矩阵。 |

这是OB-05/OV-06的受限子范围，不包括历史归档、对象退役、正式持久绑定、模型上传/审核发布、现场设备控制或G1/G2/G3整门。按[AGENTS.md](../../AGENTS.md)“正式实现前应冻结页面状态和服务契约”的要求，本稿先提供可评审页面与服务边界，等待本次版本策略选择。
