## 已实现服务契约

同源路径均由当前本人会话读取，服务端固定项目及设备上下文；浏览器不能提交上游连接、项目权限或文件URL。

| 路径 | 本批行为 |
|---|---|
| POST `/api/workbench/context` | 当前设备上下文、根对象及首屏直接子节点一起返回，减少串行等待 |
| POST `/api/workbench/catalog` | `q`最多200字符、`scope=project|equipment`、可选服务端cursor；每页50项。范围、权限、游标由OntoBase核验 |
| POST `/api/workbench/object` | 明确equipment/project读取；未安装的项目对象没有设备祖先，不借用7号身份 |
| POST `/api/workbench/evidence/resolve`、`content` | 设备对象成对提供上下文/层级修订；未安装的项目对象两项同时null。对象修订和来源/内容核验保留 |
| POST `/api/workbench/model` | 已授权私有GLB指纹、三柜实际UID与固定对象修订、版本内几何范围和演示精度 |
| POST `/api/workbench/model/content` | 仅接受期望模型SHA256；当前项目授权、会话、层级及三柜身份在读取后复核，返回no-store GLB |

OntoBase仅新增`hasChildren`摘要及未安装对象的自身图纸读取，没有新迁移或业务写入。耗时的旧默认密码哈希比较按哈希有界复用；活跃账户、项目成员和授权修订仍逐请求查询，密码哈希变化重新校验。
