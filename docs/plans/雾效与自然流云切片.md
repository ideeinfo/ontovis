# 雾效与自然流云切片

2026-10-24，Q-43，承接已部署3290903与Q-42环境V1；本批测试范围已完成并部署153，运行源码b6412b1；证据见执行记录§67。

## 冻结范围

修正原色影像与外围材质绕过雾的路径，原色仍不受太阳/曝光影响，开启距离雾时与模型、地表共同融入地平线颜色。保留已有线性雾参数与旧场景保存值；新预设陆地/黄昏起点150m、终点6000/4000m，海上起点2000m、终点35000m。雾距从相机沿视线起算，近景可降低起终点，关闭雾则保持原色。

在原环境面板中增加“自然流云”，包含显示开关、云量0—1、密度0—2、视觉云团尺度500—12000m、行进方向[0,360)°、视觉速度0—100m/s、默认播放。默认云量0.5、密度1、尺度2200m、速度12m/s、方向75°；通过预设或明确启用进入预览。中英文、灰绿主题、14px复选框与数值范围说明沿用。

## 保存与兼容

环境V1的atmosphere新增可选clouds：固定mode=procedural-cumulus-v1，enabled、coverage、density、scaleM、speedMps、headingDeg、seed（0—2147483647整数）、defaultPlayback（playing/paused）。缺失保持无云，不在读取时补字段或产生修订；后端cloudModes能力声明后才开放写入。已有clouds不可被旧客户端省略，409 CLOUD_FIELD_REQUIRED；显式enabled=false关闭，environment=null恢复原有显示。沿用权限/CAS/幂等/check/save与environmentWriteVersion=1，后端拒绝未知字段、外部URL、程序、非法数值。

## 渲染与边界

一层程序天空，使用有种子的多尺度无缝噪声和形态扭曲，区分云团覆盖、柔边与受光明暗；不使用直线波带或外部素材。单张256²噪声含mipmap约349524B，单个24×12球面（528三角），无离屏云pass、无逐帧纹理生成或PMREM重算。只绘制天空，非实测天气，不投地面云影、不改变静态环境反射或光照计算。水纹/流云分别暂停，尊重减少动画与后台暂停，最多30次视觉更新/秒；取消预览恢复各自时钟与个人播放状态。

云层与外围均不参与拾取、放置、贴地、测量、全景包围盒，地形/影像/模型版本/实例坐标和工程关联不变。旧场景雾参数保留，雾仅改变显示，不修改原始影像像素。
