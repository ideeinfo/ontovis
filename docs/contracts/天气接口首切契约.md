# 天气接口首切契约

2026-10-30，C3-W1 实施冻结；未部署。用户授权调研开放天气接口、接入及 ONTOVis 后台 API 配置。配置只属于可视化，不修改 OntoBase 工程资料。

## 来源选择

| 来源 | 授权及接入 | 首期决定 |
|---|---|---|
| [Open-Meteo](https://github.com/open-meteo/open-meteo) | 服务源码 AGPLv3，可自建；[托管免费 API](https://open-meteo.com/en/terms)限非商业，商业托管需订阅 | 保留为后续自建/商业来源，不擅自启用付费或把免费端用于商业产品 |
| [MET Norway Locationforecast 2.0](https://docs.api.met.no/doc/FAQ.html) | 全球预报，CC BY 4.0，合理流量可免费商业使用；需有效联系标识 | 首切接入；无需 API Key。已核实本项目公开 GitHub 可开 issue，可作为默认联系链接 |
| [OpenWeather](https://openweathermap.org/api) | 需账户/API Key，按产品与套餐授权；不等同开源服务 | 暂不创建账户或购买套餐 |

MET 全球数据为模式预报，官方资料列约 9 km 网格、每日 4 次更新；复杂地形的风速不代表机位实测。温度为地面以上 2 m，风速为 10 m，风向为来向；不能转换成机舱偏航/转子转速。见[数据模型](https://docs.api.met.no/doc/locationforecast/datamodel.html)。天气图标代表未来 1/6/12 小时时段，不能标成瞬时观测；见[时间语义](https://docs.api.met.no/doc/locationforecast/FAQ.html)。

## 页面与数据

工作台“数据与告警”增加“天气接口”页签。显示固定供应商/HTTPS 端点、联系链接或业务邮箱、启停、最小更新间隔（3/6/12 小时）、场景查询点（WGS84 经纬度、点名），最多 50 点且每场景一个。查询点是显示参考点，不认定整个场景已测绘或覆盖；局部坐标场景也需明确填点，不推断坐标。默认关闭、无点。

“测试查询”只预览当前草稿点，不保存/启用；标明结果为预报。保存需项目管理员、当前会话/权限版本、配置修订 CAS 和请求幂等键。只读成员可看已授权配置和天气，不能测试草稿或保存。前端处理未保存离开；请求中禁重复提交，离开或切项目取消读取，迟到结果不覆盖新范围。

新增项目受控 POST 路径 `/api/workbench/weather/{config,save,test,current}`，复用现有会话、CSRF、项目隔离和撤权处理。配置保存于 ONTOVis 配对模型库的版本与请求回执表；天气响应缓存独立表，纳入现有离线备份。端点由服务端固定，客户端不传任意 URL/API Key，返回中无凭据。

查询只外发四位小数以内的经纬度和联系标识，不发送项目名称、设备 UID、模型或资料。遵循 [MET 缓存要求](https://docs.api.met.no/doc/TermsOfService.html)：不早于 Expires 和本地最小刷新期，续查使用原 Last-Modified；合并相同点并发；限流/失败退避；连接与响应大小有界；支持 gzip 及同源 HTTPS 重定向。全球最短 3 小时，页面轮询只读取服务端缓存。无后台定时抓取。

## 驾驶舱

场景右侧增加天气卡，显示“预报”、查询点、有效时段、发布与获取时间、温度/10 m 风速/风向/时段降水、来源及 CC BY 4.0 链接。原始数据经单位校验与展示归一化。缺值为未知，不填 0。无配置、停用、服务异常、超时、限流、数据超期和格式不支持分别可见。

仅可用且在有效时段的预报驱动云/雨/雪/雾的视觉示意；标注“按预报显示”，提供个人特效开关，不持久改写场景。隐藏页面、分析页、低动态偏好暂停动画。无法得到可用天气时停止特效并保留原因，不伪造晴天。不会驱动叶轮、偏航或现场设备。历史场景不把当前天气写入历史来源。

验证至少覆盖：管理员/成员/撤权与跨项目；CAS/请求幂等；坐标范围/NaN/未知字段；缓存/304/Expires/失败退避；过期/未来时间/缺值/未知符号；真实源单次试读；中英/深浅/缩放/窄屏；未保存保护；备份新目录恢复。真实设备遥测、C4 地球/空间过渡及爆炸仍单独推进。
