# 天气接口首切契约

2026-10-30，C3-W1 实施冻结；已发布并完成公网及备份恢复验收。用户授权调研开放天气接口、接入及 ONTOVis 后台 API 配置。配置只属于可视化，不修改 OntoBase 工程资料。

## 来源选择

| 来源 | 授权及接入 | 首期决定 |
|---|---|---|
| [Open-Meteo](https://github.com/open-meteo/open-meteo) | 服务源码 AGPLv3，可自建；[托管免费 API](https://open-meteo.com/en/terms)限非商业，商业托管需订阅 | 保留为后续自建/商业来源，不擅自启用付费或把免费端用于商业产品 |
| [MET Norway Locationforecast 2.0](https://docs.api.met.no/doc/FAQ.html) | 全球预报，CC BY 4.0，合理流量可免费商业使用；需有效联系标识 | 首切接入；无需 API Key。已核实本项目公开 GitHub 可开 issue，可作为默认联系链接 |
| [OpenWeather](https://openweathermap.org/api) | 需账户/API Key，按产品与套餐授权；不等同开源服务 | 暂不创建账户或购买套餐 |

MET 全球数据为模式预报，官方资料列约 9 km 网格、每日 4 次更新；复杂地形的风速不代表机位实测。温度为地面以上 2 m，风速为 10 m，风向为来向；不能转换成机舱偏航/转子转速。见[数据模型](https://docs.api.met.no/doc/locationforecast/datamodel.html)。天气图标代表未来 1/6/12 小时时段，不能标成瞬时观测；见[时间语义](https://docs.api.met.no/doc/locationforecast/FAQ.html)。

## 页面与数据

工作台“数据与告警”增加“天气接口”页签。仅配置项目级天气接口：显示固定供应商/HTTPS 端点、联系链接或业务邮箱、启停、最小更新间隔（3/6/12 小时），不要求逐场景重复配置查询点或填写查询点名称。项目启用天气后，所有已完成地理定位的场景（`coordinateFrame.mode == 'projected_site'`）直接读取场景生效快照自身的 `coordinateFrame.anchor.geographicAnchor`（截断至四位小数）查询天气；未完成地理定位的局部坐标场景（`local_plane`）返回 `unconfigured`，不推断坐标。默认关闭。历史配置记录若含旧 `points` 字段，保留其场景范围；只有管理员明确保存新项目级范围后才扩展，详见本页Review修订。

“测试查询”预览当前草稿对应的预报。保存需要项目管理员权限，并核对当前会话、权限和设置标记。提交与当前设置相同的内容时直接返回当前设置。只读成员可看已授权配置和天气。前端提示未保存的修改，离开或切换项目时取消读取。

项目受控 POST 路径 `/api/workbench/weather/{config,save,test,current}` 复用现有会话、CSRF、项目隔离和撤权处理。ONTOVis 配对模型库为每个项目保存一条当前设置，天气缓存使用独立表，两者均纳入现有离线备份。已有项目先读取最后一次保存的旧设置，管理员保存时将当前设置写入新表。端点由服务端固定。

查询只外发四位小数以内的经纬度和联系标识，不发送项目名称、设备 UID、模型或资料。遵循 [MET 缓存要求](https://docs.api.met.no/doc/TermsOfService.html)：不早于 Expires 和本地最小刷新期，续查使用原 Last-Modified；合并相同点并发；限流/失败退避；连接与响应大小有界；支持 gzip 及同源 HTTPS 重定向。全球最短 3 小时，页面轮询只读取服务端缓存。无后台定时抓取。

## 驾驶舱

场景右侧增加天气卡，显示“预报”、有效时段、发布与获取时间、温度/10 m 风速/风向/时段降水、来源及 CC BY 4.0 链接（不展示人工定义的查询点名称）。原始数据经单位校验与展示归一化。缺值为未知，不填 0。无配置、停用、服务异常、超时、限流、数据超期和格式不支持分别可见。

仅可用且在有效时段的预报驱动云/雨/雪/雾的视觉示意；标注“按预报显示”，提供个人特效开关，不持久改写场景。隐藏页面、分析页、低动态偏好暂停动画。无法得到可用天气时停止特效并保留原因，不伪造晴天。不会驱动叶轮、偏航或现场设备。历史场景不把当前天气写入历史来源。

验证覆盖权限与项目隔离、同时保存与重复提交、旧设置读取、输入校验、缓存与失败退避、预报有效性、真实来源试读、双语与主题、缩放与窄屏、未保存保护和备份恢复。真实设备遥测、C4 地球/空间过渡及爆炸仍单独推进。

## 2026-11-02 Review 修订（本机修复，未发布）

旧配置保留 `points` 指定的场景范围，并使用这些场景的当前锚点。配置读取通过 `legacySceneIds` 返回该范围。管理员明确点击“启用项目范围并保存”后，设置才适用于项目内全部已定位场景。

没有可用锚点的草稿测试返回 `WEATHER_POINT_REQUIRED`，不使用固定北京坐标。场景在来源请求期间发生head变化时返回冲突，不把旧坐标预报标成当前场景结果。

天气界面只描述模式预报，不通过统一切入/额定/切出阈值推断设备工况，不对登塔、无人机自动巡检或维护发出适宜度/许可判断。缺失、未知、过期数据不当作0或良好条件；降水按对应时段累计展示。100m估算必须标为假设而非当前设备轮毂实测。经纬度使用正确半球，夜间图标与预报时段匹配。见[Review](../reviews/其他智能体迭代Review-20261102.md)。
