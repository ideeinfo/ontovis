# 分析画布列表与回收站

2026-10-27，按用户本轮要求实施。沿用[Q-23实现契约](分析画布Q23实现契约.md)的本人、项目、版本与来源边界。

- 画布列表与加入资料面板分别开关，互不关闭。编辑区顶部始终保留带文字的“画布列表”开关；隐藏、召回、打开资料和详情不清空当前画布或修改其内容。窄窗口列表以浮层显示，顶部开关和列表关闭按钮均可操作，不能用媒体查询强制隐藏。
- 列表每行的更多及右键共用菜单：打开、移至回收站。删除前显示名称和可恢复说明；当前画布有未保存内容时明确提示这些修改不会保存。删除成功清理当前已删除画布的编辑状态，列表仍可操作。
- 回收站与正常列表分开筛选，可只读查看及恢复，不提供永久清除。恢复保留原分析ID、全部内容修订、固定来源及工单历史关联；删除不制造新的内容修订。
- 服务端只允许本人且为当前项目管理员执行移至回收站及恢复。请求包含期望内容头修订、期望生命周期修订和幂等请求ID；事务同时检查权限、归属、状态与版本。已删除画布拒绝保存、修订恢复及新增资料；旧客户端不能通过重试写回。已有工单固定修订及历史参考继续可读。新报警不自动续接已删除画布，也不将其列为同码历史候选。
- `/api/workbench/analysis-sessions`新增`lifecycle=active|trashed`筛选，默认active；行及详情带`lifecycle/lifecycleRevision`。新增`/trash`及`/untrash`，正文为`analysisSessionId/expectedAnalysisRevision/expectedLifecycleRevision/requestId`，沿用项目引用及登录会话条件；`/restore`仍表示恢复内容修订。
- 分析存储显式v2→v3离线迁移，保留storeId和五张原表全部业务行，新增只追加的生命周期事件表；首次状态视为active/0。备份覆盖事件与请求回执，支持旧v1/v2读取恢复及新v3成组恢复。运行账户只获得新事件表的SELECT/INSERT，不扩大工程来源或项目访问权限。

实现和实际发布验收分别记入[执行记录](../plans/开发执行记录.md)，设计端使用明确合成数据，不能替代真实后端持久化和权限验证。
