# 型号共享资料读取同步契约

2026-10-29，按用户授权在 ONTOVis 实施；OntoBase 仅作为已部署的只读权威来源，不修改其数据库、业务数据或部署，Test2 不动。型号差异仍用独立型号，不恢复变体。

## 受控转接

所有工作台路由使用现有 POST 会话信封，项目、用户、访问修订来自当前会话，不接收源站 URL 或令牌。读后重新核对权限/会话修订，退出、撤权、切换、取消后清理内容。

| ONTOVis 路由 `/api/workbench/equipment` 下 | 固定源端读取 |
|---|---|
| `/materials/models` | GET `equipment-materials/models/{specificationId}`；scope/kind/cursor/limit |
| `/materials/candidates` | GET 同型号 `/candidates`；revision/scope/q/kind/cursor/limit，选中状态仅作来源说明 |
| `/materials/resolve` | POST `equipment-materials/devices/resolve`；实时设备 entityUid/expectedEntityRevision/installationContextId/expectedHierarchyRevision，cursor/limit |
| `/materials/metadata` | GET 当前项目固定 document/version 元数据 |
| `/materials/content` | GET 固定 `documents/{documentId}/content?version_id=...&rendition=display&page=...` |
| `/attribute-form` | GET `equipment/{entityUid}/attribute-form`，不由客户端指定模板或分类 |

只开放表中明确读取；不转接源端 preview/save/operations 管理动作。UUID、整数范围、角色范围、资料类型、游标长度与响应身份均验证。源端管理保留导航入口，资料计数不硬编码。total 是范围关联数量；设备 items 按固定版本去重，不能把两者混称文件数。

## 页面状态与资料选择

设备共享资料新增“适用资料”，消费服务端解析出的型号/角色；保留“对象定位照片”“工程图纸与证据”和独立“现场照片”。整机零适用资料是有效空结果，不回退其他角色。型号共享目录可按服务端 roles、PDF/照片分页读取；一次源端配置直接适用于同型号设备，不重新采用、不逐台选择。

固定原文使用现有受保护二进制读取和照片视口；PDF翻页、照片整图均可滚轮缩放/左键平移。没有 evidenceRef/bbox/renditionId 时不补造区域，旧定位框仍由旧接口读取。

分析资料选择明确增加“当前设备适用资料”和“本项目文档库”。前者要求明确的安装设备身份，后者按项目文档接口分页查询，有权读取的 PDF/照片不以缺对象关联、区域或已发布知识为由隐藏。选入分析仍经本人固定证据登记，不修改型号共享目录。安装设备卡的“推荐相关资料”直接进入设备适用目录；共享定义保留原定位资料。推荐记录可含 reasonEn 作为英文说明，不改变固定来源描述。

新增普通照片描述：sourceKind=`photo`，descriptor 恰为 `{sourceType:'project_document', documentId, contentVersionId, sourceSha256}`。其身份是固定项目文档版本，不声明对象、安装设备或区域。旧照片描述及历史引用完全保留。PDF可从仅含 documentId/contentVersionId/pageNumber 的选择登记，后端读取固定版本取得 sourceSha256；旧完整描述继续核对原摘要。该扩展不新增数据库结构，配对恢复继续验证固定描述。

设备 resolve 保留源端 model；部件没有自身型号时不把整机参数展示为部件参数。单台属性使用源端 attribute-form 的上下文、字段名称、单位和继承信息。原固定采用、绑定、场景及分析修订保持。

加载、有效空结果、过滤空结果、失败重试、401/403/409、失效来源、快速切换/取消、中英文与窄屏均为本批验证状态。实际发布与验收结果见执行记录；34 PDF、6照片、目录r2/6关联等仅作当前只读样本。
