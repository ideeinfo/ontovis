# 驾驶舱报警标签与风机取景契约

日期：2026-10-31。承接已发布的橙色样式，落实风机/设备文字标签、首页风机总数与默认全场取景。本契约只改变驾驶舱展示；不增加业务写入或现场数据源。

## 风机统计

首页有完整风机模型的项目显示“风机总数”。当前按已登记固定内容的整机风机模型识别，不根据名称猜测；柜体、测试三角形及其他模型不计入。同一已绑定且在当前项目可读的安装设备跨场景只计一次；无有效安装绑定的风机按场景布置实例计，不合并同名模型。个人显隐不改变统计。缺失场景快照时显示未完成值，不用部分数量冒充总数。其他行业项目沿用“设备总数”。

此数为可视化场景中的风机布置口径；未绑定部分不是已核实现场设备台账。完整口径集中在“数据与来源”，主屏只显示统计名称及数字；场景卡和场景摘要也显示完整风机数量。

## 报警文字标签

沿用当前授权模拟回放与已关联安装目标。场景页在报警风机上方显示风机完整名称、活动事件数；设备页继续显示报警部件名称，以及选中的固定事件或聚合数量。多条事件按同一场景实例/部件合并成一个标签，独立复发仍计入事件数，不按故障码或同名对象合并身份。警告为橙色，严重为红色。

标签锚点取当前显示整机或固定绑定部件的世界边界，随旋转、偏航及镜头移动更新。部件映射、固定资源、对象修订或可见性不满足时，不凭名称制造部件位置；没有有效独立几何时保留风机级标签。名称允许换行，标签避开两侧面板，并以引线连接实际锚点。点标签继续使用同一事件/版本和安装对象进行定位隔离。

主屏仍保留紧凑模拟来源标识。标签不是现场报警接入或工程位置认证；数据与精度边界保持。

## 首次取景与返回

驾驶舱首次进入场景，以全部可见风机整机范围适屏，排除大范围地形和非风机样本；无风机的行业场景按可见模型范围。使用平缓俯视角，保留原镜头方位，并把左右信息面板占据的区域从取景空间扣除。逐台对实际风机边界求透视适屏距离，避免只靠中心三台或整个地形范围取景；全场镜头保证相机不进入原地形；不会把落在山体内的场景中心当成设备目标，反复抬高镜头。设备特写仍保留原视线避障。

当前会话返回同一场景时恢复已记住镜头；明确从工作台传入的镜头或设备定位保持显式意图。报警/设备定位优先聚焦目标。驾驶舱“显示全部”重新按全体风机适屏。

工作台保存场景时仍保存当前视角，不回写或重置业务场景视角。驾驶舱首次全场取景优先于直接使用场景中保存的过远镜头；这是2026-10-31对既有加载规则的展示侧补充。

## 验证范围

风机类型/身份/跨场景统计、固定事件聚合、错误与恢复排除、标签边界/避让、构件运动后锚点和全部风机透视适屏分别测试。正式候选与公网另核验真实模型、深浅主题、标签点击、全部可见风机默认取景及返回镜头；MagicPath只作为设计预演。
