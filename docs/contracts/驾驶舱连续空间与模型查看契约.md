# 驾驶舱连续空间与模型查看契约

## 模型热切换的交互锁（2026-11-03）

- 从发起设备定位开始，到当前固定模型、安装实例及当前会话对应的资源加载并完成画面提交前，禁用设备选择、结构下钻/返回上级、空间拾取、报警再定位、聚焦、隔离和模型查看模式。返回项目资产/场景、退出、资料查看和失败重试仍可用，不排队执行被禁用的点击。
- 准备状态绑定场景/导航、固定资源版本与SHA、实际实例-模型组合、会话和重试。旧模型、其他实例、旧会话或迟到回调不能解锁当前操作；接口返回、模型元数据就绪或缓存命中本身不视为切换完成。既定构件高亮/隔离须在完成画面提交前应用。
- 定位请求阶段显示简洁的不定进度“正在切换模型”；已知资源后沿用真实准备步骤进度及画面生成步骤，不伪造字节/时间估计。失败显示可重试状态，允许改选其他设备，失败模型的聚焦/隔离/变形保持禁用；取消或离开后不采用迟到结果。
- 本条只调整展示交互，不新增权限、工程写入或绑定规则；通用外观/完整模型配对及后端权限/版本复核保持。

V1.0，2026-10-30。按已批准 C4 顺序实现，承接既有详细设计与夏李本机 Demo 的交互节奏；不发布 Demo 包，不复制其私有资源。

## 地球与场景位置

- 使用已核对来源的 NASA SVS Blue Marble 历史合成底图，保留署名、年代与来源；地球云层、大气、光照为示意，非实时卫星影像或现场天气。底图随应用分发，不向外部地图服务发送项目位置。
- 只使用当前已授权、读取成功的固定场景 `projected_site` 地理锚点。位置标为“场景参考点，精度未核实”；不把参考点认定为实测设备位置，不使用天气配置反推资产位置，不为局部场景添加 0,0。
- 项目列表保持全部可读场景；搜索同时过滤地球点位。重叠点聚合计数为场景数，点击展开或聚焦，再选具体场景。无地理位置或 WebGL 不可用时仍可从列表进入。

## 连续导航

- 从资产页选择场景，先加载固定模型、地形及影像，保留地球与列表；目标第一次成功绘制后才执行飞入与淡入交接。加载失败保持资产页，提供重试、取消。
- 导航带递增标识及固定场景修订。取消、改选、切项目、退出时废弃旧导航；迟到的加载、计时器或准备回执不得覆盖新目标。
- 地球沿场景锚点收敛，局部场景直接切换；最后交接到场景保存的镜头或会话书签。地球球面与工程局部相机分别计算，不直接复用矩阵，不宣称测绘级连续投影。
- 场景到设备沿用目标包围盒的相机渐变，返回保留固定版本及视角。交接期间只有一个空间引擎接收输入，导航/取消仍可操作。
- 减少动态时直接切换；后台隐藏暂停渲染并重置时间，避免回来后补播。纹理或 WebGL 失败降级到可用列表；清理视口、贴图、监听与动画。

## 模型查看

- 在设备页提供实体、透视与爆炸示意。首切适配已有完整 TU-3000 合并版固定内容；外观版或未匹配模型保留实体并说明能力缺失。
- 透视只改变实例克隆的外壳透明度，内部几何必须来自已加载模型；不生成不存在的工程部件。爆炸为可逆的查看位移，明确“示意、非拆解步骤或测量依据”。
- 节点按固定内容及加载器来源身份适配，保留模型校准、实例安装、对象绑定、共享缓存及原材质。模式复位、换实例/版本、换页、隐藏及卸载完整恢复。
- 查看变形与模拟运行互斥，进入透视/爆炸前结束模拟并复位；恢复实体后须用户明确重新开始模拟。任何模式不保存场景或源模型，不改变设备控制与工程事实。

## 2026-10-30 隔离与报警定位修正

- 构件定位先用当前固定配置及模型元数据预览，工程上下文和场景定位并行复核；未核对完标记“核对中”，确认两者的对象、版本、项目、固定实例全部一致后显示“已定位”，不一致则撤销预览；切换和退出取消旧请求。构件镜头过渡300ms，普通场景仍900ms。仅切换隔离不重播镜头；已加载几何立即响应，后台核对的同一目标不重播。驾驶舱部件镜头保留周边装配空间。
- 隔离保留所选实例的上下文：目标高亮，壳体透明度为原材质的11%，其余为20%，保持原隐藏状态；复位还原原材质，实例之间不共享修改。透明遮挡不抢占目标拾取。
- 首页“演练设备”选择具体已安装、可见且在场景中唯一的实例，默认优先地理场景中的首项。所有模拟案例均在该演练设备上按采纳定义的RDS柜体角色解析，复发案例保持同一安装目标；只是本会话演练关联，不写入工程事实或模拟来源本身。
- 报警卡显示安装设备名称；点击经场景准备与地球过渡，进入指定场景/风机/柜体并隔离，显示简短模拟事件条。无法唯一匹配、隐藏表示、修订变化均不猜测目标；定位前复核卡片中的柜体版本。回放详情及案例分析仍使用固定模拟数据集；设备分析使用所选安装对象，两者不伪装为现场测点证据。
- 返回项目资产时，新动画从当前时刻开始，不叠加页面离开时长；已存在动画在后台暂停后按实际挂起时长恢复。动画进度限制0–1，结束帧主动交接到自转循环，不依赖镜头变化事件再次触发；自转保留0.6度/秒与恢复缓入。
- 无新增后端API、数据库或OntoBase写入。最终577项检查、候选三档缩放与正常账号公网验收通过，含返回后的持续缓转；见[执行记录§152](../plans/开发执行记录.md#152-半透明隔离报警定位与地球返回修复2026-10-30)。


## 2026-10-31 地球自转提速

按用户要求，自转从0.6度/秒提高3倍至1.8度/秒（稳定后约200秒一圈），取代前述速度。1.4秒恢复缓入、操作后4.5秒等待、帧间隔100ms封顶、暂停/减少动态及切页重置保持；不加速飞入动画或鼠标手动旋转。

## 2026-10-31 地球点位随缩放动态聚合与展开

- 球面聚合阈值按当前相机距离与视口高度换算（默认屏幕间距40px），且组内任意两景之间的球面夹角均不超过当前阈值，避免链式漂移把远距离场景并入同一组。单纯地球自转不改变聚合阈值。
- 远景密集区域显示场景数量标记；点击跨坐标的区域聚合点时，镜头自动飞向该区域并拉近到拆分距离，使各不同坐标的场景在地球上独立展开显示名称；“恢复地球视角”回到全局全览并重新聚合。
- 保留真实场景地理锚点，不通过移动坐标分开重叠标签。相同或极近参考坐标的多个场景（如复用同一参考锚点的场景）在近景下显示组合标签（如`名称 +N`），点击后打开可选场景清单进入目标场景。
