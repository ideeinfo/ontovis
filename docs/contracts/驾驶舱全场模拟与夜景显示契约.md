# 驾驶舱全场模拟与夜景显示契约

2026-10-30。承接用户“所有场景模型加载即模拟、保留夜空并补光、提高隔离周边构件可见度”的要求。实现位置为 ONTOVis 前端；发布与验收状态以工作区交接和开发执行记录为准。

## 全场模拟

- 所有场景复用统一会话偏好，首次进入默认“均衡运行”。只运行当前可见场景，模型加载后自动开始，无需逐台点击。
- 每个实例按稳定身份生成转速、叶轮初始相位和偏航偏移。已核验动作的型号使用各自预设范围；三角形等静态模型分配静态预设。未知固定内容不猜测旋转部件。
- 当前场景使用的 TU-3000 和十种其他型号已有固定内容适配。动作只改变当前模型副本：叶轮绕源轴心转动，偏航带动机舱与叶轮，塔筒、基础保持原位。其他实例及共享源资源不变。
- 适配同时核对内容指纹、版本、校准和源节点结构。轴心来自源模型零位，不能用不对称轮毂包围盒中心替代。
- 显示设置 → 演示提供“均衡运行 / 低速展示 / 停机展示”、暂停全场、恢复预设；当前模型转速、偏航和轴线在折叠微调内。切换场景继续采用统一预设，恢复预设清除本会话微调。
- 构件及报警定位继续播放所选模型的模拟。固定安装身份和服务端零位包围盒用于核对，镜头和定位框使用当前模型副本的显示包围盒；不把模拟后的姿态写成工程位置。透视和爆炸查看仍使用静态姿态，退出后继续模拟。
- 隐藏页面、暂停及系统“减少动态”不追赶错过的时间。每秒刷新本机模拟样本，过期或异常冻结，轴向变化按时间而非帧数计算。
- 模拟转速不来自天气风速，不表示现场遥测，也不写入场景、工程对象或设备控制。界面保留简短“模拟”标识，详细说明按需展开。

## 夜景与隔离

- 晴夜等有效夜间预报保留夜空。深蓝天空与地平线分别为 #070e23 / #25344f，星点固定、稀疏并随云量减弱；星点仅用于展示，不表示实际天文位置。
- 中性偏冷环境光和观察方向补光提高设备辨识度，保留模型自身材质；夜间云层同步降低亮度。
- 陆地延伸层夜间改为 #1b2639 并参与同一色调映射，去除日间浅绿色带。原地形、贴地依据、经纬度、模型和影像文件不改。
- 夜景中影像使用临时受光显示，恢复场景或白天偏好后恢复相应显示。显示设置增加“夜景补光”，可独立选择；这些偏好不保存为场景环境。
- 构件隔离时，周边外壳不透明度为原值 × 0.32，其他构件为原值 × 0.50；所选构件保持高亮。保留原透明度和隐藏状态，退出后准确还原。

## 验收边界

自动化覆盖稳定预设、全场请求、可见性、单台微调、停止、模型副本隔离、十型号源轴心、塔筒静止、失效冻结、复位、夜景临时配置及隔离材质恢复。实际 GLB 离线检查只核验几何与恢复，纹理展示另由候选浏览器验收；不把这些检查记为制造商工程轴向确认或全部硬件性能结论。

## 设备页定位修正（2026-10-30）

承接用户设备页模拟、视角与地形遮挡反馈。整机和构件主动定位保持当前水平朝向，使用适中的俯视角，校验镜头与目标之间的原地形，避免从地下或穿过山坡看设备；不修改已保存的场景默认视角。影像先于透明装配绘制，保留真实地形深度检测，使半透明构件与地形保持正常前后关系。底部原模拟入口直接显示当前模型的运行或暂停状态，详情继续按需打开。
