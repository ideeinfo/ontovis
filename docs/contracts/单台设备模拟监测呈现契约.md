# 单台设备模拟监测呈现契约

2026-10-29，Q-18模拟设备呈现首切。前置为[模拟流订阅](模拟流订阅与恢复契约.md)和已接续的设备库/固定项目采用/共享构件绑定。真实监测映射、场景动态样式和项目呈现策略仍沿Q-18/Q-22继续，不将本首切算作真实源验收。

## 入口和数据边界

设备层级的项目设备详情新增“模拟监测”页签，默认不订阅。用户选定一台设备、一个模拟故障后明确开始演练；页面持续标记模拟，所选单台设备UID与共享资料对象分列。不同设备、项目、页签或绑定查看之间切换均停止旧流，不能把同一事件自动扩散给其他同型号设备。

当前来源仅Demo-PDS既有13001—13004及复发。源profile的柜级规范位号通过本台固定项目应用中的共享定义匹配，再通过已登记sourceTemplateEntityUid找到本台真实关键子设备；同时要求项目、整机身份、安装范围与层级修订一致，匹配唯一。不得按设备显示名称拼接身份、复制1133个工程对象，或把共享定义UID当作单台设备UID。缺采用、缺映射、歧义或角色不符时准确显示未建立此演练目标，不猜对象或更改源数据。

## 展示和操作

显示模拟来源、选定安装目标、共享工程位号、源日期与时钟、原始报警状态、质量和最后数据是否过期。内部设备列表只有本次明确目标显示模拟告警，其余显示无此模拟数据；整机仅汇总该可见模拟事件，不能标为整机确诊故障。坏质量值为null，未发生和已恢复分别处理，断线不继续推演。

开始默认从第60秒，支持停止、继续和重新演练；沿用Q-17去重/补数/授权/连接限额。点击“定位构件”重新读取本台子设备和固定采用后进入现有构件绑定查看器，由共享映射选择对应柜体，保持原几何精度标记；不保存映射、不自动修改相机或场景。离开监测页停止连接，固定分析与工单不受实时数据改写。

该操作只是本次查看的模拟投射，不创建正式测点映射、设备、工程事实或配置修订，也不写源系统。正式现场数据仍以源连接、单台设备/角色与测点键的版本化映射接入，留Q-16/18/22；不能把这次演练选择作为实际SCADA配置。

## 验收

覆盖根设备及其CN1、其他柜体/型号无匹配、重复定义和跨安装范围、固定采用/层级变化、同型号4号与7号互不串台、告警和恢复、质量断点、停止/补数/离开取消，以及正常账号从单台子设备进入共享构件定位。只读查看不增加业务修订，原12台场景布置和15/16/18预留保持。
