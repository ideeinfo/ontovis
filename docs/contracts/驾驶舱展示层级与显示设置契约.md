# 驾驶舱展示层级与显示设置契约

版本：2026-10-30，承接用户对生产驾驶舱八张截图的反馈。实施范围为展示层与会话偏好；复用既有项目、设备、资料、天气和分析服务，无新增服务接口或数据表。

## 1. 主屏与详情分层

- 以1920×1080为设计基准，沿用深浅灰绿主题、原Logo、13px正文与11px辅助文本。主屏面板使用半透明底色、细边框、圆角及柔和阴影；预留三维内容空间。
- 资产页：摘要与场景卡；场景卡两行名称、类型和设备/表示数量。按面板实际高度计算每页容量，用上下按钮换页。搜索改变后回第一页，不截断数据集合。名称完整内容可由进入场景后的详情读取。
- 场景页：左侧场景摘要、两项统计、简短预报及设备入口；右侧告警入口与独立图层卡。移除常驻描述段落和整棵实例列表。浏览设备在独立分页窗口完成，保留单模型可见性开关。
- 设备页：左侧只展示当前对象直接下级，逐层进入并可返回上级；长层级分页。右侧保留对象摘要、图纸与资料、设备参数、对象详情及分析入口。身份、几何精度、完整型号等在详情读取。无独立几何绑定的子对象保留“所属设备示意”标识，不虚构构件定位。
- 设备资料预览和参数使用现有完整查看器。主屏不堆叠资料内容、身份UUID或来源说明。真实模型预览缺失时使用对象图标，不用设计素材冒充真实工程模型。
- 实体/透视/爆炸示意位于三维视图底部。模拟参数移至显示设置，原固定内容适配、零位/最短路径/质量冻结及退出复位规则保持。轴线默认关闭，可显式开启。
- 分析工作台恢复其原生列表样式与上下翻页按钮；列表滚动条隐藏，但键盘和滚轮仍可用。原画布编辑、固定资料及未保存保护保持。

主屏避免滚动条；尺寸不足时设备面板切换为“结构 / 资料”单面板。完整资料和长文本详情仍保留必要的可访问滚动，不缩减资料内容。页面不以删除数据或伪造计数实现简化。

## 2. 显示设置

| 分类 | 控件 | 实际行为 |
| --- | --- | --- |
| 显示 | 自动、100%、150%、200% | 调整驾驶舱文字与面板，沿用CSS可用空间规则；三维镜头、画布缩放、照片原像素独立 |
| 显示 | 深色 / 浅色 | 复用现有主题偏好，不改变场景时间或天气 |
| 显示 | 暂停可视化 | 暂停流云、水纹、降雨/降雪和模拟动作；仍可操作镜头及导航；不发送设备控制 |
| 显示 | 全屏、恢复自动缩放 | 浏览器全屏；仅将界面缩放恢复自动 |
| 场景 | 跟随场景/预报、白天、黄昏 | 临时光照覆盖；原场景水面、地形、模型与保存环境保持 |
| 场景 | 按有效预报、关闭特效、晴/多云/雨/雪/雾演示 | 有效预报驱动原天气视觉；手动模式持续显示“天气演示”，预报卡仍显示真实接口预报 |
| 场景 | 设备模型、地形、影像 | 当前视图图层开关，与保存场景独立；无影像时不可开启 |
| 演示 | 模拟转速、偏航、开始/暂停/复位 | 仅对支持的固定教学模型；仍标明模拟，天气不推导转速 |
| 演示 | 轴线和质量演练 | 明确进入高级核验后操作；不影响真实数据质量或权限 |

MagicPath中的权限失败、读取失败为设计状态预演，不作为生产用户可修改的权限或业务状态。生产应用不提供伪装真实权限/报警的开关。

## 3. 必要标识与来源

主屏保留简短的“预报”“模拟”“模型示意”“身份未绑定/精度未核实”等状态。失效天气不展示为当前有效值；真实报警未接入不显示为零告警或正常。首页统计使用“报警”，数字与文字按主题以橙色高亮，计数沿用当前固定回放来源，右侧回放及详情保留来源上下文。来源时间、位置说明、几何范围与长提示放入详情。MET Norway / CC BY 4.0署名保留在天气摘要；地球与影像的完整署名及说明集中到右上角“数据与来源”，主屏取消常驻来源长条。

## 4. 验收范围

自动检查：分页完整性/筛选收缩、环境覆盖不可变性、天气与手动光照边界，及已有前端类型、构建、回归。

真实浏览器：夏李场景资产分页、设备实例选择、层级进入/返回、设备资料与参数、模拟运行、有效预报与手动天气、主题/缩放、图层/暂停、分析列表与返回空间；检查主屏无滚动条及无不可达操作。

发布、备份恢复、实际截图和已知边界记录在[本批交付](../../output/cockpit-display-20261030/README.md)。设计源维持[原MagicPath项目](../design/MagicPath交互设计.md)。物理4K屏与真实遥测不属于本次新增验收结论。

## 5. 场景容量与结构交叉定位补充（2026-10-30）

- 资产左栏至少显示3个场景（总数不足时显示实际数量），设备结构至少5条；余项上下分页。按可用高度调整卡片/行高，紧凑模式隐藏重复摘要，完整名称在标题提示和详情可读。点击结构名称不钻入层级；有实际下级时才显示独立箭头。
- 首次进入场景，按可见资产在平面的中位位置选中心资产，取最近3个资产构成到达视角，降低俯视角；隐藏资产不参与。已有会话镜头书签优先保留，“显示全部”仍为全场总览。该视点选择不改场景保存数据。
- 结构名称点击后按所选安装身份及固定模型请求既有定位服务，成功后定位并隔离；“显示全部”恢复，定位按钮可再次聚焦。无独立几何时保留所选工程身份，仅显示“所属设备”；缺失/歧义/错误不猜测模型构件。
- 模型反选只接受当前实例、固定模型和唯一构件绑定，选择列表中相应对象并翻到所在页。动态共享映射只用于当前场景修订，并严格匹配源端当前采用的应用/应用修订/规格修订和安装对象的模板UID；历史场景仍按已保存绑定。
- 点击工程结构时结束模拟和内部查看，恢复固定模型后定位；隔离只克隆当前实例材质，不改缓存、源模型、场景可见性或工程数据。切换设备、页面及销毁时释放临时材质。
- 工作台新增“接续采用修订”：确认同应用、根对象及全部已映射定义UID/修订一致，复制原模型与映射到新采用的独立配置。旧配置及历史完整保留。仍由原后端校验权限、源端固定引用、定义/模型、唯一应用绑定、并发和请求幂等；没有新增接口或放宽旧配置固定引用规则。
