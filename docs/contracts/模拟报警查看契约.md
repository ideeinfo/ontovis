# 模拟报警查看契约

2026-10-26。补齐固定模拟源上线后的正常查看入口；上一批仅提供来源/分析接口，工作台“数据与告警”仍按未实现而禁用。当前范围为项目内只读回放，不计作实时SSE、源端确认或整项Q-17/18完成。

## 页面与操作

1. 登录默认项目中心，未进入项目时仅项目中心、模型中心可用。进入某个项目后启用“数据与告警”，顶栏为“数据与告警 - 项目名”。
2. Demo-PDS显示13001、13002、13003、13004四个既有模拟数据集。列表按现有共用选中、更多和右键菜单；按故障码/名称搜索，不接真实源时不显示“0条真实报警”。
3. 选择数据集读取固定修订。三分钟窗口用明确日期和UTC+8展示，默认暂停在第60秒，可播放/暂停及拖动时间轴；未发生/报警中/已恢复取自源事件时间，不取当前墙钟，不写工单状态。
4. 趋势显示传感器及独立参照温度、状态反馈、供电和过流。坏质量值显示警示色“质量异常”，曲线断开，不填0或插值。温度以°C显示，保留源单位degC；无量纲状态不附单位1。
5. 生命周期显示发生/恢复时间、原严重性与事件版本。“测试预设与来源”按需展开，保留来源修订、预设原因和证据缺口；模拟回放持续标识，不确认现场根因。
6. “相关工单”进入当前项目既有工单并按故障码检索；不创建或变更工单，不自动启动诊断/分析。完整画布资料卡和工单固定分析入口继续Q-23。
7. 其他有权项目可进入本模块，明确显示该项目尚未配置报警来源；不能显示Demo-PDS数据，也不能因为查看而建立空项目空间。源不可用、版本变化、项目撤权及请求迟到时清理旧数据；语言、双主题与窄屏遵循既有工作台。

## 只读接口

沿用当前会话、expectedSessionRevision和完整projectRef；当前项目活跃成员可读，不需要分析owner或创建分析。以下路径在Nginx和服务端均精确匹配，请求16KiB；多余路径不开放。

| 路径 | 业务参数 | 返回 |
| --- | --- | --- |
| /api/workbench/analysis-sessions/simulation/catalogue | 无 | 当前项目可用的固定模拟数据集；非Demo-PDS返回SIMULATION_PROJECT_REQUIRED |
| /api/workbench/analysis-sessions/simulation/detail | datasetId、datasetRevision | 固定数据集、发生/恢复事件及可用指标的完整三分钟趋势 |

detail拒绝额外字段和错误修订，授权仅来自当前源主体/项目。读取不创建分析、来源句柄、工单快照或项目空间，不进行照片资格核验，不重复拉取工程资料。原分析权限和来源登记边界保持。数据内容、正负例及来源身份沿用[来源与模拟故障契约](分析来源与模拟故障契约.md)。
