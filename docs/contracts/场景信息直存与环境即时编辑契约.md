# 场景信息直存与环境即时编辑契约

2026-10-30，承接用户要求；沿用既有场景修订、权限和保存接口，无数据迁移。

- 场景列表的“基本信息”只读取所选场景配置并打开表单，不进入三维场景、不下载模型。名称和说明在弹窗中直接保存；成功留在列表并刷新该场景信息。取消不写入。
- 列表保存只改变名称/说明，保留保存视角、环境、坐标、实例、资源和关联。场景页内的基本信息也提供直接“保存”，合并当前场景草稿并按既有规则保存当前视角；不再先“应用”再保存。
- 保存以读取时的场景/生命周期修订为条件，沿用后端权限和工程复核。冲突保留输入并要求重新读取；不得静默覆盖或自动确认变化的工程关联。回执不明时锁定输入、重试同一冻结请求与幂等编号。
- 环境参数在布置模式修改，合法参数即时进入场景草稿和视口，直接标记未保存。移除“采用环境”“取消预览”及预览状态；顶部保存持久化，撤销/重做与未保存离开提醒沿用场景规则。
- 无效数值保留输入并阻止保存；雾终点不大于起点时保留最后合法画面，修正后一次进入草稿。不以校验失败值覆盖已保存配置。
- 预设及默认播放改变时按新默认更新对应水纹/流云，其他参数修改保留个人播放选择。系统减少动态、后台暂停和渲染预算保持；个人播放状态不保存。
- 选择“原有显示”立即写入草稿的显式environment:null，保存后生效。旧场景读取时不补字段、不新增修订。
- 资源采用、地理锚定和模型/地形换版仍保留各自的工程预检与确认，不由本次交互简化取消。

设计预演在原MagicPath工作台维护；实际候选副本验证持久化、公网只读复核，禁止将验收名称和环境写入正式场景。
