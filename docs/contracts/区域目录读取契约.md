# 区域风电目录读取契约

驾驶舱的项目资产页提供区域目录入口，首批包含有来源署名的欧洲海上风场和英国风电规划观测。名称、状态和容量按各自来源展示。地图定位仅使用有可核对经纬度的源点。源边界及未核实格网的记录仍可检索及查看出处。项目场景继续使用经授权的既有场景入口。区域首批没有核准的目录观测与工程项目关联。

`POST /api/workbench/regional-catalog` 沿用当前项目及会话校验。初次查询包含检索条件及分页参数。翻页和查看详情携带同一目录版本。批次切换返回 409，界面允许从新批次首页重新读取。详情可查看原边界范围。响应只包含投影清单内的公开字段。浏览器无需访问外部数据源。

首批以经过校验的只读目录快照交付。运维将完整批次构建为固定清单，再原子切换当前摘要指针。回滚切回已有批次。失败采集不改变当前指针。正式全球批次、跨源归并、工程项目映射和英国格网转经纬度在各自依据齐备后扩展。

采集保留源文件及 SHA-256。REPD 同编号两行的全部字段一致时，归入一条观测，并在采集清单记录重复编号。有任何字段冲突时整批不发布。发布包只含查询所需的字段和来源声明。首次发布保留校验过的 7 月批次用于回退。建设、激活及回退分别使用 `python -m tools.publish_regional_catalog build`、`activate`、`rollback`。回退按批次摘要验证内容，列表和详情通过同一版本确认分页。服务器的正常项目读权限适用于这三类前端操作。
