# 模型删除与恢复契约

2026-10-26。用户要求模型允许删除。本切片对整个共享模型资源提供可恢复删除，包含其全部固定版本；没有永久清理或单独删除历史版本的入口。

## 行为与已有场景

删除后，模型从正常目录及可新增使用的资源中移除，模型回收站可预览及恢复。模型文件、固定版本、校准、属性证据、缩略图和场景引用保留；删除不释放已保留文件的存储配额，不改写OntoBase对象。已有场景及历史仍能读取，已有实例可继续调整、保存；删除的模型不能用于新增实例、复制出新实例或替换为另一个已删除版本。恢复后可重新选用原固定版本。

场景保存以“实例ID＋固定模型版本”为既有引用基准。检查和保存预读拒绝已删除资源的新引用；最终保存阶段在已有SQLite写事务中复核，并与共享模型生命周期写入共用同一进程锁，避免校验后删除的竞态。GIS准备在锁外，已有固定内容摘要和几何校验保持。当前仍为单进程服务，不将此锁视为跨进程实现。

## 接口与权限

沿用同源POST及expectedSessionRevision：

- `/api/workbench/resources/models`增加state：active（默认）或deleted；分页游标绑定状态、筛选、主体、授权和库修订。
- `/api/workbench/resources/model/delete`及`/restore`严格接收modelAssetId、modelVersionId、expectedAssetRevision、expectedLifecycleRevision、clientRequestId。modelVersionId须属于指定资源，操作范围仍为整个资源。
- 返回modelAssetId/modelVersionId、assetState、assetRevision、lifecycleRevision、libraryRevision和changedAt，附原会话/能力/限额。
- 资源能力增加modelLifecycleWriteVersion=1与canDeleteModels。沿用共享模型维护权限，即当前至少一个源项目的管理员；只读身份可读取正常/回收站目录和受保护固定内容，不能删除、恢复或业务编辑。每次写入和回执重放仍重新核对当前身份与维护授权。

assetState与版本的ready状态分列。原资源默认为active、生命周期版本0。assetRevision及生命周期版本都须匹配；每次删除/恢复同时推进资源修订、生命周期版本及库修订，防止恢复后的旧页再次删除。模型正在更新或版本条件过期返回409；新增使用已删除模型返回410/MODEL_DELETED，提供恢复提示。客户端未知结果重试沿用同一requestId，回执表示该次操作结果，随后重新读取目录。

新增project_model_lifecycle表及身份/修订约束。状态、资源头、目录版本、审计和幂等回执同一SQLite事务提交，提交前重新授权，失败完整回滚。固定版本表和文件不删除。已删除资源不能新增信息、属性证据、校准或追加文件版本；历史成功回执仍可受控重放，受保护读取及缩略图缓存保持。

HTTP与Nginx只开放两条有界路径，沿用16KiB小请求上限、Origin与会话校验；多余路径、尾斜线和purge不开放。前端写权限拒绝保留只读登录状态。

## 页面与验收

模型卡片、列表及资源面板使用既有“更多/右键→移至回收站”，确认说明完整资源及版本数；模型回收站提供预览和恢复。预览已删除资源时关闭业务编辑、校准、替换和放置入口。选择、筛选、分页和迟到响应沿用取消机制；场景、模型列表、全局/项目导航规范保持。

覆盖全部版本和字节保留、旧场景读取/保存、跨项目新引用拒绝、校验后删除竞态、权限撤销、事务回滚、并发冲突、旧页/幂等重放、分页状态及备份恢复。实际浏览器只操作新建且明确标注的合成验收模型，不删除用户既有资源。发布前后沿用包含PG登记/分析与所有SQLite/文件的整组备份，恢复到新库、新目录并由运行账户消费。产生删除状态后，不能回退到忽略该状态的旧代码。
