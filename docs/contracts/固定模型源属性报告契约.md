# 固定模型源属性报告契约

Q-09 · 2026-10-25后端基线，2026-10-30增加产品只读报告首切。承接[本机源身份核验](../plans/模型属性与源身份核验切片.md)，在已有共享固定模型上增加只读报告。§4保留原后端验收阶段，产品页面范围见§5；实际部署与正常账号验收以[执行记录](../plans/开发执行记录.md)最新检查点为准。

## 1. 固定输入与授权

同源 `POST /api/workbench/resources/model/inspection`，JSON 请求固定包含：

| 字段 | 条件 |
|---|---|
| `expectedSessionRevision` | 当前 HttpOnly 会话修订，沿用原会话入口 |
| `modelVersionId` | 已保留的共享资源固定版本 UUID；不读取任意文件路径 |
| `expectedContentRevision` | 该固定版本的内容修订 |
| `expectedSha256` | 该固定 GLB 的 64 位小写 SHA256 |

不接受路径、URL、处理命令、额外选项或查询参数。沿用 Host/Origin、POST、16 KiB 请求、JSON 严格解析和 no-store。旧客户端附带合法同连接 projectRef 时，继续按[共享模型契约](共享模型资源与项目边界契约.md)校验连接并移除，不以项目筛选模型。

当前有效账号均可读取共享模型，包括普通成员和无项目用户；维护权限不因报告读取而增加。项目撤权仍阻断该项目场景和工程数据；有效身份仍可读取共享模型。账号停用、退出、会话改变或源身份核实失败时拒绝报告。旧单项目 WorkbenchSessions 的读取继续遵守原项目授权。

处理前后复核当前身份、固定内容修订、SHA及实际文件。报告只读取已有保留 GLB，不新建模型版本、场景、绑定、数据库表、任务记录、审计或报告缓存。输入文件仅由后端根据受核验的版本ID定位；不访问属性中的URI、不执行属性内容。

## 2. 输出与语义

普通资源响应继续带 sessionRevision、capabilities 和 limits，新增报告主体：

| 字段 | 含义 |
|---|---|
| `schemaVersion:1` / `profileVersion:"source-nodes-v1"` | 固定的源文件报告格式与处理范围 |
| `processorSha256` | model_inspection、model_validation、model_probe三份源码摘要的确定性合成指纹 |
| `modelVersionId/contentRevision/sha256` | 本次核验的固定版本与原 GLB |
| `scope:"fixed_glb_source_local_only"` | 原GLB局部坐标及来源声明，不是场景或工程安装结果 |
| `sourceValidation` | 按既有上传规则重新核验得到的技术摘要；单独表示原GLB的坐标未核实 |
| `sourceNodes` | 全部声明节点的版本内键、原名称、原始extras、是否存在extras、活动场景状态、原身份声明与诊断 |
| `sourceIdentityStates` | missing/incomplete/invalid/unverified_claim/collision的实际计数 |
| `catalogSha256` | 按既有离线components.json的`{"source":...}`、UTF-8/两空格缩进/末尾换行格式计算的实际SHA |

`sourceNodes`沿用原核验目录，包含默认场景之外的节点。`componentKey = 文件SHA:node:节点号`，`keyStability=version_local`；不替换原上传分组的`component:*`键，不改绑定或三维拾取映射。节点号、名称、旧ObjectID、相邻位置和完整/外观两种表示均不补作跨版本工程身份。

属性保持原JSON类型、大小写、空白、显式null及字段缺失区别；extras中的自报“已核实”不生效。完整三元组仍为未核实声明，同文件重复（包括非活动节点）列冲突。来源URI只作为文本，不触发资源加载；后续界面按文本显示，不执行HTML或脚本。

响应中的sourceIdentityVerified、geometryCorrespondenceVerified、bindingMigrationApproved、releaseReadiness.eligible及G2Passed始终为false。校准版本仍保留原操作员校准及原报告；本次sourceValidation的unverified只描述原GLB局部坐标，不撤销或重新批准校准。模型层级不解释为工程物理层级。

## 3. 隔离与错误

复用现有上传校验，单份20 MiB、JSON 2 MiB、节点至多2000、原纹理/几何预算及未支持格式拒绝保持。独立Python工作进程采用CPU 6秒、Linux地址空间192 MiB、总墙钟12秒、输出4 MiB预算，主进程读取输出时同步限制字节数。报告与上传/校准复用同一模型处理名额，忙时返回429/MODEL_BUSY，不另建队列或通用任务服务。

主进程退出会关闭保持打开的输入管道，工作者收到EOF退出；超时或输出超限时主进程终止并回收工作者。该同步只读请求不持久化进度；退出或撤权后的迟到结果拒绝返回。源文件、输出指纹或处理器不一致时不能以旧报告冒充当前结果。

| 状态 | 主要错误 |
|---|---|
| 401 / 403 | 会话失效、当前授权拒绝；401按原规则清理身份 |
| 404 | 固定资源不存在或不属于可读取的资源范围 |
| 409 | RESOURCE_CHANGED或原会话修订冲突 |
| 413 / 422 | 请求大小/格式错误，或INVALID_MODEL、UNSUPPORTED_MODEL、MODEL_LIMIT_EXCEEDED |
| 429 | MODEL_BUSY |
| 502 / 503 | MODEL_INSPECTION_UNAVAILABLE或MODEL_STORAGE_UNAVAILABLE；不返回路径、属性或部分报告 |

## 5. 产品只读报告首切（2026-10-30，实施基线）

承接截至照片缩放修复db0eef6的应用与上述既有接口。本批补共享模型固定版本的报告入口，不改变处理器、上传/校准、模型构件键或工程绑定。

- 模型中心及场景资源的模型属性区提供“源属性报告”，明确点击后才读取。关闭、切换固定版本、离开或会话失效时取消等待并清理结果；再次打开重新检查当前权限，不缓存报告到浏览器持久存储。
- 标题显示模型名称，版本标识、文件/目录/处理器摘要按需展开。原校准状态与源文件局部坐标核验分开，报告读取不撤销校准。成功提示仍明确源身份、几何对应及工程用途未经核实。
- 按实际返回汇总五类身份声明状态；搜索原节点名/节点号/声明值，筛选声明状态及默认场景内外。显示匹配数与总数，列表每次50项，空结果可清除筛选；不借节点名或旧ObjectID补齐身份。
- 选择节点显示版本内编号、活动场景、声明诊断及原始extras。JSON保留字符串/数字/布尔/null/数组/对象，缺失extras单独显示；原内容仅作转义文本，不执行HTML、脚本或链接。完整长值可滚动阅读，不静默截断或假称已核实。
- 窄屏列表和属性纵向排列，正文13px、说明11px，长名称换行；中英文、键盘及关闭返回原选择沿用现有控件。
- 加载允许关闭；版本冲突提示重新选择原固定版本，忙碌/失败允许显式重试，不自动轮询或重试。401/403沿用现有身份清理。浏览器关闭只取消等待，不宣称已终止服务器有界工作进程。

验收包括固定请求/响应身份匹配、取消和迟到结果、状态计数/分页、非活动重复声明、缺失与null区别、危险文本转义、宽窄屏/中英文及正常账号只读读取。合成模型覆盖真实资源没有的身份正反例。实际测试站版本、MagicPath修订和结果随后记入执行记录；旧节中的部署状态仅代表2026-10-25当时阶段。
