# 分析推荐与关系依据

2026-11-02更新。适用于当前分析画布；推荐表示值得查看的资料，关系表示记录中存在的关联或明确标记的候选依据。两者均不自动确认故障原因、现场身份或分析结论。

## 统一相关性顺序（2026-11-02）

工程对象卡的“推荐相关资料”统一进入“相关资料”，安装设备和共享定义使用同一入口。以明确选中的对象UID及修订为先；未选对象时使用当前报警配置的主对象。类型切换沿用这一范围，搜索工程对象及“本项目文档库”则是明确的项目目录检索。读不到所选对象时阻断，不悄悄改回其他对象。

| 顺序 | 推荐依据 | 显示与约束 |
| --- | --- | --- |
| 1 | 本设备现场照片 | 只限实际安装上下文；不把共享定义当作单台现场 |
| 2 | 本对象已有图纸关联、定位照片，或其保留的共享定义关联 | 同级图纸与照片交替取项，保留原引用、版本和区域 |
| 3 | 当前故障码的已发布知识证据 | 固定手册版本、知识节点与页码；不能当作现场根因 |
| 4 | 已登记下级对象的图纸、本对象及成员的共享照片 | 明示“下级对象”或“共享照片”，默认整页/整图，不借用成员框宣称柜体区域 |
| 5 | 已选安装设备的型号和角色适用资料 | 由OntoBase现有解析接口给出；不是按名称猜测适用性 |

相关资料综合入口合并图纸、照片与PDF；图纸/照片/文档分类复用同一依据顺序，只读取对应来源。三维模型单列，继续“有效绑定→历史绑定→名称候选”的服务端排序，名称相似不升级为绑定。显式文档名称搜索可在相关来源之后补项目目录，单独标明“目录检索”。“本项目文档库”保留源端目录顺序，不宣称对尚未读取的全库做了语义排序。

当前事件/趋势优先本次固定数据集；同码独立事件保留自己的身份和时间窗。工单先当前工单，再同故障码；同级按更新时间及稳定标识排序，切页校验原工单快照。工单没有可靠设备UID，不能仅凭柜名标成“同设备”。历史分析只列本人当前可读、同连接/项目/故障码的有效画布，先同事件及数据集修订，再同对象、同分支及更新时间；空事件字段不置顶。驾驶舱沿用此候选顺序，仍只读查看，不自动编辑或导入。

推荐行使用简短依据标签和具体来源说明，不展示伪造的百分比、因果判断或现场确认。相同固定照片版本合并，保留更直接的可用定位引用；相同固定文档页保留更强依据。不同版本、不同页码或只是同名的资料不合并。跨页合并在当前面板完成，不改源端关联或已有卡片。

### 分页、权限与缺口

- 每页最多12项，先消耗更强依据，再进入下一层；同级图纸/照片交替，避免一种资料占满前页。没有一次性读取完整资料库。
- 单次最多进行8次分来源分页读取，同一来源最多2页；知识页、对象身份及授权核验仍使用各自现有有界读取，此数字不是全部HTTP请求数。直关联证据沿用原20条上限，超限明确记录缺口，不能声称已遍历全部来源。
- 续读游标签名并绑定用户、登录修订、连接、项目、报警入口、对象/层级修订、分类及查询词，5分钟有效。不包含凭据或原文；每次续读重新核验来源页，变化后要求刷新。工单另绑定原快照修订。
- 401/403、身份/来源版本变化及失效不作为空结果继续补查；普通来源暂不可用可显示来源缺口，不把“没读到”写成“没有资料”。有后续游标的空批次允许继续读取。
- 推荐是只读动作，不创建证据、保存画布、调用AI或修改OntoBase。点击加入时才沿既有本人证据登记流程，原图纸/照片定位项附推荐时的来源修订，来源已变则拒绝登记。

当前没有实施通用故障因果推理、基于手册自动构造完整排查链，或跨项目无条件推荐。资料来源 API 与模型元数据能够复用，不等于演练诊断规则已经通用。

## 连线与推荐使用相同依据

- **模拟报警对象（实线）**：固定模拟数据集的主位号与卡片对象的项目级主标识匹配。仅接受 RDS/electrical_tag、有效状态和当前项目范围；多个不同 UID 同时匹配时保留缺口，不自动选择。
- **模型构件绑定/模型整体绑定（实线）**：当前项目与连接中的同一对象 UID、固定模型版本，在有效场景内已有未被阻断的绑定。不能用同名对象替代。
- **历史场景绑定（虚线）**：同一对象 UID 的绑定保存在回收站场景，作为历史参考，可定位原构件；不恢复场景，不冒充有效绑定。
- **同名构件候选（虚线）**：没有同一 UID 的绑定，但固定模型的构件名与对象主标识或柜级 RDS 位置段匹配。点击可查看候选位置，并显示候选说明。模型已绑定其他 UID 时另行提示。
- 对象图纸/照片、定义层级、图纸引用、知识节点映射、故障手册连线继续使用已有来源记录；手工关系独立保留。

先加报警再加对象、先加对象再加模型，以及重开已有画布，均重新按当前可读的固定来源计算连线；不为补线修改已保存分析内容或工程数据。展开关系时，明确目标构件优先于保存的旧镜头。

## 范围与性能

模型推荐按选中对象查询，服务端分页每页12条；绑定先筛项目、对象/模型，首批最多100场景/200绑定。已有模型资产处于回收站时不作新增推荐；绑定指向旧固定模型版本时保留该版本。读取超出首批范围、构件缺失、身份不同和历史状态均不自动升级为有效关系。

关系计算只读取当前最多50张资料卡的固定来源，模型名称索引按版本复用，模拟报警连线复用已经读取的对象，不增加逐对象身份网络请求。现有会话、项目成员、来源权限与版本检查继续执行；不新增数据库表、写授权、外部调用或 OntoBase 写入。
