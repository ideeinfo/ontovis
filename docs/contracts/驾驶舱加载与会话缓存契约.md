# 驾驶舱加载与会话缓存

2026-10-31：按用户要求实施，范围为现有读取接口与驾驶舱显示状态，不新增数据保存或服务 API。

- 首次进入资产组合，场景目录与设备目录并行读取。场景名称列表先显示，详情最多三并发逐项补齐；总量未齐时显示等待值，不以零冒充完整统计。点选场景提高其排队优先级。
- 相同本人会话、项目及连接内保留内存目录。重新进入先显示已有内容，同时重新授权读取目录；仅当前目录仍存在且修订完全一致的场景快照可复用。删除及新修订按新目录替换。退出会话、切换项目、权限失效与读取失败清理缓存，不写浏览器持久存储。
- 单独进入资产页不加载隐藏的三维模型、地形和影像；首次进入空间页才初始化查看器。同次驾驶舱查看中返回资产页保留现有查看器资源，避免重复解码。
- 点选即进入场景总览，导航和返回可用。配置未返回显示不定进度；已知资源后显示现有真实准备步骤，包含模型、地形、影像及实际画面提交。不是下载字节或剩余时间估计，不虚构进度。
- 准备期间不操作未就绪设备。可返回资产组合或重新选择；取消、换目标、离开及迟到响应不能恢复旧跳转。失败留在目标页并提供重试和返回。
- 场景缓存不绕过固定版本、内容校验或私有内容权限。三维资源继续由现有受控资源缓存与查看器管理；刷新浏览器仍需首次加载，不承诺全冷或长期容量性能。
