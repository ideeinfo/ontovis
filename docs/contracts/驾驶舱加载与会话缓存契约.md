# 驾驶舱加载与会话缓存

2026-10-31：按用户要求实施，范围为现有读取接口与驾驶舱显示状态，不新增数据保存或服务 API。

- 首次进入资产组合，场景目录与设备目录并行读取。场景名称列表先显示，详情最多三并发逐项补齐；总量未齐时显示等待值，不以零冒充完整统计。点选场景提高其排队优先级。
- 相同本人会话、项目及连接内保留内存目录。重新进入先显示已有内容，同时重新授权读取目录；仅当前目录仍存在且修订完全一致的场景快照可复用。删除及新修订按新目录替换。退出会话、切换项目、权限失效或目录读取失败清理缓存；单场景失败保留明确失败状态，其快照不复用。不写浏览器持久存储。
- 单独进入资产页不加载隐藏的三维模型、地形和影像；首次进入空间页才初始化查看器。同次驾驶舱查看中返回资产页保留现有查看器资源，避免重复解码。
- 点击地球浮层“进入场景”后立即进入场景总览，导航和返回可用。配置未返回显示不定进度；已知资源后显示现有真实准备步骤，包含模型、地形、影像及实际画面提交。不是下载字节或剩余时间估计，不虚构进度。
- 准备期间不操作未就绪设备。可返回资产组合或重新选择；取消、换目标、离开及迟到响应不能恢复旧跳转。失败留在目标页并提供重试和返回。
- 场景缓存不绕过固定版本、内容校验或私有内容权限。三维资源继续由现有受控资源缓存与查看器管理；刷新浏览器仍需首次加载，不承诺全冷或长期容量性能。

相关：[连续空间导航](驾驶舱连续空间与模型查看契约.md)、[展示与设置](驾驶舱展示层级与显示设置契约.md)。正式测量与 MagicPath 修订在执行记录登记。

## 跨场景三维资源复用（2026-11-03）

- 同次项目驾驶舱内切换场景，复用原三维画布、渲染器和固定模型/地形缓存；不再以场景ID与修订作为React卸载键。未使用实例移除并释放独立外观，源几何与材质仍由原资源缓存统一管理。影像继续采用单份活动资源，跨场景可以重新读取。
- 显式场景键仍由场景ID及修订组成。场景变化时清除旧构件定位、相机补间、待处理滚轮、模拟动作与初始聚焦，再采用该场景已有会话视角或保存视角；相同坐标框架修订不代表可以沿用另一场景的相机。模型外观/完整表示切换不改变此场景键。
- 原固定版本、SHA与校准检查、请求代次和会话/权限修订保护保持。退出、项目切换或会话修订变化仍销毁查看器及其缓存。缓存仅在当前会话内，不新增持久缓存、网络上传或生产监控。
