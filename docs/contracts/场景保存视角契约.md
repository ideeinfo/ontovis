# 场景保存视角契约

2026-10-30。沿用既有 `snapshot.initialView.eye / target`、场景保存权限、固定修订及请求幂等，不增加后端字段或接口。

- 普通“保存”在点击时截取当前场景镜头，一并提交为默认视角；旋转、平移、缩放均包含。仅调整镜头时进入“布置”模式即可保存。浏览态单纯移动镜头不产生未保存提醒。
- 保存期间的转动不改变已提交快照；结果不明的重试沿用同一完整请求和请求ID。只有明确结果后才能以新镜头发起下一次保存。
- 资源模型预览、路线播放和环境预览不作为场景默认镜头。锚定/换版的确认仍提交已锁定的空间预检快照；如需调整其默认视角，在确认完成后使用普通保存。
- 场景工作台和驾驶舱首次加载均使用对应修订中保存的默认视角。驾驶舱本会话返回已有场景时保留会话镜头；从报警或设备显式定位仍按具体目标聚焦。
- 保存视角不修改坐标系、地形、影像、模型布置、工程绑定或其他场景。非法或重合的眼点/目标不能提交；历史修订保持原视角。
- 验证覆盖镜头单独保存、内容与镜头同时保存、重开/刷新、驾驶舱首次进入、旧请求重试、资源预览排除和原场景数据保持。
