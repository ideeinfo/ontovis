# 模拟流订阅与恢复契约

2026-10-29，Q-17首切及Q-18连接状态。承接现有固定模拟源与画布接口；本批先实现三分钟模拟源的授权流式传输，不把它称作现场实时数据。实际交付及测试结果写入开发执行记录，本文不代表真实源接入已完成。

## 页面与范围

“数据与告警”保留默认模拟回放。用户点击“订阅模拟流”从当前回放位置开始按1秒节奏接收；订阅期间不能拖动回放时间轴，停止后可重新定位。模式、源时钟和连接状态同时可见，模拟窗口日期保持，不改成当前现场时间。

流状态为连接中、接收中、正在补数、重连中、已停止、演练结束。中断时保留最后已读数据并标记过期，不外推数值或报警恢复；切换项目、会话、数据集或离开页面时取消连接。回放、流式查看均不写工单、分析、设备或源资料。已有画布不因后台更新被改写。

自动重连使用最后成功应用的事件游标，指数退避1、2、4、8、15秒，最多5次；用户可主动重试。超过10分钟的游标、源epoch或固定修订变化需重新订阅，不能偷偷读新源。源权限拒绝清理当前项目数据，瞬时服务异常保留过期数据等待重试。用户停止后再次继续会补齐停止期间已到源水位的样本。

## 服务接口

精确路径为POST `/api/workbench/analysis-sessions/simulation/stream`。沿用同源HttpOnly会话、Origin、`expectedSessionRevision`和完整`projectRef`；禁止URL凭据、任意源地址和额外字段。初次业务参数为`datasetId`、`datasetRevision`、`fromSecond`（0—180整数）；续读参数为相同数据集身份及`cursor`，不与`fromSecond`混用。请求不超过16KiB。

只读项目成员可订阅，开启前核对当前项目访问；本机会话在每次发送前复核，源端成员与访问修订至少每5秒重核。权限改变、过期或源授权服务不可用时停止发送业务数据。每主体最多2条连接、服务共8条，超限429；不占用分析PG连接，不创建项目空间，不自动续期用户活动时间。

响应为UTF-8 `text/event-stream`，`Cache-Control: no-store`、`X-Accel-Buffering: no`及当前`X-Session-Revision`。使用fetch读取POST响应并自行恢复，事件编码遵循[HTML事件流规范](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation)，代理不缓冲的依据见[Nginx文档](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_buffering)。只为此精确路径补充代理规则，不改变其他接口的缓存/超时配置。

## 事件与水位

- `ready`给出固定数据集、epoch、源模式、范围、授权复核间隔及过期阈值。
- 首次`snapshot`返回当前回放位置之前的有界历史、当前报警版本及连续序号；后续`sample`每秒一个序号，含原始质量、源时间、接收时间、原单位、报警变化和传输时间。已知第90秒坏质量必须保留null与断点。
- 序号0—180与固定数据集的秒位置对应；数据事件ID为版本、源时钟锚点及最后序号组成的游标。游标只表达读取位置，不授予任何权限。固定历史可由版本化模拟数据确定性重建，服务重启后仍须本人重新登录，不能复用旧身份。
- 续读按游标计算当前源水位，先按序补齐中断期间的历史，再接收新样本。客户端仅在校验并应用事件后推进游标，重复/旧序号忽略，跳号重新从最后游标恢复，不按到达顺序覆盖较新状态。
- `complete`表示模拟窗口发送完毕，不等于源报警确认、现场消缺或工单关闭。`stream-error`仅给稳定错误码，不返回源正文或令牌。

服务按需读取固定有界日志，不建无限客户端队列；阻塞写超时断开并释放名额。客户端每帧最大256KiB、每连接总量1MiB，最多保留181点/指标；连接静默超过5秒显示过期，超过10秒主动断开重连。所有数据仍为simulated，原严重性、源事件ID、发生/恢复修订和原始质量保持。

## 验收与后续

覆盖完整0—180序号、发生/恢复、坏质量、断线补数、重复/乱序/跳号、错误游标/epoch、慢客户端、有界内存、匿名/项目/会话隔离、权限撤销、上游失败、取消及名额释放；正常浏览器核对模式切换、停止/继续、跨数据集取消和原回放/画布入口。记录首帧及连续事件间隔，不把一次样本当作公网p95。
