# 场景公开数据查询中心契约

2026-10-30，沿用现有公开数据获取 API，无后端或数据结构变更。

- 从场景打开“获取公开地形与影像”，默认中心取当前场景坐标框架的地理锚点，经度在前、纬度在后；地图和输入框使用同一坐标。
- 不用选中设备的坐标、镜头位置、地形文件覆盖中心或其他场景的历史任务替代场景锚点。未配置地理位置的场景保留空输入，由用户指定。
- 经度0、纬度0有效；非有限或超出WGS84范围的配置不带入。有效但超出公开来源覆盖范围时保留原坐标，由现有范围校验阻止获取，不能静默移到另一地区。
- 用户可在表单中修改中心和半径。修改只用于本次查询，不改场景锚点、模型位置或默认视角。关闭后重开，以当前场景重新初始化。
- 读取最近任务时，已完成、失败或取消的旧任务不覆盖新表单，也不冒充当前场景获取结果；已有入库资源仍在资源目录中。
- 正在处理的任务恢复其真实请求范围并锁定输入，不将进行中的获取任务改到新地点。等待其结束或停止后，重开窗口再按当前场景新建获取。初次读取任务期间禁止提交，避免迟到响应覆盖用户输入。
- 新场景有独立资源面板状态；原读取仍受会话、请求序号和取消控制。获取按钮仍沿用后端项目权限、并发限制和幂等保护；没有自动发起地形或影像下载。

本次获取完成后仍需显式采用资源并保存场景；公开影像、DSM和场景参考坐标的精度声明保持。
