## 1. 已实现范围

[analysis_drafts.py](../../apps/api/analysis_drafts.py) 采用专用 PostgreSQL schema `ontovis_analysis_v1`，显式初始化，运行时不建表、不自动降级。与自有项目登记可位于同一个 ONTOVis 独立库；不写 OntoBase 业务库。

| 表 | 内容与限制 |
| --- | --- |
| store_meta | 固定源连接和存储身份；不可覆盖 |
| analysis_sessions | 固定UUID、完整项目范围、owner UUID、名称/过程状态、头修订；身份和所有者不可更改 |
| analysis_revisions | 规范化JSON文本、SHA、操作者、create/save/restore、恢复来源及时间；数据库触发器禁止更新/删除 |
| analysis_requests | 完整项目/主体/requestId、请求摘要、固定操作回执；与修订同事务且不可覆盖 |

只接受人工分析卡、笔记、人工关系和布局；拒绝源卡、工程对象上下文、额外URL/正文/凭据字段。真实来源绑定与逐项权限仍须由后续受控读取实现，不能把浏览器自报身份存成权威证据。保存的前三种状态为分析中、待现场核查、待专家复核；结论确认/归档尚不开放。

调用者必须从可信服务会话提供稳定主体UUID、当前项目角色和授权回调；本候选不接收客户端owner。项目admin只能写自己的草稿；读取也限定本人、连接与项目。每次读写及重放在返回/提交前再检查授权，撤权引发事务回滚。此回调边界已用合成授权测试，**尚不代表真实HTTP和源账号授权联调通过**。

创建产生r1；保存必须命中期望头修订；恢复旧版追加新修订，原内容/摘要保持。相同requestId、相同内容返回原回执；不同内容409；当前已撤权不能重放成功。修订、头指针和回执同一事务提交；并发保存只有一个版本获胜，不覆盖对方。

快照256KiB、50卡/100人工关系、单笔记4000字；每会话最多1000修订、每项目最多1000会话。本隔离候选全库最多10000修订、规范化快照正文合计8MiB，写前串行核对；拒绝超过后无法完整导出的写入，不清理旧版本。该限额是候选验收边界，正式上线前需按实际用量完善容量与归档，不作生产容量承诺。

## 2. 备份与恢复

[analysis_draft_backup.py](../../tools/analysis_draft_backup.py) 负责固定四表导出与新schema恢复：只读一致快照、原JSON文本与SHA、连续修订/头指针、owner/项目/回执/恢复来源一致性；新存储身份，原会话/修订/主体/时间保留。清单和内容显式摘要核对，拒绝已有目标、符号链接、改动内容、缺失版本或回执。独立分析备份不替代完整工作台备份。

[analysis_workbench_backup.py](../../tools/analysis_workbench_backup.py) 已补齐完整配对：

1. 明确停服条件；分析四表持共享表锁，现有工具持本机目录与项目登记占用保护，读取期间阻止写入。活动工作台拒绝备份，不把传入停服标记当作服务已停的唯一证据。
2. 整组包含 `workbench/` 的登记、全部业务库/保留文件，`analysis/` 的全部分析修订，以及顶层清单；核对连接一致，分析项目须已在登记中存在。待准备/阻断项目的既有草稿仍保留，不以不可用状态丢弃数据。
3. 恢复前核对全部子清单/字节/范围；只写全新目录与没有两套目标schema的自有数据库。复用原登记恢复与文件核对，原项目UUID、场景/模型/工单数据不迁义；分析修订/请求回执完整回装。
4. 数据库与文件不能跨系统原子提交。任何中途失败保留已产生的目标供诊断，撤下顶层清单或 `recovery.json`；已存在部分schema也不能重用。成功回执明确 `recovered_not_activated`，不自动启动服务或将其当正式启用许可。
5. 正式消费端仍需绑定已验证恢复身份、当前真实主体与项目权限；没有完成这些接入之前，不将候选写入长期测试库。此切片不是多HTTP进程、分布式任务或在线备份能力。

运维参数只从既有环境变量读数据库连接，命令及回执不打印凭据。候选命令示例（路径需使用操作者实际新建的目标）：

```sh
python -m tools.analysis_workbench_backup snapshot --project-root "$project_root" --library-root "$library_root" --model-root "$model_root" --destination "$new_backup" --service-stopped
python -m tools.analysis_workbench_backup verify --backup "$new_backup" --manifest-sha256 "$manifest_sha256"
python -m tools.analysis_workbench_backup restore-new --backup "$new_backup" --manifest-sha256 "$manifest_sha256" --destination "$new_restore" --service-stopped
```

默认数据库变量 `ONTOVIS_REGISTRY_DSN`；恢复必须由操作者配置为全新自有目标库，不能沿用在线库。无旧模型配对时省略 `--model-root`。不得将旧B0覆盖新写入，也不得复制/伪造登记标记跳过目录身份。
