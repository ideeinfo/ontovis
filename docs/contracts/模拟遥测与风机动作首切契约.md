# 模拟遥测与风机动作首切契约

版本：V1.0，2026-10-30。用户已选择以明确标注的模拟遥测完成动作与轴向验收。本契约冻结 C3-M1 实施范围；真实设备遥测仍未接入。

## 范围与身份

- 驾驶舱设备页提供“模拟运行”面板，默认关闭，仅作用于当前选中的一个场景模型实例；显示完整实例名称、模拟来源和固定模型适配状态。
- 首切支持当前场景 TU-3000 合并版 `fb7963a94988d67a16c5ef08c024b200881df53d4f4e2e2cde27661861d9d9b1`，以及外观版固定内容摘要 `078bbc161a9c9c8cbe0bbc872ca825b6a222d4d4c22f8c16c7889908a97a5806`。名称相同、内容不同的模型不适用。该教学模型不代表夏李设备的实测几何或真实设备参数。
- 同时匹配当前模型版本、内容版本、SHA 与加载器提供的源节点身份。不得用名称或 GLB extras 推断动作节点。绑定对象或子部件的导航不改变作用实例，不把整机模拟值表示为部件实测值。
- 不新增业务持久化配置、后端接口或 OntoBase 写入。此为浏览器会话内的显式演示，未来真实数据接入须另行冻结来源、权限、版本条件与姿态映射契约。

## 几何与运动约定

- 保持模型校准与场景放置矩阵；运动叠加顺序为场景放置 → 模型校准 → 偏航 → 叶轮。
- 原始模型节点 0 为根、1 为静态组、2 为叶轮组。节点 12–14 的机舱壳体与节点 2 同步绕源局部 `[0,90,0]`、`+Y` 轴转动；外观版节点 3–11 的塔筒保持固定。合并版有 184 个节点，节点 12–142 与叶轮组共同偏航，叶轮子节点为 143–175，塔筒节点 3–11、176–183 保持固定。加载器确认的 `proxy:CN1` 示意机舱柜跟随偏航，`proxy:CT` 塔基柜不动，示意身份不变。叶轮绕节点 2 自带枢轴 `[0,90,6.67]` 的局部 `+Z` 转动。
- 偏航输入为“相对模型零位的顺时针偏移”，正值对应源局部 `-Y`；不是相对真北的实测航向。叶轮正转采用局部 `+Z` 右手方向。轴线与正向指示随校准和安装一起变换。
- 模拟转速范围 0–20 rpm、偏航偏移 0–359°，仅为演示控制范围。偏航按最短路径、最高 30°/秒逼近；叶轮按 `rpm × 2π / 60 × dt` 累加，不从天气风速推导转速。
- 对象层级、源节点和枢轴不匹配时拒绝驱动。只修改实例克隆的变换，不修改共享缓存、材质、几何或源文件；复位完整恢复原父级和原变换。

## 模拟来源与生命周期

- 本地来源 `ontovis-local-motion-demo-v1`，每次开始创建独立会话 epoch，序号递增，以单调时钟生成 1 Hz 样本。样本有效期 2.5 秒；值同时明确标为模拟。
- 样本校验来源、epoch、序号、时间、质量、数值范围与单位。重复、乱序、错误来源和失效样本不得继续驱动；质量异常、过期、断连冻结当前姿态，恢复后不补转。
- 渲染按帧插值，单帧积分最多 100 ms；网络/样本频率与渲染频率分离。暂停冻结，复位退出；切换实例、固定版本、场景、项目、页面、隐藏实例、浏览器隐藏及退出驾驶舱均结束演示并恢复零位。
- “减少动画”下默认不播放，仍需用户显式开始；自动天气特效与本模拟互不驱动。

## 验收

1. 固定模型及源节点匹配；其他模型拒绝开始。源属性搜索、选择与校准状态保持正常。
2. 偏航 0/90/180/270°：机舱与叶轮共同转动，塔筒不动；359°→1°走最短路径。
3. 正转、0 rpm 停转、暂停/继续、异常/过期/断连冻结，恢复时不补转；显示三维轴线及方向说明。
4. 多实例共享同一模型时只改变目标实例；复位后结构、变换、源缓存一致。切换与离开无残留动作。
5. 深浅主题及界面缩放下标签与控件可用；正常登录的隔离候选与公网验证，发布前后业务数据和素材完整性检查。
