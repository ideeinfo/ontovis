# 场景告警与受控检索实施契约

2026-10-29，本批实施冻结；完成状态以开发执行记录及实际验收为准。结论确认保持关闭。

## 读取性能

文档默认关联视图使用源端已实现的固定发布版知识邻域（两跳、12节点、18关系、48证据），保留版本、状态、原页和对象映射校验；全文节点检索/分页仍可显式使用完整视图。请求前后实时授权，不缓存跨用户或跨请求的授权。批量只读描述一次取得，避免逐个读取相同固定分析。图片、模型缓存沿用已有固定身份及取消/释放规则。

## 场景告警

场景“告警演练”入口按需加载，默认关闭，不新增持久告警配置。用户选择一个已布置且绑定设备库整机身份的实例及一个已有模拟数据集，然后显式开始/停止/继续演练。沿用现有模拟SSE、质量/恢复/过期规则。用整机安装上下文、已采用型号修订、源工程定义及子设备模板UID唯一解析目标；不能因同型号让其他实例着色。重复整机表示不能自动选择。

视口只叠加该实例的状态标记，显示模拟、发生/恢复/数据过期/无映射状态；选择告警可主动定位整机，进一步定位沿用项目共享构件绑定。未加载/隐藏的模型不因订阅强制加载，不自动改变相机或保存场景，不持久更改模型材质。离开场景、切换实例或数据集即停止旧订阅。15台设备、12台布置及3台预留均不变。

## 受控自主检索

在已选固定资料中，按资料类型使用白名单读取工具；问题中的首个五位故障码可触发所选文档固定发布版内的精确查找及有限邻域读取，所选对象则按已有精确UID读取两跳图。每轮最多8份资料、2个并发、120秒、1次模型调用；所有工具为白名单只读工具，不能由文本指定URL、SQL或写动作。每份资料内部检索有单独边界；记录工具、结果/截断/缺口与固定版本的摘要回执。

跨资料检索只在用户已选的资料集合内，不自动把未选对象、原图、整库或任意全文发给Qwen。不跨发布版借用同码节点。不支持的请求明确报告缺口，可推荐用户加入资料；不伪造结果或确认工程事实。保留多轮原引用、权限复核、取消、幂等、策略与服务版本校验。检索结果来自源端，不从Demo专用规则补造知识。

默认优先覆盖不同类型，挑选最多6份固定资料，为额外的手册定向读取预留额度；用户仍可调整为最多8份。预算先为每个选中资料保留一次读取；只有余量足够时，手册才执行“故障码精确查找＋已发布邻域”两步。当前每份手册每轮仅针对问题中首个五位故障码；多码比较需要逐轮查询，不宣称任意全文或模型自主工具循环。检索过程保留查询码、固定节点和原页锚点，E引用及后续工单采纳保留这些锚点。编辑问题后原摘要预览立即失效；不会展示与新问题不符的“拟发送摘要”。

既有手册轮次没有检索修订字段时，仅在来源固定身份、版本和脱敏摘要逐字相同的条件下允许进入新轮上下文；工程图检索修订仍严格比较。源服务变更、权限或固定分析变化的既有阻断保持，不为性能解除。
