# 驾驶舱设备资料与参数契约

日期：2026-10-31。承接用户三张截图，更新驾驶舱设备页的三个查看入口。

## 页面

右侧入口依次为“文档资料”“设备参数”“图纸”。文档资料保留当前设备适用的型号共享文档/PDF和照片，依来源提供预览；图纸展示当前所选对象已有的关联图纸，显示名称、页码、直接/共享定义来源，点击预览。关闭预览返回原列表与分页，空间镜头和所选对象保持。列表及长参数使用上下分页，主屏避免滚动条。没有图纸、型号或资料时显示真实空态，不借用其他对象或父级的资料。

设备参数提供“型号属性”“单台属性”两组只读内容。型号属性优先采用当前设备自身型号的固定规格/模板修订，按规格已登记的属性值与定义展示名称、值和单位。若部件未登记独立型号，但当前安装上下文及项目采用确认了所属整机型号，可单独显示“所属整机型号”；整机参数不能标为部件自身属性。没有可靠关系时保持未登记状态。单台属性继续由源端属性表单自动决定上下文，不由前端任意选择模板。未知/不适用保持来源语义，不改写为零。

原“对象详情”列表入口改为“图纸”；设备卡右上角身份/精度入口按需保留必要状态，长身份和质量说明不堆在主屏。

## 读取边界

文档资料沿用equipment/materials/resolve及固定文档metadata/content。图纸沿用objects/evidence/resolve和content，始终携带当前对象、对象修订、安装上下文/层级修订及固定来源摘要；来源变化/权限变化阻断，读取后再次校验。图纸只表示既有对象关联，整页显示，不声明未经提供的精确区域。

现有equipment/attribute-form保留原单台读取；新增受限的includeModel:true与expectedEntityRevision参数组合，服务器自行解析当前对象及同安装上下文的整机采用，读取固定型号规格/有效模板。客户端不能指定规格、模板、父对象或外部地址。保持当前用户项目权限，前后复核对象、层级、型号与采用关系；无可靠型号时可返回独立空态，权限撤销和版本变化仍阻断。接口不写入源端或ONTOVis业务数据，不提供参数编辑。

## 验证

覆盖设备自身型号、明确的所属整机型号、无型号/无采用、不同安装/采用不能混用、固定修订与未知值、非法请求及迟到权限/来源变化；图纸选择/内容请求固定当前对象和摘要，切换/关闭取消读取及释放图片。候选和公网真实账号验证机舱动力柜/整机、资料/图纸预览返回、两套主题、1920×1080和紧凑视口，数据/源端版本核对后发布。
