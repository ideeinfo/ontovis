# 驾驶舱分析只读展示契约

日期：2026-10-31。按用户最新要求，大屏分析工作台限定为已有画布可视化查看，并允许独立悬浮查询。后台分析画布的编辑、权限、固定来源和版本机制保持。

## 页面与交互

大屏分析工作台只展示当前故障相关的本人可读已有画布；不呈现全部画布列表、回收站、保存、编辑、添加资料、调整卡片、改检查状态。当前故障与推荐画布选择集中在顶部，推荐排序沿用现有同码历史服务，默认加载首个推荐固定修订。由具体固定分析入口抵达时先读取其上下文，再解析相关故障；无故障上下文或无推荐时显示简洁空态，不借用其他故障画布。

承接4d-1/4-1与原MagicPath分析页：点阵底、中心报警卡、围绕排列的图纸/模型/照片/文档/趋势/分析记录卡，右侧展示该修订已保存的助手或人工分析。卡片进入即可加载正文/图像/三维，无需点“打开/启用”。只加载当前页的可见卡；超过容量以按钮分页，中心故障保持。卡片可放大查看，照片/模型内部查看不回写分析视图。资料缺失、无权、来源变化保持阻断，不用示例图替代。主屏避免滚动条；详情内必要导航保留。

布局只作临时展示投影，完整保留原卡片身份、固定来源、关系、笔记、分组、视图和保存坐标，不自动保存或重排业务数据。实际登记关系用实线，候选及人工假设作明显区别，不绘制未经依据的因果线；每页仅连接可见且当前可读的资料。右侧只读取已有分析记录，不自动生成或恢复失效回答。大屏可主动打开可拖动的悬浮查询助手，按所选固定画布资料提问、检索及定位引用；保留原项目策略、摘要外发范围、版本和调用预算。查询对话可以保存，不能加入画布笔记、追加卡片、修改已保存布局或写入工单；这些入口只在后台提供。关闭/切换故障不把对话写回画布。

2026-10-31用户允许手动调整资料卡展示位置。按住资料卡标题栏或移动图标拖动，连线及正常比例文字标签实时跟随，当前卡片置前；卡片保持在可见画布内。标题栏移动图标支持方向键微调。图片/模型正文的缩放和平移、放大按钮继续独立操作。分页及主题/界面缩放保持同一查看过程的临时位置；切换故障、推荐画布、刷新或离开分析页时重置，“恢复布局”随时回到默认排布。中心故障卡保持原锚点。不新增布局保存请求、存储或修订，后台原坐标不变。

关系读取覆盖当前固定画布全部来源，不随资料分页截断。当前页两端之间若经未在本页的可读工程对象形成既有关系链，可作收束展示并标明“经对象”；点击查看完整链和各段依据，不能把间接关联冒充直接绑定或故障因果。来源变化/受限的节点及跨历史范围不参与投影，候选链保持虚线。只为补齐可见连通分量显示最短关联链，保留本页直接关系；原关系数据不写入。连线路径随画布适配，标签采用正常比例的独立文字层。

“后台编辑”返回同项目后台分析界面，读取该画布最新修订后按现有权限编辑；当前展示固定修订保持。“新建画布”返回后台空白草稿，保存前不创建服务端记录；任何原后台未保存修改仍需既有离开保护。返回驾驶舱保留空间位置，重新进入按当前授权重读推荐。

## 服务与边界

复用现有`analysis-sessions/history-candidates`、`detail`、固定证据读取/关系及助手对话读取。推荐按源连接、项目、本人、故障码过滤；不同对象、分支或事件只作为明确标记的历史参考，不能称为当前实例已确认结论。同码独立复发不合并。

新展示组件不调用`start/create/save/restore/evidence/register/import-history`；只有用户在悬浮助手明确发送查询时才调用已有助手`start`。后台新建/最新编辑只增加前端入口意图，不增加后台写入接口。权限、版本条件、来源变化与未保存保护仍由原业务路径执行。

## 验证

覆盖故障切换、无关画布排除、固定修订与历史区别、自动加载、分页完整性、布局不变、已有助手记录版本检查、编辑/新建路由和迟到响应清理。候选与公网正常账号验证深浅主题、1920×1080及紧凑尺寸、自动资料加载、无主屏滚动条、后台跳转与未保存保护，发布核对业务数据不因查看变化。
