# 模型基本信息编辑

2026-10-26。模型目录仅呈现模型卡片或紧凑列表，不在列表内展开版本。点击模型进入详情，版本选择和更新文件放在详情侧栏。

- 可编辑资源名称（1—200字符）、用途（equipment / simplified_scene / environment）和说明（0—2000字符）。说明属于共享模型资源，不替代固定版本的上传来源声明或工程证据。名称调整不确认工程精度。
- `POST /api/workbench/resources/model/info/save` 使用现有共享模型维护权限、登录修订和16KiB JSON边界。请求包含 `modelAssetId`、所属 `modelVersionId`、`expectedAssetRevision`、`clientRequestId`、`displayName`、`purpose`、`description`。
- 当前资源修订不符返回409 `MODEL_ASSET_CHANGED`；界面保留修改，可重新读取后明确重新编辑。请求ID相同且正文不同返回409 `REQUEST_CONFLICT`，重试同一请求返回原回执，重放仍需当前维护权限。
- 单一SQLite事务更新资源基本信息与资源/目录修订，追加不可变的信息修订、既有操作审计和请求回执；提交前再次授权，失败全部回滚。不同资源的编辑互不制造资源修订冲突。
- 正常目录、搜索和各固定版本详情显示当前资源名称。固定版本保留原上传名称和来源、内容摘要、校准、构件及文件；模型基本信息保存不创建GLB版本，不改场景快照或放置实例。
- 现有名称中的教学用途描述改为简洁名称；完整/外观的几何区别可以保留在名称中。原来源说明、属性证据和精度状态保留，历史名称可由信息修订追溯。一次性清理通过同一受保护接口逐资源执行，不直接改业务表。
- 旧信息修订不提供单独恢复入口；用户可以再次编辑并保存。完整配对备份和恢复须保留新增信息修订及原固定内容、审计、回执和所有私有文件。
