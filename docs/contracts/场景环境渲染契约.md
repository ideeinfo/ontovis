# 场景环境渲染契约

2026-10-24冻结ENV-01—03。承接[实施方案](../plans/场景环境渲染配置实施方案.md)，采用其嵌套environment V1字段；仅新增surface.terrainRoughness（0.2—1）与textureRepeatM（1—200米）。首批renderProfile固定standard-v1、阴影quality固定balanced、textureSet固定null、水面仅normal-waves且amplitudeM=0、reflection为procedural-sky。不接受外部URL、用户程序或任意字段。

缺失environment与显式null保持不同；旧景读取不补字段、不创建修订，默认灯光和无色调映射保持。新配置通过既有scenes/check/save保存；新客户端check/replacement-check/save附environmentWriteVersion整数1。前后快照任一含environment（含null）时必须确认写版本；已有字段不能被省略，只能显式null恢复原显示。错误为INVALID_SCENE_ENVIRONMENT、UNSUPPORTED_SCENE_ENVIRONMENT、ENVIRONMENT_WRITE_VERSION_REQUIRED、ENVIRONMENT_FIELD_REQUIRED、WATER_SURFACE_NOT_SUPPORTED。权限、幂等、乐观版本及空间receipt继续由原服务控制。

色彩、灯光、雾、阴影、水纹数值范围沿用方案；远雾必须大于近雾。太阳角度朝向太阳，水纹为TO；地理场景真北0°顺时针、转换到当前投影坐标，局部仅称局部北。seed为0—2147483647整数；initialPhase为0—1000秒，重开从该固定相位开始。运行时相位、个人暂停和低动态状态不保存。

水面只允许当前平坦UNKNOWN_RELATIVE固定定位面。前端以处理报告提示可用性，后端GIS核对实际mask内高程，最大差≤0.0001米。保留原地形采样和实例位置，独立视觉水面不位移顶点、不参与拾取；显示水面期间隐藏影像但保留引用与显隐意图，关闭后恢复。拒绝起伏DSM、已知高程基准和局部平面。纯环境不改变坐标系、实例、模型固定版或工程关联；锚定与模型/地形换版必须完整保留环境，水面不适用时明确阻断，不能静默关闭。

右栏属性中折叠环境渲染，提供预设与参数，与原“场景显示”并列。预览只改当前视口，不调用保存；采用进入草稿后走一次服务校验，再由顶部保存持久化。取消不改变镜头和选择，并恢复预览前的播放状态与相位；离开预览释放资源。共享环境仅可写用户采用，能力未声明时不开放。水纹默认尊重减少动画，支持临时播放暂停，后台取消RAF、恢复首帧零增量，最多30次视觉更新每秒。1024局部阴影预算为8个投射实例且250000三角；环境资源创建失败时提示并降为静态天空和水色，关闭阴影及动画。海上概览预设默认关闭距离雾，避免全景超过13km时被完全遮挡；其他预设保留可调距离雾。ENV-04外部纹理、位移、平面反射不在首批。
