# 受限助手与项目策略契约

2026-10-29，Q-22/Q-24首切。用户已批准复用现有阿里云Qwen，独立用途`ontovis_analysis`，仅外发所选模拟报警、趋势汇总及脱敏文本摘要；不外发原图、照片像素或整库。8次读取、2并行、120秒为上限，单次最多一次模型调用、1800输出token。本文随实现验收，不代表全部Agent或真实数据源已完成。

## 源端独立用途

OntoBase新增项目内`ontovis-assistant/service`读取和`ontovis-assistant/analyze`调用。部署配置批准项目、模型和阿里云目的地主机；默认关闭。用途、系统提示、请求/响应结构、限额及撤权校验独立，凭据通过源端已有模型配置引用读取，不复制到Vis、不返回密钥或尾号，也不冒用原用途的提示模板。首批仅项目管理员可运行；该权限不代表诊断专家资格。

请求固定服务修订、权限修订、操作ID、问题和至多8个带临时E编号的文本摘要。禁止任意endpoint、工具、代码和图片字段。脱敏替换URL、本机路径、UUID、邮箱、电话和凭据模式；项目/身份标识在Vis投射为临时编号。原始引用仅保存在当前账号的Vis运行记录。模型返回的观察、假设、缺口及下一步必须通过结构/长度/引用白名单校验，未经验证不展示为有效回答。JSON模式与非思考模式按[阿里云结构化输出](https://help.aliyun.com/en/model-studio/qwen-structured-output)实现；不展示内部推理。

源端无自动重试；相同操作ID与内容在当前进程去重。Vis在调用前登记运行，重启后的未完成请求标记中断，不自动再消费模型。断开调用时关闭源端模型连接；取消先呈现请求中，后台确认停止才标为已取消。模型错误只返回稳定错误码，不向客户端回传供应商原始异常或凭据。

## 项目策略与运行

同源POST路径为`/api/workbench/assistant/{policy,preview,publish,history,rollback,summary,start,status,cancel}`。沿用当前HttpOnly会话、Origin、完整projectRef与expectedSessionRevision。项目配置和运行在既有可成组备份的SQLite工作库中保存；所有记录包含连接/项目，运行另含owner。默认策略关闭；管理员预览、显式生效/回滚，expectedRevision和expectedAccessRevision约束原子写入；回滚新建修订，不能恢复撤销权限。平台规则与项目允许集合求交，预算取较小值，项目不输入密钥或URL。

启动只接受本人分析ID/所见分析修订、选中的已登记资料句柄及问题，不信任浏览器标题或资料文本。服务器在权限内重新读固定版本，释放PG连接后再读取资料和调用模型。至多8次资料读取、2并行；只读工具仅对象摘要、模拟报警、模拟趋势汇总、图纸/照片/模型元数据、文档知识摘录和历史工单摘要。未接的通用图邻域不启用，不读原图或全库。质量缺口、固定历史、模拟和代理精度进入摘要，不把共享定义当单台设备。

运行固定项目策略、服务、分析修订和资料来源版本；轮询/取消/结果回读均重验当前权限及资料可用性，不能在撤权后显示缓存答案。策略授权收紧/服务禁用即时停止旧任务，宽松新策略仅对新运行生效。全局最多2个活跃运行，同一账号/项目最多1个，无无界队列；超限明确可重试。硬预算至多120秒，源端模型调用另受50秒上限约束，用户切换项目/会话后不应用迟到结果。当前为一次固定读取批次和一次模型整理，无自主二轮检索；早期设计的60秒软预算不作为本次已实现能力。

## 页面与验收

沿用活动MagicPath工作台：项目内AI策略固定表单、有效配置/差异、生效与历史回滚；分析画布侧栏有“详情/助手”切换。用户可检查所选资料摘要，明确发送问题；显示读取、模型整理、引用校验、部分资料缺失、失败、取消、中断和冲突。结果按观察/假设/缺口/下一步分组，引用可定位现有资料卡。加入分析笔记是用户点击的可撤销本地画布操作，仍由原保存按钮保存；不自动确认结论、改绑定或关闭工单。

验收分离纯合同夹具、HTTP权限/并发/撤权/取消、正常账号浏览器与一次批准资料范围内的真实Qwen调用。实际记录用量/耗时，错误不伪装成功。配置修订/运行记录须随成组备份独立恢复；原设备UID、12台布置/3台预留、原图纸照片、工单和历史画布保持。
