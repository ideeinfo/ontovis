# ONTOVis 未登录首页：风电场背景视频提示词与制作规格

2026-10-23｜视频制作提示词；本文件不包含视频成片，也不表示首页已发布。风电场作为首个应用场景的视觉背景；ONTOVis 的介绍仍面向工业资产，不限定为单一行业。

已生成用于设计预览的原创静帧，来源和实际接入状态见[登录前首页设计](登录前首页设计.md)。可将该静帧作为图生视频构图参考；最终Poster应从成片重新提取并匹配。

## 推荐方向

采用**灰绿、固定广角、缓慢叶轮、无人物操作**的一镜到底风电场画面。视频负责氛围，产品介绍和登录表单由网页绘制；不把文字、Logo、数据界面或登录框生成进视频。

首选15秒、16:9、24fps；允许12–18秒。先制作能静态成立的首帧，再补充少量运动。固定机位比持续航拍更容易保持阅读稳定和循环接缝。

## 可复制中文主提示词

```text
为工业资产可视化产品 ONTOVis 的未登录单页首页，制作一段写实摄影风格的风电场背景视频。画面是非特定项目的陆上风电场环境，不复刻任何客户或真实项目，不带可识别地点和工程标识。几台结构可信、比例自然的三叶片风机分布在平缓起伏的草地与远处山脊之间，可有低调的场内道路，但不出现检修、吊装、设备控制或人员作业。

整体为克制的灰绿主题：鼠尾草绿草地、柔和灰色天空、灰白塔筒、远山薄雾和自然漫射光。低至中等反差、低饱和、明暗稳定，清晰而不锐利刺眼。主体集中在画面中右侧与右下侧；左中约40%的区域保持低细节、低反差，供网页叠加简短介绍；右上角保留安静留白，不能让叶片、塔筒或高亮云边穿过登录按钮区域。主要风机与地平线不要贴边，兼顾宽屏和居中裁切。

一个连续、稳定的广角镜头，优先固定机位。叶轮缓慢、匀速、方向一致地转动，叶片形状与长度始终稳定；草与薄雾只有轻微运动。专业、平静，具有风电运维环境的秩序感，不出现戏剧化天气、夸张速度或眩目的科技特效。

时长15秒，允许12至18秒，16:9，无声、无音轨。制作无缝循环：首尾的构图、机位、曝光、天气与叶片相位相衔接；循环点无跳帧、停顿、闪白、黑帧或突然变速。不靠倒放叶轮或明显交叉溶解掩盖接缝。首帧本身就是可直接作为静态首页背景的完整清晰画面。

视频内不要出现文字、字幕、数字、Logo、水印、UI、登录框、图表、传感器光点、HUD、AI控制演示或虚构运行数据。不要暗示这是客户项目实拍或当前真实设备状态。只输出适合网页叠字的风电场环境背景。
```

## 构图与剪辑规格

| 项目 | 建议规格 |
|---|---|
| 时长与帧率 | 首选15秒/24fps；交付允许12–18秒，固定帧率，不插入停帧 |
| 画幅 | 16:9；母版至少1920×1080，生成器有余量时可保留更高分辨率母版 |
| 机位 | 固定广角优先；如保留轻微位移，只用几乎不可察觉的平移，首尾机位必须闭合 |
| 文字安全区 | 归一化画面x=8%–48%、y=28%–72%保持低细节；用于左中标题、短介绍与三条能力入口 |
| 登录安全区 | x=76%–96%、y=0%–18%保持安静；实际按钮由网页渲染，并保留视口边距 |
| 关键主体 | 尽量处于x=48%–80%、y=25%–85%；移动裁切需单独检查，不以拉伸适配 |
| 色彩 | 服从现有灰绿主题；不做大面积荧光色、强蓝光或强橙色夕阳；不要改用户Logo原件 |
| 网页蒙层 | 独立的深灰绿渐变蒙层保证文字可读，左侧略深；不要将蒙层或文案烘焙进视频 |
| 循环质检 | 连播至少3次，逐帧核对接缝前后叶片相位、轮廓、云雾、亮度；生成提示中的“无缝”不代替实际检查 |
| 接缝修复 | 优先选天然可匹配的相位并重选循环段；不采用明显倒放或让叶片重影的溶解。无法平滑循环时重做，不将跳变交给网页掩盖 |
| 画面含义 | 摄影写实风格，不标为实拍、现场监控或实时运维；保留生成来源与使用许可记录 |

## Poster 与网页交付规格

以下是拟定交付目标，文件名为建议，均不是已存在资产。

| 交付物 | 建议 |
|---|---|
| 主视频 | `wind-ops-loop-1080.mp4`：1920×1080、24fps、H.264、yuv420p、无音轨，`+faststart`；15秒版目标不超过6MB（十进制） |
| 轻量版 | `wind-ops-loop-720.mp4`：1280×720、24fps、无音轨，目标不超过3MB；按实际画质和传输结果调整 |
| 可选替代格式 | 可另交同帧同色的WebM/VP9作为候选源；保留MP4，不把单一格式视为所有目标浏览器均可播放 |
| 桌面Poster | `wind-ops-poster.webp`，从最终成片的第一个有效清晰帧提取，1920×1080，目标不超过200KB；保留JPEG兼容副本 |
| 窄屏Poster | 用同一首帧另做移动裁切，保持主要风机与文案背景关系；窄屏默认静态图即可，不强求视频铺满 |
| 母版与记录 | 保留生成母版、最终循环入出点、提示词、模型/工具版本及许可记录；不把原始客户素材加入生成输入 |

编码先以画质为准调整，再验文件预算；CRF值不保证成品大小。若1080p无法在预算内保持轮廓稳定，先测试900p或720p，而不是把细节压成块状。MP4的`+faststart`把索引移到文件前部以利渐进播放；它不等于视频已经预加载或一定能自动播放。[FFmpeg官方格式文档](https://ffmpeg.org/ffmpeg-formats.html#mov_002c-mp4_002c-ismv)

Poster与视频须使用相同构图、裁切与调色。网页先显示Poster，视频首帧可用后再平稳接替；不让登录和正文等待视频下载。视频采用`muted`、`playsinline`、`loop`，仅在满足播放条件时尝试`autoplay`；自动播放被拒绝时保留Poster，不阻断登录。[MDN video元素](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)、[MDN自动播放指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

`preload="metadata"`只是浏览器提示，不能承诺只下载少量数据；自动播放可能优先触发继续下载。需要省流或减少动态时，应不设置视频源/不挂载视频，只加载Poster，而不是仅把正在播放的视频用CSS藏起来。[MDN preload说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video#preload)

## 减少动态与播放控制

- 初始化先检查`prefers-reduced-motion: reduce`：默认只显示Poster，不自动加载或播放背景视频；运行中偏好变为reduce也停止运动。需要尊重用户系统设置，不用更慢的视频替代静态选择。[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)
- 对于持续12–18秒自动循环的非必要背景，提供可键盘操作的“暂停背景 / Pause background”及“播放背景 / Play background”控件；记住用户当前选择。不要仅提供鼠标悬停暂停。[W3C WCAG 2.2.2说明](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)
- 登录弹窗打开时暂停背景，使用主题Surface保证字段可读；关闭后仅在用户此前允许播放、系统未要求减少动态且页面可见时恢复。用户主动暂停后，不因关闭弹窗而擅自重播。
- 页面进入后台时暂停；返回前台也遵循上述状态，不把后台视频维持播放作为必要功能。窄屏或用户选择省流时优先Poster。
- 背景视频为装饰内容，不承载唯一说明或交互目标；正文、三条功能文案和登录按钮始终可读、可操作。视频失败或完全不加载时，首页仍完整成立。
