## 1. 产品范围与核心决策

一个项目对应一个驾驶舱。项目已有的每个场景就是一个资产组合，不再建立需要单独维护的“资产组合”实体。场景可以重叠、覆盖项目的一部分，也可以只有局部模型而没有地理位置。

四个主要页面是“项目资产 → 场景总览 → 设备 → 分析工作台”。保留参考图的地球、空间大画面、浮动玻璃面板和底部搜索条；将“全球资产”改为“项目资产”，将行业特定的“风场总览”改为“场景总览”。风机、风场是此次示例，项目和设备类型不写死为风电。

大屏用于观察、定位、分析和进入既有业务流程。资产登记、场景编辑、绑定修改在原工作台；现场操作在受控业务系统。驾驶舱中的“暂停”只暂停视觉动效，不代表设备停机。

| 参考画面 | 采用的设计细节 | 交互完善 |
|---|---|---|
| 1d-1 / 1-1 | 亚洲地球、云层与大气辉光、绿/橙水滴标记、资产缩略图、曲线关联、底部胶囊搜索 | 项目范围、重叠场景去重、无地理场景入口、标记聚合与列表同步 |
| 2d-1 / 2-1 | 海岛地形、透视风机、灰绿信息卡、橙色告警、绿色集电线、天气层 | 实际转速/偏航/变桨驱动；观测天气与光照分离；数据过期停止外推 |
| 3d-1 / 3-1 | 机舱透视、工程树、齿轮箱橙色轮廓、资料数量、实体/透视/爆炸模式 | 真实部件身份、模型能力检测、几何精度说明、资料固定版本与单台适用范围 |

## 2. 入口、权限与导航

### 2.1 标题栏右上角

在正式工作台标题栏右侧、通知及账号区之前放置“驾驶舱”按钮，使用 LayoutDashboard 图标与文字，宽约 96–112px、高 34px。继承当前已进入的项目，不能从仅选中的项目目录行推断上下文。

- 已进入项目且可读：点击进入该项目驾驶舱，首次到项目资产页；再次进入优先恢复本人该项目的有效视图。
- 全局模型中心等无项目页：点击弹出当前用户可访问项目选择器，选择后进入。没有项目则显示正常空态及“返回项目中心”。
- 场景页进入：仍使用同一标题栏入口，可恢复到当前场景；入口提示显示项目名。
- 没有驾驶舱/项目读取权限：不泄露计数；按钮不可进入并说明“无项目访问权限”。不新增隐式管理员旁路。
- 驾驶舱右上角提供返回工作台、主题、通知、显示设置和账号入口。返回恢复进入前的工作台路由、项目和已允许保留的查看状态。
- 全屏是独立显示动作，按浏览器权限执行；Esc 退出全屏或先关闭当前弹层，不触发业务写入。

#### 显示设置 → 界面缩放

右上角显示设置内新增“界面缩放”：自动（默认）、100%、150%、200%，以及“恢复自动缩放”。自动档显示当前生效百分比。缩放调整文字、图标、间距和面板，重新排版；保持当前场景、设备选择、主题、报警、分析来源和返回位置。三维相机倍率、分析画布倍率及照片 100%（1:1）保持各自语义；照片原像素查看层不继承界面放大。

自动以浏览器可用 CSS 视口为依据，不按物理像素或 devicePixelRatio 再乘倍率：可用空间达到 3840×2160 时为 200%，达到 2880×1620 时为 150%，其余为 100%。例如 4K 屏幕系统缩放 200% 后只有约 1920×1080 可用空间，自动仍为 100%；用户可以手动覆盖。浏览器工具栏减少可用高度时按实际空间降档，显示生效比例，不声称所有 4K 显示器固定选 200%。

首切偏好只在当前用户会话内保留，跨驾驶舱页面和返回工作台不丢失；退出/撤权清除。缩放过大时使用分页、逐层进入或“结构 / 资料”单面板切换，主屏避免滚动条；完整长资料与详情保留必要滚动，显示设置和恢复自动始终可达。全屏、主题与缩放独立。1920/4K 的全部档位、窄屏、键盘和减少动态需浏览器验收。

#### 展示分层与其余显示设置（2026-10-30修订）

生产主屏按展示优先：资产卡与设备列表上下翻页，设备树每次展示直接下级，长说明与UUID转入详情。场景左侧摘要与紧凑天气、右侧告警/图层分卡；设备左侧结构、右侧资料入口与模型缩略图。保持预报、模拟及未核实身份等简短标识和必要来源署名。

显示设置分为“显示 / 场景 / 演示”。显示含缩放、主题、全屏和暂停；场景含临时光照、天气、设备/地形/影像开关；演示集中模拟转速、偏航、暂停/复位及按需展开的核验。手动天气标为演示，真实预报卡不随手动视觉改值。配置行为、已实施边界及窄空间退让规则以[展示层级契约](../contracts/驾驶舱展示层级与显示设置契约.md)为准。

### 2.2 页面及导航语义

| 动作 | 目标及保留状态 | 写入/模型调用 |
|---|---|---|
| 点场景卡或地球标记 | 该场景总览，保留项目、过滤条件，记录来源视角 | 无 |
| 点设备或搜索设备 | 解析精确安装身份后进入设备；多场景表示需选择 | 无 |
| 点报警卡 | 原页右侧报警详情；不立刻强制移动镜头 | 无 |
| 报警详情“定位设备” | 定位有效场景表示；无几何则打开对象侧栏 | 无 |
| 报警详情“进入分析工作台” | 显式创建/继续本人该事件分析，固定来源；不自动问模型 | 复用现有分析启动/保存，服务端幂等与版本控制 |
| “分析这条报警” | 当前已保存分析修订及所选来源 → 受控助手 | 按既有项目策略显式调用一次 |
| “整理到工单” | 选择目标工单、勾选并编辑建议、提交追加 | 仅最后提交写入；不自动派单/结案 |
| “返回空间” | 恢复进入分析前的场景、设备、相机、筛选、时间模式 | 无；已失效对象重新解析 |
| 点图纸/手册/照片 | 同屏完整查看器，关闭回原位置 | 无 |

页面顶部导航保持四个稳定位置；未选场景时点击“场景总览”先选场景，未选设备时“设备”显示可选择对象，不能偷偷选择第一台。直接点“分析工作台”进入本人项目分析列表或恢复已选择分析；只有明确的“新建分析/进入分析”动作才创建记录。当前可交互预演为方便评审预选了示例场景和设备，正式版依本节实现。

浏览器后退与页面返回统一使用上下文栈。关闭详情仅返回上层，不重建整个场景。分析中切换设备、项目或事件须切换到对应上下文；当前未保存笔记/布局按现有离开保护处理，不能静默覆盖。

### 2.3 连续空间导航

承接[已有连续导航设计](全球风场风机连续导航设计.md)及夏李本机 Demo 的节奏与同屏体验，不把 Demo 发布到产品站或直接打包其模型。

1. 点击目标后预取目标低精度表示、包围盒与权限，当前视图保持可用。
2. 地球 → 场景：相机向目标范围接近；地理场景已有固定地理锚点才做真实落位，无位置场景直接切到局部坐标视图。
3. 场景 → 设备：先收敛至设备包围盒，目标模型达到可绘制状态后在同一视口淡入，视角方向与屏幕锚点对齐。
4. 概览引擎与局部引擎分阶段映射视点；不直接复制相机矩阵。复用现有 MapLibre / Three 路径做首批验证，不为驾驶舱另建通用渲染平台。
5. 最后 250–400ms 为建议交接区间；整段通常 700–1200ms，属于待实测设计目标。任意时刻只有一个输入接收方。用户取消、反向导航或选新目标即废弃旧转换标识，迟到资源不能覆盖新页面。
6. 目标加载失败停在最后可用视图，给出重试/返回；不出现黑屏。减少动态偏好下直接切换并保留选择。恢复时只恢复仍有权读取且修订匹配的视点。

## 3. 页面一：项目资产

### 3.1 布局

1920×1080 基准：顶部约 96px；面包屑位于顶栏下；左侧资产面板约 390px，距左 30px、距上 175px；右侧图层面板约 190–220px；地球占中间及右侧主要空间。底部中央搜索条约 720px×60px，左下保留数据来源与时效。

地球视觉包含深海蓝、地表灰绿、真实比例大气薄层、独立云层、低亮星空；浅色使用低饱和灰绿和柔雾边缘。产品实现用已获许可的底图与地形资源、合规标注，不将生成的地球图片当成可测量地图。昼夜以项目时钟和太阳位置或明确的演示时钟控制，不跟随主题切换。

### 3.2 资产组合卡

每卡显示场景缩略图、完整名称、地理/局部模型类型、设备表示数、当前可读告警数和数据可用状态。长名称允许两行，卡片高度自适应，不把关键名称截断到无法区分。

项目摘要分列“场景数 / 去重设备数 / 当前告警数”。去重设备只统计身份已解析的安装设备；未知身份单列“待解析表示”。一个型号或模型实例不等于一台真实设备。场景内再区分设备身份数与模型表示数，默认摘要展示设备表示并可展开口径。

本次示例：3 个场景，分别 24 / 18 / 6 个设备表示；北部和检修场景均来自全场，项目去重 24 台。两个报警可分别出现在多个场景，项目仍为 2 条。以上全部为合成设计数据，与 Demo-PDS 15 台、12 台布置和 3 台预留无关。

### 3.3 地图与图层

地理范围已核验的场景显示绿点，含活动告警的场景加橙色数量徽标；橙色不是设备根因结论。密集点按视距聚合，点击展开/聚焦，聚合数量按场景数而非设备数。选中卡与点形成一条克制的橙色虚线，避免同时显示全部连线。

图层：场景位置、气象摘要、告警。无当前气象时显示“暂无观测”，地球视觉云层不因此冒称实时云图。场景无地理范围时仍显示列表卡及“局部模型”标识，不添加经纬度 0,0 或估计位置。

状态：无场景→进入场景工作台创建；无筛选结果→清空筛选；所有场景无地理位置→列表优先与中性地球；部分不可访问→只显示当前授权集合；读取失败→上次允许保留快照加时间/过期标记，提供重试。

## 4. 页面二：场景总览

### 4.1 画面与信息

主要空间用于地形、模型和选择反馈。左侧约 325px 场景卡显示名称、区域、设备/告警数量及风速、温度、风向；右侧约 302px 显示当前场景告警与图层；缩放、恢复视点位于右下。底部不堆叠运行大数字，避免遮挡资产。

风机使用实际布置矩阵和地形高度；地形、影像、代理几何分别标明来源与精度。设备选择使用轮廓和轻量基座标记，不让整个风机持续高频闪烁。绿色集电线默认表示拓扑；有经过验证的电气流向和测量才显示流动，禁止用装饰粒子冒称功率流。

### 4.2 动态风机

- 机舱偏航、转子旋转、叶片变桨使用三个独立节点层级。固定安装朝向/校准不被运行姿态覆盖。
- 转速来源必须明确是转子 rpm；不能直接使用发电机 rpm。按时间积分，`角增量 = rpm × 2π / 60 × Δt`；更新 rpm 不重置旋转相位。
- 偏航显示机舱实际朝向；风向仅作为对照，不自动强制机舱面向风。359°→1°走最短 2°路径，超过允许旋转速率的值标异常而不是镜头里快速绕圈。
- 没有真实转子相位时，角度为连续视觉相位，不作为现场叶片绝对姿态证据。停机有可靠状态/rpm=0才停转；数据失联单独显示未知，不能推定停机。
- 数据过期、乱序、来源身份变化时冻结最后可信姿态/相位，显示原因；不无限外推。恢复后平滑追随，避免瞬间跳到旧值。
- 远景使用实例化低细节外观，只对可见或重点设备更新昂贵的部件动画。近景切真实层级，缺少分离节点时明确“模型不支持此动效”，不让整机一起旋转。

### 4.3 气象匹配

天气效果由观测数据和有效时间驱动，主题与光照独立。气象卡说明来源、观测时间、覆盖范围/观测高度、质量和“观测/预报/模拟”。预报必须由用户明确切入，不能覆盖当前观测。

| 归一化天气 | 视觉 | 缺失/限制 |
|---|---|---|
| 晴 | 稀疏或无动态云、清晰能见度 | 无云量时只使用天气类别，不计算伪精确云量 |
| 多云/阴 | 依据可信云量调整云层，降低太阳直射 | 地球贴图内云层仍仅为背景 |
| 雨 | 定向雨粒子、适度地表湿润感 | 强度缺失用“雨”基础效果，不显示臆造 mm/h |
| 雪 | 低速雪粒子 | 不累计积雪厚度，除非取得该测量 |
| 雾 | 依据有效能见度调整远景雾化 | 无能见度数值使用保守预设，标记定性效果 |
| 雷暴 | 云雨效果与文字状态 | 默认不做频闪闪电；不能由动画判断安全作业条件 |
| 未知/过期 | 停止动态天气，保留中性环境 | 展示最后观测时间，不能沿用“当前晴天” |

粒子避开文字面板，运动量可关闭。风向统一为气象“风从何方来”，图形箭头另注朝向；源单位先转换后展示。不同场景不借用另一处气象站数据，除非配置明确覆盖范围并显示距离/代表性。

### 4.4 告警

每条显示等级、设备名、报警摘要、源状态、发生时间及数据质量；列表默认活动报警，提供等级/设备/时间过滤。系统断流以数据状态展示，不把所有设备自动置为工程报警。

点报警打开抽屉：固定事件身份/版本、发生与更新时间、源状态、当前值及阈值单位、发生窗口趋势、对象解析状态、关联资料范围。确认/解除状态来自权威源；本期驾驶舱只读，不因查看或进入分析自动确认。

若设备不在当前场景，提示可访问的有效场景或提供“仅查看对象”；不静默切项目。多处表示用同一安装 UID 聚合，选默认表示须有明确项目配置。原先隐藏的模型只有用户点“定位并临时显示”才显现，不修改已保存场景显隐。

## 5. 页面三：设备与部件

| 模式 | 条件与行为 |
|---|---|
| 实体 | 外壳和已显示结构正常渲染；关键部件受遮挡时允许明确“透视定位” |

## 6. 页面四：分析工作台与处置闭环

### 6.1 从报警抵达

默认一条明确操作“进入分析工作台”。先校验项目/安装身份/事件修订/来源授权；可唯一解析时直接在既有分析模块建立或继续本人该事件分析。不能仅以报警码复用不同设备/不同时间的分析。推荐同码历史是只读候选，由用户选择。

首批固定来源：报警事件及窗口趋势、设备身份与可用几何定位、适用手册/图纸元数据及允许摘要、本人可读同设备工单。来源获取缺失不阻塞整个页面，但每张卡明确“缺失/无权限/版本变化”；未经确认的候选资料不自动作为已选证据。来源变化保存新分析修订后才进入下一轮助手。

中心报警卡保留发生窗口，不随右上当前时钟滚动。画布关系分为有效身份关联、来源引用、人工假设/待验证；线型和图例不能让假设看起来是已证实因果关系。拖动、缩放、多资料同时预览及固定来源继续复用现有分析画布，而不是另建不兼容画布存储。

### 6.2 助手

右侧工程助手分为“本轮来源—观察—可能原因—证据缺口—建议下一步”。进入页面不自动调用模型。发起前看到项目策略、所选来源及固定修订；项目默认 AI 关闭，不能沿用另一个项目的授权。

沿用现有上限：8 次逻辑读取、2 并行、120 秒、单轮一次模型调用；最多默认选 6 份资料预留检索额度。模型/照片/图纸原图不因驾驶舱入口而扩大外发；当前批准范围仍为模拟事件、趋势统计和允许的脱敏摘要。持久对话和固定 E 引用继续用原机制，换资料不重写旧轮引用。

回答允许假设、待核查步骤和缺口，不自动确认根因、设备故障事实或现场处置结果。引用按钮定位对应卡片/原页。没有足够证据时明确“依据不足”，不补造阈值、规程或维修结论。未知接入源的真实数据外发需另行纳入项目策略。

### 6.3 处置方案

1. “整理到工单”展示本人有写权限、同项目、适合追加排查内容的现有工单；可另行进入既有新建工单流程，不自动创建。
2. 勾选假设、步骤与证据缺口，可逐条编辑。保留原建议、修改后文本、原轮/固定分析修订和原 E 引用。
3. 最后“加入本单排查”使用工单当前版本与幂等键，原子追加；版本冲突展示差异并重新选择，不能静默覆盖已有方案。
4. 不自动填结果、派单、流转、确认或关闭。工单权限不自动赋予他人阅读私人分析历史的权限，回看原引用仍独立授权。
5. 用户在原工单登记执行依据和结果后，分析卡显示“有新进展”；用户选择载入，保留卡片身份/布局/笔记/关系，并保存新分析修订，再继续问助手。原回答仍对应原来源。
6. “返回空间”回到原设备/报警，不重放已完成转换，不自动将该报警标为已处理。

## 12. 首切实施与目标设计的差异

C1/C2首切复用现有项目、场景、安装设备、固定资料与分析/工单组件。背景暂为中性空间示意，场景读取真实固定资源；没有数据时不生成天气、报警数和运行姿态。缩放作用于驾驶舱导航与信息面板，原分析工作区和照片查看器保留独立倍率。地球质感、连续空间导航、透视/爆炸与真实动态继续按C3/C4推进；MagicPath效果不作为已上线能力证明。验收与发布状态见[实施输出](../../output/cockpit-implementation-20261030/README.md)。

## 告警与选择强调色落实（2026-10-30）

以2d-1/2-1、3d-1/3-1为依据：主导航与正常图层保持绿色；活动警告、设备结构选中项、对应三维选中反馈和设备分析入口使用橙色。深色装饰色#FF790D、浅色装饰色#E96700；浅色小字用#B65308保持对比。设备选中行同时显示浅橙底、3px左强调条、橙色图标/名称及加粗文字，不能只依赖颜色。

首页与场景复用同一告警卡结构：警示图标、故障码、等级、摘要、具体安装对象及定位箭头。场景仅展示活动事件，首屏两条，完整回放仍从“查看报警回放”进入；场景左卡第二项显示该场景活动报警数，模型表示数保留在场景详情。读取尚未完成或失败不显示为0。主标题简化为“报警”，保留紧凑“模拟”来源标识；严重事件保持红色等级区别，已恢复/未发生/不可用不使用活动告警强调。

点击卡片继续以固定事件和安装身份进入设备、定位并隔离；选中列表、三维反馈与右侧资料对象同步。只有当前报警关联的同一对象在右侧显示对应等级；切换到其他部件不继承该报警。工作台普通编辑选择色不受驾驶舱橙色方案影响。

补充排查：场景设备选择弹窗标记当前安装实例，采用与结构列表相同的橙色选中反馈。驾驶舱分析画布的报警来源卡显示橙色边框、警示图标与标题；固定事件生命周期仍按原来源展示，不将历史报警误标为当前活动事件。普通工作台资料卡配色保持。
