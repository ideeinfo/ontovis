## 2. 页面与交互

| 区域 | 行为 |
|---|---|
| 固定顶栏 | 原Logo、功能概览、语言、主题、右上角登录。窄屏隐藏重复的概览入口，保留登录及偏好 |

| 功能介绍 | 灰绿半透明面板覆盖背景，三条短介绍；不堆叠概念、流程图、实时指标或工程示例 |

首页锚点由本页滚动处理，不进入浏览器工程路由；没有新建Router、外部returnTo、项目选择、服务地址、Token、验证码或权限配置。旧`#site`/`#asset/K07`属于参考Demo，不推定为正式回跳目标。

## 3. 页面状态与已有服务契约

| 状态/事件 | 页面与保护行为 |
|---|---|
| 首次会话检查 | 先显示公开首页；检查完成前不以空会话版本提交登录，不预读工程资料 |
| 匿名/已退出/已过期 | 公开首页；用户主动点右上角登录才弹出表单 |
| 已登录且项目可读 | 进入原工作台及原默认入口，不先显示原匿名三栏空壳 |
| 已认证但项目拒绝 | 首页不显示原用户名；重新登录前经已有退出及匿名会话检查，避免对已认证cookie重复登录 |
| 登录失败/暂不可用 | 弹窗就近显示既有通用错误与必要重试；清空密码，不暴露服务端配置或凭据 |
| 退出/失效/跨标签变化 | 清除工程内容、模型、图纸及私有弹窗；登录前首页不能残留旧账户信息；原会话轮询和取消机制保留 |
| 视频无法播放 | 保留静帧，正文和登录照常可用，不以加载遮罩等待视频 |

只复用现有`GET /api/session`、`POST /api/session/login`、`POST /api/session/logout`及`expectedSessionRevision`条件；不新增匿名工程读取或身份服务。正式鉴权、项目权限和会话有效期继续以[公网会话与工程读取契约](../plans/公网会话与工程读取评审.md)和当前后端为准。MagicPath弹窗只预演输入、等待和失败，不传送真实凭据，不模拟生产授权成功。

## 4. 背景素材与性能约束

本轮已制作**原创AI静帧**[wind-operations-poster.webp](../../assets/media/wind-operations-poster.webp)，1672×941、111,892字节，由内置imagegen生成；不是真实场站照片，不来自空间导航Demo。视频尚未生成/接入，首页默认仅使用该静帧，没有伪装成视频的CSS动画、外部图库请求或失效视频地址。

视频制作采用[完整生成提示词与交付规格](登录背景视频提示词.md)：15秒静音循环，固定广角，临近黄昏的克制灰绿环境，轻微叶轮/草地/云雾运动。现有静帧可作为图生视频构图参考；最终成片需重新提取匹配首帧，不能把本次静帧误记为实际视频首帧。

接入点为首页可选`videoSrc`，只有获得成片后才传入真实资源。静音、行内循环、播放被拒保留静帧、主动暂停、页面隐藏暂停、登录弹窗暂停；减少动态或省流偏好不挂载视频。背景是装饰，不承担唯一信息。自动播放规则见[MDN](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)，持续动态保留暂停入口见[W3C](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)。
