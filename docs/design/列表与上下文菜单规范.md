# 列表与上下文菜单规范

2026-10-26。承接用户“参考OntoBase、统一所有列表样式和上下文菜单”的要求。沿用ONTOVis灰绿双主题、13px正文、11px辅助文字及原Logo。

## 1. 参照与共用规则

参照本机OntoBase的`apps/web/src/components/ui/DataTable.jsx`、`Menu.jsx`及`features/formal/DrawingOrganizer.jsx`：固定表头、紧凑行、轻量分隔、图标文字菜单、行末更多入口、删除项分隔。ONTOVis复用同系列Radix控件和现有tokens，不跨仓导入业务组件。

| 项目 | 规则 |
|---|---|
| 表头 | 高32px、11px、弱背景，滚动时保持可见 |
| 数据行 | 最小40px；双行/长工程名称自然增高，水平内边距12px |
| 层级行 | 最小32px，保留缩进、展开和树语义 |
| 文案 | 主名称13px，辅助/时间11px；不因固定行高截断重要工程名称 |
| 状态 | hover弱背景；选中采用统一selected色与左侧标记；focus-visible使用统一focus描边 |
| 行操作 | 多个操作收进28px“更多”按钮；单一主操作保留点击行，不制造多余管理动作 |
| 上下文菜单 | 右键/触屏长按与“更多”使用同一动作集合、文案、图标和禁用条件 |
| 菜单 | 宽至少204px、内边距6px、项高至少34px、图标14px、圆角6px、主题阴影；自动避让边界 |
| 危险操作 | 最后一组、分隔线、危险色；保留原确认和后端条件 |
| 键盘 | 菜单方向键/Enter、Escape关闭与焦点返回，触发器有具体对象名称；行主操作保持原按钮可访问性 |
| 工具栏 | 搜索、筛选、刷新成组；主要创建/上传操作置右；窄屏可换行 |

## 2. 覆盖范围

- 场景目录、回收站：名称打开；更多/右键提供打开、基本信息、移至回收站或恢复。保持未保存保护、权限、内容/生命周期版本和原确认弹窗。
- 项目目录：选择查看权限、进入项目；进入前仍核对当前项目权限。
- 模型目录：卡片及列表统一选中、边框和更多入口；预览及更新文件沿用既有流程。版本仍只在详情侧栏展开。
- 工单、本人分析目录：统一紧凑行和选中；上下文仅提供已有打开操作，不引入删除、确认结论或其他未接入能力。
- 地形、影像、对象/构件、实例、引用与修订列表：使用同一字号、间距、选中和焦点规范；保留树、检查项、历史只读和领域交互，不把工具栏/表单控件强行改成菜单。
- 分析图谱、三维视口、图片缩放等领域工具不属于目录行；其操作和工程事实状态保持。

## 3. 控件与依赖

`ListMenus.tsx`同时服务场景、项目、模型与资源等实际调用方；两类入口共享动作，不引入动作注册平台。更多复用已有`@radix-ui/react-dropdown-menu`，右键使用`@radix-ui/react-context-menu`2.3.7（MIT，Radix官方维护），与既有Dropdown/Dialog共享menu 2.1.24依赖，负责焦点、键盘、长按与避让；不自研菜单引擎。打开确认框或上传表单的动作显式交接焦点，菜单先完成关闭及焦点清理，再打开表单；普通关闭与Escape仍返回原入口。独立产品只共用视觉规则，不共享OntoBase内部模块。

## 4. 验收

中文长名称、深浅主题、窄屏；更多与右键动作相同、点击菜单不误触行打开、Escape/键盘/焦点返回、禁用动作不执行、删除确认可取消。真实页面检验场景、模型、项目、工单、分析和资源入口；本机合成数据验证可恢复删除与权限；静态发布保留旧分块、视频、Logo、后端和业务数据。
