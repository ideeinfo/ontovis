## 2. 界面与交互范围

顶栏保留原 Logo、当前项目、设计预览标记、帮助和用户；管理侧栏宽约 200px。正文基准 13px、说明 11px；有意义的工程名称允许换行。主色沿用 `#0f766e`，正文 `#17212b`，次要文字使用可读灰绿，保持浅色背景。

| 视图 | 可检查的交互 | 必要状态 |
|---|---|---|
| 项目与访问 | 项目名称、行业、时区、单位；能力弹窗 | OntoBase 未连接；能力待核验 |
| 模型中心 | 名称/状态筛选，模型/报告/版本页签，四步导入，进入绑定 | 待核实；无处理报告；无发布版本 |
| 构件绑定 | 三柜选择、构件搜索、均衡/模型/证据三布局、对象/属性/证据详情、匹配规则草稿 | 对象身份未核实、源模型候选/示意代理、几何质量 |
| 设备层级 | 柜体选择、子设备搜索和分类、查看所选子设备与柜体定位 | 层级样例；不作为已确认安装树 |
| 场景与可视化 | 图层开关、视角偏好、状态样式、场景名称 | 布局预览、坐标待核验、地形未配置 |
| 数据与告警 | 连接类型、过期阈值、模拟选择、测点与告警页签 | 未接入；无映射；质量未知 |
| AI 策略 | 工具勾选、上下文、预算、回答偏好、有效策略摘要 | 模型未配置；未发布；试运行禁用 |
| 证据与审计 | 发布/绑定/AI 页签、检索与空态 | 无真实业务记录；导出禁用 |

绑定工作台在 1600px 宽度采用树约 220px、可伸缩视图、详情约 302px；布局偏好改变三栏比例。较窄屏幕收起导航文字或叠放详情，仍提供图标名称；当前只验证响应式预览，不承诺移动端现场作业能力。

主控制器等子设备被选中后，右栏保留该子设备名称；底部将“所选对象”与“空间定位对象”分列。所属控制柜只提供祖先代理定位，不替换分析对象，也不宣称具有柜内精确坐标。真实设备 UID 仍未核实。

首个工作台现提供8种演示状态：假定关系、无权、身份合并、机位不符、父链不完整、快照变化、读取中、读取失败。7/8号切换不复用旧高亮，断链保留所选分析对象；身份变化不自动迁移几何。三柜统一显示CT塔基信号柜、CN1机舱动力柜、CN机舱信号柜（来源旧称CN2）。状态切换器只用于设计评审，不是让浏览器自报授权/父链；确认和发布保持禁用。

## 3. 提示与信息密度

- 默认显示操作所需的名称、状态、字段和主要动作；删除重复的待核实提示与常驻原理说明。

- 匹配规则使用弹窗；完整属性和更新规则按需展开；审核要求从确认绑定附近打开。
- “未接入”“待核实”“示意视图”“祖先代理”等会影响判断的信息保留在对应区域，不能被个人偏好隐藏。
- 禁用按钮通过简短原因说明前置条件；未开放的上传处理、设备选择、审核、发布、AI 运行不返回假成功。
- 保存草稿后仅显示短反馈；准确标记本页内存保存、刷新清空。
- 空态只给一个清楚的标题和有用操作，不用长段解释填充页面。

## 4. 原型边界

模型视图为代码绘制的控制柜示意，不是实际 GLB 渲染或拾取；未上传第三方三维模型到 MagicPath。三柜与六个子设备是设计样例，不能据此确认设备身份、安装关系或工程等价性。

导入步骤实际检查文件扩展名与 200MB 大小限制，接收本地文件元信息。结构校验、稳定 ID 提取与坐标核验明确显示待处理；最终只保存本页导入草稿，不上传文件、不生成成功导入记录。GLB 规范仍为米、右手坐标、Y 向上。

AI 配置限制读取最多 8 次、并行最多 2、检索最多 2 轮、活跃执行最多 120 秒；子设备摘要默认关闭，开启后显示 1 层/最多 50 条。它们是原型表单与设计上限，生产实现需后端强制执行。AI 试运行保持禁用。

原三个管理画面聚焦项目管理；新增导航画面覆盖P01–P03空间连续性的交互样例。实际分析Canvas、AI对话运行或完整模型解析器仍未实现。MagicPath组件本身未连接模型、OntoBase、监测或AI服务，状态为合成预演。另一个本机三维技术样机已接真实演示读取API，两者验证分开，见[执行记录§9](../plans/开发执行记录.md#9-已确认范围安装后端与7号演示闭环)。正式绑定发布仍未实施。
