# 设备库、型号库与构件绑定调整

2026-10-28，待评审设计，覆盖此前将型号名称/设备类型维护放入 ONTOVis 的临时分工；已部署能力与历史引用保持。

## 权威边界

型号基础资料、分类、参数模板、型号内部设备角色、项目对型号的采用及实际设备台账归 OntoBase。项目工程对象及图纸/文档/共享定位照片继续归 OntoBase。ONTOVis 只维护三维资源、项目内构件绑定、场景表示和分析配置。

“设备型号”与“三维模型”使用不同身份。一个型号可以有多个三维表示；同一三维文件也可被不同项目应用，不代表工程结构相同。型号角色与项目工程对象的关系在 OntoBase 明确，几何构件与这些共享对象的关系在 ONTOVis 明确。

## 设备层级页面

保留“设备层级”模块，两个页签改为“项目设备”和“构件绑定”。默认项目设备；左侧可搜索、按需展开的设备树，右侧固定设备页头、路径、摘要和资料页签。选子设备留在同一棵树，去掉“返回整机＋内部设备(0)”的嵌套操作。长名称换行，属性成对对齐；资料不再纵向堆满折叠面板。

项目设备详情分“概览 / 共享工程资料 / 现场照片 / 构件定位”；型号、制造商和规格参数只读，维护按钮到 OntoBase。共享资料显示图纸、照片和文档知识，按需读取；照片显示来源为显式适用或柜内对象汇总，区域不转移身份。没有现场照片保留正常空状态。

构件绑定页固定项目、OntoBase 已采用型号/变体与规格修订；左侧共享工程对象，中间模型，右侧构件树/映射详情。型号名称、分类和技术参数不可在这里编辑；“新建型号配置”改为选择已有项目规格并建立绑定。已有定位、隔离、N对1、多构件占用检查、换版影响、保存和历史修订保持。资料查看移入抽屉/详情页签，避免挤占绑定工作区。

同项目同规格变体的设备自动读取同一绑定配置，应用范围只读展示；若设备换型，先在 OntoBase 修改实际采用，ONTOVis 根据新角色/定义检查映射，不创建逐台绑定副本。后续编辑当前绑定继续影响当前采用者，历史分析固定原修订。
