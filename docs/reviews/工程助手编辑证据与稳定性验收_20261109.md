# 工程助手编辑、证据与稳定性第二批验收

2026-11-09。承接11月8日综合总结及用户“开始执行下一批任务，自助测试”的授权。本批扩展后台画布编辑、固定发布知识与原页阅读，完成相关测试、发布及公网验收；EA-05工单业务流转和其他系统模块仍按完整计划后续接入。

## 交付与权限

- 画布受限动作共29项：补齐笔记替换/追加、卡片标题/复制/固定、分组及手工关系维护、同来源显式换版、有效趋势时间、撤销/重做/旧修订恢复和卡内视图复位。批次在副本上顺序执行、整体校验；失败不部分应用。手工与助手共用20步本机历史。
- 同轮新建笔记后可继续分组、固定及连线。公网首轮暴露规划丢失依赖动作，修正新卡编号协议后使用相同要求复验，不把首轮失败写成成功。纯编辑不再把“未读项目资料”误报为资料缺口，完成以真实回执为准。
- 项目知识在8次总读取预算内可进入最多两个固定发布来源；范围一致才继续分页。未读、失败、预算截断分别留痕。引用可直接打开原固定页、区域和知识节点，无需先加入画布；查看原页不调用模型，不表示模型读过图面像素。
- 后台在本人权限内编辑，驾驶舱持久为查询模式，准备/确认接口拒绝写入。转后台只带问题，重新核验后才能执行；问题仅向目标画布预填一次，不自动发送，不污染其他画布历史。
- 不改工程事实、源端工单状态、模型连接或密钥，不控制现场设备。沿用单一有界编排器，没有增加多Agent平台、任意HTTP/SQL或外网检索。历史与固定来源、候选/模拟/质量标记保持。
- 视觉继续承接原MagicPath设计与现有控件：正文13px、说明11px，身份/阻断信息必要呈现，其余按需展开；深浅主题一致。此批不另造页面风格或改Logo。
