## 4. 对Q-08的实际影响

公开影像来源缺口已解除，可以继续固定资源版本、同一MagicPath资源/场景增量及服务合同；近期Sentinel裁片优先，WorldCover2021保留为明确年份的后备。来源文件、裁片、SCL、处理参数、署名与哈希一并留存，后续换源产生新资源版本，既有场景不静默追随外部服务最新图像。目录API为[尽力提供的公共服务](https://github.com/Element84/earth-search)，不把其可用性当正式工作台的运行前提。

尚未实现影像资源、场景引用/显隐、坐标处理与私有读取、换版/权限及释放回归；矢量道路/场站边界尚无工程资料，可继续既有全球概览和合成反例，整项不能因此提前完成。工程影像精度/现场核实仍留Q-11。未改15机位、原DSM、Esri存档、业务身份或线上数据，Demo不发布。

早期STAC排序字段尝试返回400，修正为`properties.datetime`后成功；一次完整裁片脚本在写出数据后因本机机位文件路径错误收尾失败，修正路径后重新完整读取与15点覆盖核验通过。失败回执保存在本机，不据此认定数据源或产品异常。来源数据与处理脚本均在[本机输出](../../output/q08-geographic-layers-20261023/README.md)，不进入Git。
