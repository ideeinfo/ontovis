## 1. 模型资源

源站为Three.js程序生成的教学模型，未发现直接提供的GLB下载。隔离浏览器从实际型号页面导出机器根节点，保留来源URL、源文件和原始导出指纹；再生成符合现有导入限制的静态GLB，不自行重画另一套机型。每款有完整和仅外观两种，共20份：

| 型号页面标识 | 关联示例 |
|---|---|
| vestas-v105-3450 | Beck Burn |
| ge-3-2-103-corriemoillie | Corriemoillie |
| nordex-n80-2500 | Crystal Rig I |
| siemens-swt-2-3-82-crystal-rig | Crystal Rig II；III只作候选外观 |
| vestas-v136-4-5 | Crystal Rig IV独立资源，缺机位未布置 |
| siemens-sg-8-0-167 | Hornsea 2 |
| siemens-swt-2-3-93 | Teesside Offshore |
| siemens-swt-3-6-107 | Burbo Bank原场 |
| mhi-vestas-v164-8-0 | Burbo Bank扩建 |
| ge-haliade-x-14mw | Dogger Bank，13MW组也只用此候选几何 |

派生保持米制、Y向上、基点`[0,0,0]`、源正面`[0,0,1]`。基点为源地面/水面基准，海上基础可低于0，不能用包围盒最低点代替基点。“完整”限单台机器及自身基础/平台；船只、场站地面、外部阵列电缆等不并入单机。“仅外观”按源层级剔除internals/interior子树，并非经制造商核实的空腔壳体。

20份通过现有模型校验及Khronos校验（各0错误、0警告），源顶点/选取映射完整、坐标轴换算最大误差约0.000013733米。这只验证派生一致性，不验证制造尺寸、工程身份或材料等价。原始V105含越界发光参数，派生时限制发光并换成支持的PBR表达；原始反例保留，不把其原始文件记为直接可导入。

本机实际上传10份外观并校准，形成20个固定资源版本；643个实例共享其中9款的固定版本，放置没有新增型号版本。现有项目模型版本上限20包含上传/校准历史，不建议将全部资源再导入已有5版本的Demo-PDS，也不提高容量上限绕过检查；测试其他完整模型宜在分开的空测试库，或按单场选择必要型号。

源站商业页面和版权声明不等于开源许可。本次按用户请求保存为本机私有测试素材；未推送模型、网页代码或栅格到Git或公网，未据公开可访问推定商业/再次分发权。

合计643个下载地图点，保存为10个场景，全部经纬度和原索引保留且恰好出现一次。地图/OSM观测不等于现场安装核实；没有独立工程UID、物理关系或现场朝向依据。所有航向0是统一测试设置，缺编号时显示“源索引”，没有编造现场机号。Dogger分组不冒认已核实工程分期。

Crystal Rig近似配准使用源原点和固定经纬度换算，非拟合测量控制点；91点与格网机位匹配最大约3.270米，是内部对齐差，不是现场精度。高程标签来源虽提及EUDEM/OpenTopoData/Ordnance Datum，未核实垂直基准，按`UNKNOWN_RELATIVE`及专有reference保存，没有伪称EGM2008。派生只作Float32舍入（最大约0.000012207米）；最终网格在源地图点处与源渲染地面差最大约1.748米。实例采用产品固定网格采样贴地、偏移0。III期6台源只声明Siemens 2.3MW及估计64米轮毂，复用的SWT模型为68.5米源模型，界面明确“候选外观·塔高未复原”。

源Crystal影像仅能确认页面署名为2023年9月Sentinel-2，精确采集日/产品未得；不伪填日期通过上传，也未将其记为采用。Beck的20m影像来自10m RGB与20m SCL保守掩膜，非工程定位。Corri同时获取地形+影像的任务失败，独立地形重试成功；不能把地形成功写成影像通过，也不把失败未经证明地归因到特定服务。

海上7份平面仅用于地理布置验证，全部使用独立`UNKNOWN_RELATIVE`基准；7份色板是合成颜色。其“2026-10-23”为生成日期，非卫星采集日期、DEM或测深；未获取真实水深、海浪、岸线、道路或电缆工程资料。

## 3. 实际验收与交付

- 正常API完成10模型上传/校准、10地形和8背景影像资源引用、10场景保存/重开；最初空修订保持。地形中3陆地＋7合成海面，8背景中1真实概览＋7合成色板。
