# 夏李风场空间导航验证

2026-10-20建立首轮验证；2026-10-21按用户正式平面图修正机位。本轮以河南平顶山叶县夏李乡风电项目为测试案例，将公开 DSM、平面图配准位置和已有教学风机 GLB 整理为本机数据包，验证[全球—风场—风机连续导航设计](../design/全球风场风机连续导航设计.md)的真实三维输入与同视口渲染路线。

本机入口为[测试包说明](../../output/xiali-spatial-demo-20261020/README.md)，目录为 `output/xiali-spatial-demo-20261020/`。这是技术验证成果，不替换 MagicPath「ONTOVis 产品设计」活动设计源，不批准生产 API，也不代表 W2 的性能、权限和异常条件已全面验收。三柜绑定与无几何子设备定位仍遵循[既有拟议契约](../contracts/三柜绑定与子设备定位契约.md)。

2026-10-21演示联调增补：用户已确认首切范围，7号新增5个独立安装对象、4条假定关系并连通真实OntoBase读取API。本机“工程”页签定位三柜/无几何子对象，分析身份与CN空间宿主分列；其余机位不借7号UID。18项真实API/三维、13项浏览器失败注入和3项窄屏检查通过，证据与本机会话启动见[交付说明](../../output/installation-preview-20261021/README.md)。这不改变下文地形/配准精度或TU-3000本机用途边界，工程发布仍阻断。

## 3. 渲染输入与来源边界

MapLibre GL JS 5.24.0 持续承载全球与地理相机，Three.js 0.184.0 在同一 WebGL 画布绘制局部地形和风机；Three 局部层在地图进入本地平面尺度后显示。低精度全球陆地轮廓来自 Natural Earth 1:110m，具体下载地址及固定运行库见[运行资源清单](../../output/xiali-spatial-demo-20261020/sources/runtime-urls.json)。

[Copernicus GLO-30 AWS公开镜像](https://registry.opendata.aws/copernicus-dem/)采用2021 release，属于包含建筑和植被的 DSM。产品水平基准与EGM2008垂直基准见[Copernicus官方规格](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)。本区域没有使用地面控制点校核高程，不应用于基础、净空或安全距离核定。

[Poly Haven Leafy Grass](https://polyhaven.com/a/leafy_grass)采用1K漫反射与 OpenGL 法线贴图，作者Charlotte Baglioni，资产为[CC0](https://polyhaven.com/license)。草地只提供视觉材质，不表达本地区真实土地覆盖。Natural Earth数据采用[公共领域条款](https://www.naturalearthdata.com/about/terms-of-use/)。

TU-3000来自工作区已有[TerraUrsa教学附件](https://terraursa.com/wind-lab/turbines/tu-3000.html)，不是夏李实际机型。原件含2,470节点、2,272网格实例及113,804三角形；单台归并细模保留全部源三角形，归并为181个primitive；外观版保留塔筒、机舱壳、轮毂壳及叶片，17个primitive、18,296三角形。两个主要派生模型的轮毂高约90 m、叶尖最高约145 m，源模型无动画片段；程序旋转只可标注模拟。细节见[模型说明](../../output/xiali-spatial-demo-20261020/assets/models/README.md)和[模型清单](../../output/xiali-spatial-demo-20261020/sources/models-manifest.json)。

模型开放再分发许可未核实；本包的原件、派生模型、用户附件和配准用商业影像仅保留本机。配准影像不作为浏览器地形贴图、不打包公开分发。Copernicus原始许可和衍生来源声明在数据包内保留；开放地形和CC0贴图的许可不延伸到其他素材。整个 `output/` 交付不进入 GitHub。

### 6.1 风叶运动

当前19个图示机位的默认演示转速按`4.48+((placementIndex*7)%19)*(5.52-4.48)/18 rpm`分配，范围4.48–5.52，平均5 rpm，全部不同；此前17台版本用0.065步长，仅作为历史记录。初相位也不同，“恢复默认”使用各自初始转速。仅旋转原模型`Rotor`组及其外观实例，转轴局部+Z，枢轴`[0,90,6.67]`，塔筒和机舱固定。外观实例对已烘焙几何应用`T(base) T(pivot) Rz(angle) T(-pivot)`，细模应用相同相位；没有接入真实转速。暂停/恢复不跳相位，隐藏页面暂停刷新。风叶默认开启；系统“减少动画”只影响普通镜头切换，不改变风叶开关或用户主动暂停选择。

## 7. 从塔基到机舱的连续导览增补（2026-10-20）

首轮沿用同一技术验证包，内部路线为 **CT塔基信号柜 → 偏航机构 → CN1机舱动力柜 → 齿轮箱 → CN机舱信号柜 → 变压器**。六个定位对象之间插入三段塔筒仰视，末段增加机舱望向风场的近水平镜头，共10个内部镜头。首轮完整演示结束返回风场；2026-10-21新增偏航/调速末段后，两种播放均以整机视角结束并可继续手动调整，见§12。

### 7.1 镜头与显示合同

[interior-tour.json](../../output/xiali-spatial-demo-20261020/data/interior-tour.json)保存各站`eye`、`lookAt`、构件引用、动画和停留时长。坐标相对教学模型塔底，单位米，X东/Y上/Z南。通过MapLibre公开`calculateCameraOptionsFromTo`换算相机，局部路径使用`easeTo`，中心高程继续经公开回调平滑插值；未使用内部transform对象或第二个画布。

- 上升镜头眼点依次约7、32、64m，观察点在各自眼点上方；实测俯仰值约153.6°、154.5°、157.0°，观察射线Y分量为正，是真正的向上仰视。以0°为垂直俯视、90°为水平的地图相机约定记录，不能把该数值直接当工程姿态。
