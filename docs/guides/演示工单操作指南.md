# 演示工单操作指南

2026-10-25，Demo-PDS。工单与排查结果为模拟演练；工程对象、原有照片和标注从OntoBase受保护读取。项目定义归属、独立安装事实及照片适用性分别核实。

1. 使用本人OntoBase账号登录[ONTOVis测试站](https://vis.ontobase.ai/)，在“项目中心”选择PDS风电场（Demo-PDS），待访问权核对完成，点击“进入项目”，再进入“工单”。
2. 当前有20条演示工单，来源为7类典型故障码的独立模拟事件。选择待受理工单，点击“受理并诊断”，再点“编辑方案”。已关闭工单保持只读，需“重新排查”后编辑。
3. 在“本单诊断排查”编辑原因假设、排查步骤及关联对象，按实际观察选择“已记录观察”“资料缺口”或“不适用”，填写结果说明、结论和复核依据。原因保持候选时不需要虚构支持结论；选择支持/排除必须填写依据。可添加/删除假设和步骤，上限分别6/12。每张工单独立保存，不修改源知识规则。
4. 点击步骤的对象或展开“来源参照图与柜体导航（只读）”。CN2是机舱信号柜、CN1是机舱动力柜；柜内已登记直属对象分别264/180个，每页50条。可用“下一页”“首屏”，或输入完整主位号“查阅对象”，例如CN1的`=WEC+CN1-1B4`、CN2的`=WEC+CN2-15G1`。后端核对唯一完整项目主位号、修订和登记父级；身份待审仍显示待审。
5. 点击已有照片，系统校验固定版本及显示摘要，按原标注大小自动放大、居中并滚入可见区域；交互与OntoBase平面照片一致：滚轮以鼠标位置为中心缩放、按住左键平移；“定位标注”返回来源区域，“适应窗口”显示整张照片。以整图适应窗口为100%，范围50%～1600%，按钮每次按1.3倍缩放；自动定位保留标注周边，不改变照片像素与原区域。框为“来源标签区域”时只表示原标签位置。没有关联时保留缺口。
6. 查看照片后，可在相应步骤点“引用已查看照片”，把对象、固定版本和摘要加入本单说明。点击“保存诊断方案”；未保存时切换页面会提示保留编辑或放弃。历史保留操作者、时间及原快照，可在“诊断修订历史”读取。
7. “开始排查”后完成四项清单及演示处理说明，再“提交复核”→“复核并关闭演练”。后端要求各步骤结果、说明、结论和复核依据已保存；仅勾选清单不能关闭。退回或重新排查保留定义与历史，清空结果供重新核对。只读成员没有写入动作。

## 模拟报警与工单入口

2026-10-26增补。进入PDS风电场（Demo-PDS）后打开“数据与告警”，可见13001、13002、13003、13004四个模拟故障数据集。选择故障码后查看发生/恢复记录、传感器与独立参照等趋势；播放/暂停或拖动三分钟时间轴，坏质量处显示缺口。页面持续标为“模拟回放”，不会变更工单或确认源报警。

点击“相关工单”进入当前项目工单列表并按故障码搜索，例如13002对应002/009/016三条。再按上述工单流程受理和排查；回放报警与工单当前状态分别保留。其他项目无来源时明确提示未配置，不显示Demo-PDS数据；未进入项目前此菜单仍禁用。详见[查看契约](../contracts/模拟报警查看契约.md)。
