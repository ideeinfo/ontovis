# 演示工单操作指南

2026-10-25，Demo-PDS。工单与排查结果为模拟演练；工程对象、原有照片和标注从OntoBase受保护读取。项目定义归属、独立安装事实及照片适用性分别核实。

1. 使用本人OntoBase账号登录[ONTOVis测试站](https://vis.ontobase.ai/)，在“项目与访问”选择PDS风电场（Demo-PDS），点击“查看场景”，再进入“工单”。项目卡片只核对访问权，点击“查看场景”后才进入该项目。
2. 当前已有固定20条演示工单，不必再次初始化；重复初始化不会重置原批次。选择工单，查看故障码、模拟报警和诊断参照链。首批为7类典型码的20次独立模拟事件，并非20种厂家码。
3. 点击图谱的CN2机舱信号柜或CN1机舱动力柜。“柜内对象”读取OntoBase已登记的直属对象，当前分别264/180个，每页50条，可用“下一页”和“首屏”。原7号演示安装树、旧模型组件CN继续保留，不冒充现场安装或新定义。
4. 点击柜内对象，或输入完整位号后“查阅对象”，例如CN1的`=WEC+CN1-1B4`、CN2的`=WEC+CN2-15G1`。后端核对唯一完整项目主位号、当前对象修订和已登记父级；短码、其他柜级或未登记对象会拒绝。标识仍待审核时会明确显示。
5. 点击已有照片。照片保持固定内容版本，校验实际显示资源摘要；长图打开后滚到第一处已有标注。框为“来源标签区域”时只表示原标签定位，不扩大为整台设备范围。可以放大/缩小和适合窗口；没有原关联时保持缺口。
6. 当前管理员可“受理并诊断”→“开始排查”；完成四项清单并记录演示处理说明后“提交复核”→“复核并关闭演练”。可保存、退回或重新排查，所有提交保存操作人/时间、版本及幂等回执。只读成员没有这些写入动作。

来源诊断规则保留ON-SHORE目录的适用范围与证据缺口，不自动确认Demo-PDS根因，不触发现场设备控制或外部派单。当前已完成两柜真实照片、两条实际演示工单关闭、重启并正常重新登录回读。001/007为已关闭r5，其余18条待受理；信号柜15G1只作为已登记对象导航样本，不据此认定13058故障器件。后台、合成流程及实际证据分列于[执行记录§90](../plans/开发执行记录.md#90-柜级定义与直属对象补齐及长照片定位2026-10-25)。
