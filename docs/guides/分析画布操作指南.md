本项目已接入受限 Qwen 整理，可在画布工具栏点击“分析助手”。配置、资料范围与停止说明见[AI策略与分析助手操作指南](AI策略与分析助手操作指南.md)。

## 打开完整案例

1. 登录，在“项目中心”选择 **PDS风电场 / Demo-PDS**，点击“进入项目”。
2. 进入“数据与告警”，选择 **13001 · 柜温高报警 · 传感器读数偏高演练**，点击“进入分析画布”。
3. 系统继续已保存的 **13001 · 测量偏差完整分析案例**，带入当前报警；“加入资料”中的对象和资料默认按该报警推荐。也可以直接在“分析画布 → 画布列表”中打开该案例。
4. 初始交付r4为15张卡，后续编辑按最新保存版本继续；点击“适应全部”查看整体，或使用画布缩放、平移查看局部。初始案例涵盖九类资料：对象、图纸、文档、照片、三维模型、趋势、报警、历史工单、分析记录。

选中 **13001 · 柜温高报警 · 独立复发演练** 后进入画布，可打开 **13001 · 独立复发与历史对照**。它有5张本次调查卡和12张固定历史参考卡；本次事件、时间窗口、笔记独立，原分析r3保持。重复进入同一事件会继续该分析，不重复复制。历史复用目前限同项目、本人可读的分析。

## 将故障报警加入画布

- 从“数据与告警”选择报警，点击“进入分析画布”，系统自动带入报警卡并继续同一事件的已有分析。
- 在已有或空白分析中，点击工具栏“加入资料 → 故障报警”，优先显示当前事件。可拖动报警行到画布，或点击右侧“＋”；同码复发保留独立事件与时间窗。
- 空白分析加入首个报警后，以它为本次推荐上下文；进入“加入资料 → 趋势”选择该事件的信号，也可继续选择相关对象、图纸、手册等。后续加入其他报警作为补充，不自动替换当前事件。
- 当前报警来源为明确标识的模拟数据；加入来源卡和布局后点击“保存”形成分析修订。

## 查阅和组织资料

| 操作 | 用法 |
| --- | --- |
| 添加资料 | 点击“加入资料”，选择工程对象、图纸、文档、照片、三维模型、趋势、故障报警、历史工单或笔记；实际资料可拖入、点击右侧“＋”或多选加入。拖入按释放位置落卡，相同固定资料会定位已有卡 |
| 补充检索 | 先选报警或对象，再按当前项目名称/位号补充；不要求先检索全项目资料 |
| 移动与缩放 | 拖卡片标题移动；拖四边或四角改变尺寸；Shift多选，缩放时Shift保持比例；固定卡不参与移动/缩放 |
| 画布导航 | 按住鼠标中键拖动；也可按住空格或选“平移工具”。光标在卡片上时，滚轮同样缩放整个画布；资料面板内滚轮滚动列表，拖动不会选中文字；右下缩放25%—150%，“适应全部”查看全貌 |
| 整理 | 使用多选、分区、整理布局；支持撤销/重做。移除卡片只改变分析布局，原资料保留 |
| 来源关系 | 实线显示模拟报警显式对象映射、已有对象归属、照片/图纸定位、有效模型绑定、图纸引用和故障手册；虚线标识名称候选、历史绑定或人工引用。点击关系打开目标并定位，右侧查看具体依据和缺口 |
| 人工关系 | 卡片更多菜单添加资料引用、原因假设、支持依据或反证，填写依据；详情可查看与编辑，人工连线不会变成工程关系 |
| 笔记 | 分别编辑观察、原因假设、检查步骤、检查结果、反证与缺口、下一步；每份分析独立保存 |

在卡片内点击“打开图纸 / 打开照片 / 打开文档 / 启用三维查看”，可以同时查看多张资料；点击各卡片工具栏的“收起预览”仅收起当前卡。

点击资料标题或“展开查看”打开详情，已经打开的其他卡片仍保留。大文件按需读取，慢网显示进度状态并允许取消、重试；不会在进入画布时同时加载全部原图和模型。

## 案例中的具体资料

- **对象与柜体**：主对象为`=WEC+CN1-1B4`，所属CN1机舱动力柜。CN2是机舱信号柜，不根据名称或模型几何重新定义归属。
- **工程分类**：对象卡优先显示来源已登记的标准分类，例如`BTA · 温度变送器`，展开查看保持一致。“对象范围”另指项目定义或安装对象；“定义/安装范围未标注”不表示工程分类缺失。
- **图纸**：可打开温度传感器及机舱动力柜供电固定图纸。展开后可浏览对象、端口、连接和跨页引用，列表与图面相互定位。对象按类型分组，端口按“类型 → 对象 → 端口”分组；类型默认展开，端口的对象层按需展开。分组右侧显示当前批次数量，可输入类型名称/代码、对象名称或端口筛选；图面点击会自动展开相应分组。温度页189可定位1B4；/225.5引用可打开页228的PLC模拟量输入模块。供电页缺少与当前文件一致的热点时显示整页，跨页引用不等于电气线路已闭合。
- **故障代码手册**：实际《M0100003504-MySE2.X-4.X风力发电机组运行状态及故障代码手册》已加入，默认打开13001及触发条件的已发布知识节点；点击原文证据定位第48页，也可按需浏览其他节点。该发布仍有内容覆盖和适用范围限制。
- **文档**：《13001 模拟测量偏差试验说明》为本次自编的软件演练资料，共4页，可按页码和章节定位。它不是厂家检修手册。
- **照片**：打开《机舱动力柜_左侧.jpg》，先显示快速版本并放大居中到1B4标签；“查看原图”可读取4148×11343原件。滚轮以指针为中心缩放，按住左键平移，以当前图片像素为基准显示实际比例，可通过“100%（1:1）”查看像素原大并继续放大（最高1600%），使用“定位标注”或“适应窗口”返回。
- **模型**：当前项目共享绑定已接续到OntoBase固定项目应用，新加入的模型卡按共享对象或所属柜体映射定位。完整构件树、三维拾取和属性相互联动；可同时打开多张模型卡，各自保留构件选择与视角，卡片尺寸变化时渲染区同步铺满。原13001案例r5固定旧来源与当时的候选说明；源对象修订已变化时保留提示，不把当前绑定静默写入历史。代理几何用于空间参照，不代表现场柜体精确测量。
- **趋势与报警**：模拟传感器读数72°C，独立参照约24°C；第30秒报警、第150秒恢复、第90秒保留坏质量断点。不同时间窗与量纲分别处理，可使用“趋势对比”和“时间范围”。
- **工单和笔记**：工单卡读取固定历史修订；排查记录保留X91后跨页源点、独立现场测量等缺口，不自动确认根因或关闭工单。

温度对象尚无确认的文档知识节点映射；新的柜体与单台设备通过源端固定项目应用建立共享定义关系，旧分析仍保留当时的固定引用和缺口，不按同名对象猜测或改写历史。

## 保存、历史和工单

编辑区顶部的“画布列表”始终可用，可直接隐藏或召回左侧列表；列表右上角也可隐藏。打开“加入资料”不会关闭列表，切换这些面板不会丢失未保存内容。窄窗口列表以浮层显示，可以先隐藏列表以使用画布，再随时召回。

列表每行的“…”或右键菜单提供“移至回收站”，确认时会提示是否存在当前未保存修改。列表中的“回收站”可查看已删除画布，打开后为只读；点击“恢复画布”即可恢复原画布及全部修订。已有工单关联的固定版本仍可查看。当前不提供永久清除。

“保存”写入新的分析修订；“保存当前视图”将当前画布视角纳入修改，再保存分析。照片和模型视角也随分析保存。浏览、拖动、记录与工程结论确认是不同动作。

“修订历史”可以读取旧版；恢复会追加新修订，保留原历史。两个页面同时修改时提示冲突，保留本地内容，可以另存副本或明确重读。

“保存并关联工单”关联明确保存的分析修订。分析后来保存r4，不会将工单原r3引用悄悄替换；再次关联才新增记录。当前完整案例和独立复发均已关联演示工单001，工单原状态保持。

标题栏按资料类型区分：图纸蓝、照片橄榄绿、文档紫、模型靛蓝等；深浅主题都保持文字对比度。

## 当前设备适用资料与项目文档库

“加入资料”新增两个独立入口：

- **当前设备适用资料**：先选择安装设备卡的“推荐相关资料”，由源端按该设备实际型号和角色解析。共享工程定义仍打开原图纸和对象定位资料，不能代替单台设备身份。
- **本项目文档库**：按名称搜索、分页读取有权访问的PDF和照片，不要求已有对象关联、框选或已发布知识。

选入分析只登记本人当前分析的固定文档版本，不修改OntoBase型号共享配置。普通照片标记为“项目照片 · 未声明对象定位”，显示整图并保留原尺寸入口，不生成对象定位关系；原对象定位照片仍保留框选。PDF固定到具体文档版本和页码，未发布知识时也可读原文；需要引用知识节点时再选择其已发布固定来源。
