# AI 策略与分析助手操作指南

2026-10-29，测试站首批仅 Demo-PDS 已批准启用。使用现有阿里云 Qwen 服务，凭据仍由 OntoBase 服务端管理；当前没有现场数据源，助手回答不能确认现场故障根因。

## 启用项目策略

1. 登录[ONTOVis](https://vis.ontobase.ai/)，从“项目中心”进入 **PDS风电场 / Demo-PDS**。
2. 打开“AI 策略”。核对批准服务、接收方和允许资料类型，选择“允许本项目显式发起分析”。
3. 按需收紧读取次数、并行数及时间上限。首批上限为 **8 次读取、2 并行、120 秒**，每次最多一次模型调用和1800输出token。
4. 点击“预览有效配置”，检查差异，再点“使配置生效”。只有本人当前具有项目管理员权限时可配置和运行；管理员身份不代表诊断专家资格。
5. “版本历史”可回滚旧配置。回滚生成新修订，保留原记录；关闭或收紧策略会停止受影响的运行。其他项目默认关闭，不能通过复制策略扩大批准服务的项目范围。

项目策略没有密钥、任意地址或脚本输入。源端目的地/模型/凭据配置发生变化时，刷新服务后再发起；不自动采用另一个供应商。

## 从完整案例提问

1. 打开“分析画布”，选择 **全过程测试20261029 故障13002**，确认已保存的分析修订。新建画布应先加入报警和推荐资料并保存，才能使用固定资料提问。
2. 点击工具栏“分析助手”。在右侧勾选本次需要的资料；例如模拟13002报警、故障代码手册、传感器温度和独立参照温度。
3. 可选“查看拟发送摘要”检查外发内容；这一步只读取资料，不调用模型，也不是发送前的必经操作。模型只收到所选模拟报警、趋势统计和脱敏文本摘要；图纸、照片、模型只发送定位或绑定元数据，不发送图片、几何或整库。
4. 输入问题，例如：

   > 请对比模拟13002报警、两条温度趋势和故障代码手册，列出支持依据、待验证假设、反证与缺口，并提出下一步核验；不要确认现场根因。

5. 点击“发送”。页面显示读取、Qwen整理、引用校验，随后分为“观察 / 待验证假设 / 缺口 / 下一步核验”。E编号可定位画布上的原资料卡；编号只对应本次选择，不是新的工程身份。
6. 需要保留时点击“加入本次分析笔记”，再使用画布原有“保存”入口。加入笔记可撤销，系统不自动保存笔记、确认结论、改构件绑定或关闭工单。“本次用量”可查看已返回的模型调用及token统计。

柜内定位照片属于同项目同型号共享资料；现场照片属于单台设备。摘要仍保留该范围和模拟/质量标记，不能把共享定义当作单台现场证据。历史固定资料不可用时显示缺口，不自动换成新版本。

## 停止、失败及重新进入

- “停止”先显示等待后台确认，再显示“已取消”；停止后的迟到回答不采用。若已发送到供应商，取消不能保证供应商没有计量，未收到用量回执时不显示虚构的零消耗。
- 关闭助手、切换项目或会话时尝试停止当前运行。重新打开不会自动续跑或重发；服务重启后的未完成运行记为中断。
- 启动结果因网络问题不确定时，先点“检查运行”，避免重复调用。资料、权限、配置或引用校验失败会明确提示；不会伪装为分析成功。
- 运行回执持久保存用于审计和备份；本批没有独立的“历史对话列表”，不是多轮自动检索助手。后续通用图邻域工具按Q-19另行实施。
