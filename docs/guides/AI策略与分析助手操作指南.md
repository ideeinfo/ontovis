# AI 策略与分析助手操作指南

2026-10-29，测试站首批仅 Demo-PDS 已批准启用。使用现有阿里云 Qwen 服务，凭据仍由 OntoBase 服务端管理；当前没有现场数据源，助手回答不能确认现场故障根因。

## 启用项目策略

1. 登录[ONTOVis](https://vis.ontobase.ai/)，从“项目中心”进入 **PDS风电场 / Demo-PDS**。
2. 打开“AI 策略”。核对批准服务、接收方和允许资料类型，选择“允许本项目显式发起分析”。
3. 按需收紧读取次数、并行数及时间上限。首批上限为 **8 次读取、2 并行、120 秒**，每次最多一次模型调用和1800输出token。
4. 点击“预览有效配置”，检查差异，再点“使配置生效”。只有本人当前具有项目管理员权限时可配置和运行；管理员身份不代表诊断专家资格。
5. “版本历史”可回滚旧配置。回滚生成新修订，保留原记录；关闭或收紧策略会停止受影响的运行。其他项目默认关闭，不能通过复制策略扩大批准服务的项目范围。

项目策略没有密钥、任意地址或脚本输入。源端目的地/模型/凭据配置发生变化时，刷新服务后再发起；不自动采用另一个供应商。

## 从完整案例提问

1. 打开“分析画布”，选择 **全过程测试20261029 故障13002**，确认已保存的分析修订。新建画布应先加入报警和推荐资料并保存，才能使用固定资料提问。
2. 点击工具栏“分析助手”。“当前对话”恢复本修订已保存的对话；需要另起问题时点“新对话”。展开“本次资料”，每份资料独立成行，左侧勾选框、右侧类型和完整名称；点击名称或使用空格键切换。推荐选择模拟13002报警、+CN1-1B4、故障代码手册、传感器温度和独立参照温度，共5份。选中行显示本轮E编号，取消后重选会按新顺序编号。
3. 可选“查看拟发送摘要”检查外发内容；这一步只读取资料，不调用模型，也不是发送前的必经操作。模型只收到所选模拟报警、趋势统计和脱敏文本摘要；图纸、照片、模型只发送定位或绑定元数据，不发送图片、几何或整库。
4. 输入问题，例如：

   > 请对比模拟13002报警、两条温度趋势和故障代码手册，列出支持依据、待验证假设、反证与缺口，并提出下一步核验；不要确认现场根因。

5. 点击“发送”。页面显示读取、Qwen整理、引用校验，随后分为“观察 / 待验证假设 / 缺口 / 下一步核验”。E编号可定位画布上的原资料卡；编号只对应本次选择，不是新的工程身份。
6. 需要保留时点击“加入本次分析笔记”，再使用画布原有“保存”入口。加入笔记可撤销，系统不自动保存笔记、确认结论、改构件绑定或关闭工单。每轮“本轮用量”可查看已返回的模型调用及token统计。

柜内定位照片属于同项目同型号共享资料；现场照片属于单台设备。摘要仍保留该范围和模拟/质量标记，不能把共享定义当作单台现场证据。历史固定资料不可用时显示缺口，不自动换成新版本。

固定手册资料会读取所选知识节点周围最多两跳的有限关联，保留关系类型和证据页。13002当前已发布知识只有定义和触发条件；摘要会明确提示没有原因和检查步骤条目，不用演示规则补造手册内容。回答中的E编号先定位原手册卡，再“展开查看”可核对知识节点和第49页原证据。

## 工程图谱与继续追问

展开“工程图谱”，起点选择画布已有的工程对象，无需全项目检索。服务按项目和精确UID读取最多两跳、24节点/48关系；可在返回邻域内按关系类型或名称筛选。展示柜内工程定义、安装采用定义、图纸定位、候选连接和已确认文档知识映射；不会靠对象同名推断身份。

当前1B4可读到CN1、X91及图纸定位。接线来自待复核的端口导入，统一标为候选，同一对象对的多条线合并展示，展开“来源记录”保留每条连接和端口记录。定义归属、资料定位和候选接线均不代表现场确认。没有知识映射或达到数量预算时明确显示缺口，不把演示规则当成正式手册。

直接在“继续提问”输入下一问即可，例如：

> 继续上一轮，把手册明确给出的条件、尚待复核的图谱关联和现场仍缺的证据分清。保留前轮假设为待验证内容，不推断已确认的接线方向。

每轮仍为最多8份资料/2并行/120秒/一次模型调用；最近最多4轮、6000字符可参与上下文。旧轮来源必须仍在当前选择范围，且固定修订、摘要、检索结果和服务均适用；取消勾选的资料不会经历史对话继续外发。旧假设不升级为事实。每轮保存自己的E引用映射，下一轮重排资料不会改变旧回答指向。

切换对话只读取记录。“新对话”保留所选资料，首次发送时才创建记录。对话绑定本人、项目和已保存的分析修订；另存为新修订后显示该修订的对话，旧修订记录仍保留。历史页若涉及超过单次预算的不同资料，较早一轮可点击“检查本轮”单独回读原回执，不调用模型。

## 将助手建议整理到工单

1. 在可编辑且已经保存的分析画布中，点击某一轮回答旁的“整理到工单”。系统优先列出当前工单或同故障码的本项目工单；也可按编号查找。核对目标工单编号，不能把同故障码直接当成同一现场设备。
2. 工单须已受理并处于“诊断中”或“排查中”；未受理时可“打开工单”正常受理，关闭或待复核的工单只支持查看。原来的关闭记录不会被自动重开。
3. 勾选并编辑原因假设、排查步骤和需补的证据。观察只供参照，不会自动写成工单结果。假设加入后为“待核候选”，步骤为“待排查”，结果和结论不会自动填写。每项保留原建议及该轮固定E引用。
4. 点击“加入本单排查”。原诊断和记录保留，所选条目追加保存，工单处理状态不变。本单最多6条假设/12个步骤；超量时减少选择或整理既有方案。保存结果不明时用“检查本次保存”回读同一请求，避免重复加入；版本冲突时编辑仍保留，重新读取后比较。
5. 在工单“本单诊断排查”继续编辑或记录观察/缺口。下方“助手建议采纳记录”保留采纳时的文本、原建议和固定引用；后来移除条目不会抹掉历史。“回看本轮分析”打开固定分析修订和原轮回执，仍受本人分析和当前来源权限控制，不再次调用模型。

预览、保存和回看只校验原记录，不重新调用模型。柜内共享照片与单台现场照片范围保持；结论确认、外部派单和现场执行继续不启用。错误建议无需采纳，也不必先加入分析笔记；工单整理与笔记保存分别操作。

报警摘要直接按事件时间计算发生至恢复间隔。当前13002演练为120秒，手册第49页的2秒是触发延时，二者不能替换。资料、检索结果或服务修订变化后，原回答会保留但暂不显示，也不能继续采纳；核对当前资料后可正常另起分析。

## 将排查进展带回分析

1. 在工单中记录人工依据、步骤观察或资料缺口，并点击“保存诊断方案”。“助手建议采纳记录”同时显示原条目目前是否保留、已调整或已移除，以及已保存的依据和结果；“定位当前条目”可跳到对应假设或步骤。有未保存编辑时先保存或放弃，再定位。
2. 从工单进入分析，或打开已有画布，在工单资料卡点击“工单进展”。左侧是画布当前固定版本，右侧是本单最新已保存版本；默认只看变化，可切到全部。假设和步骤按原条目身份对应，同名重建不会冒充原条目。窗口内滚动不会缩放背后的画布。
3. 确认后点击“载入本单进展”。这只替换当前工单卡的固定资料来源，保留卡片位置、大小、笔记和连线；尚需点击画布“保存”，形成新的分析修订。相同版本、只读分析或来源不可用时不能载入；保存前工单再次变化会提示版本冲突，不自动覆盖。
4. 打开“分析助手”，选择更新后的工单和本次需要的报警、趋势、手册，再发送问题，例如：

   > 对照本单已登记的人工依据和步骤结果，说明哪些假设仍待核验、哪些资料仍缺。未登记结果不能推断现场没有执行；不要确认根因。

5. 新分析修订使用自己的对话，旧修订及原轮引用保留。更新资料、保存画布和打开比较都不会自动提问、关联工单或改变工单状态；需要继续整理建议时仍明确选择目标并操作“整理到工单”。

工单摘要只提供有限的人工记录、状态、原顺序编号、总数和省略数，优先带入有记录的条目，并列出未登记步骤编号；不是完整工单。`pending`只表示未登记结果，不能据此认定未执行。模型回答仍须核对原资料，不能把模拟记录或“已记录观察”当作现场确认。原采纳记录和被移除条目的历史保持。

测试站示例为 **工单进展联动验证20261029 13002**（r3，13张卡），工单卡固定009的r4。操作截图、实际用量及恢复记录见[排查进展回流验收](../../output/q25-workorder-progress-20261029/README.md)。结论确认继续关闭。

## 在工单直接核对原引用

1. 打开009工单的“助手建议采纳记录”。每条已采纳建议下方按原轮显示 **E1 · 故障报警、E3 · 文档、E4 · 趋势** 等按钮；编号属于这条原建议，不随当前画布资料顺序改变。
2. 点击“E3 · 文档”，直接进入原引用只读页，显示工单编号、采纳时工单版本及原分析版本。本例默认定位13002已发布知识节点；“查看原文”打开固定第49页及原区域，可使用原查看器浏览知识与出处。
3. “E4 · 趋势”打开当时固定时间窗的传感器曲线，质量断点保留；“E1 · 故障报警”打开原模拟事件。该入口只挂载所选资料，不加载整张画布或助手对话，也不再次发送模型。
4. 点击“返回工单”，回到009，仍为已保存的r4。核对不会改写条目、结果、引用或工单状态；需要了解当时整轮推理时，仍可用“回看本轮分析”。

图纸/文档的分析身份与资料授权并行读取，二者均匹配才显示。访问沿用本人分析和当前资料权限：能查看项目工单不代表自动获得其他人的私人分析权限。原引用缺少固定身份时保留历史和原回看入口；无权、版本不可用或身份不一致时不换成同名或最新资料。照片和模型沿用原固定资料完整查看器，不因引用而升级为现场证据。

实际截图、版本、读取小样本及本批零新增模型调用见[原引用核对验收](../../output/q25-workorder-references-20261029/README.md)。结论确认保持关闭。

## 停止、失败及重新进入

- “停止”先显示等待后台确认，再显示“已取消”；迟到回答不采用。若已发送到供应商，取消不能保证供应商没有计量，未收到用量回执时不虚构零消耗。
- 刷新或重新进入可恢复对话。运行中关闭助手或切换项目会停止对应请求；重启中断不会自动重发问题。
- 提交结果不明确时用“检查运行”读取同一回执；短暂网络/网关状态错误最多重试3次，权限和修订冲突不自动重试。不要反复点击发送来检查进度。
- 来源、检索结果或策略变化时隐藏受影响的旧回答，原记录保留；缺少或取消勾选的来源也不会被偷偷用于下一轮。发生对话版本冲突时，重新打开该对话读取最新头再继续。
- 回答、历史记录与图谱查看均不会自动保存分析笔记、确认工程结论、改绑定或关闭工单。原照片/模型/图纸的正常打开流程保持，不要求逐张进行AI核验。

本批实际验收及文件清单见[工程图谱与多轮对话验收](../../output/q19-graph-conversations-20261029/README.md)，接口约束见[服务契约](../contracts/工程图谱与多轮分析对话契约.md)。通用自主工具循环、真实现场源及结论确认仍不启用。


## 场景告警演练

1. 进入项目的“场景与可视化”，打开已布置且关联设备库设备的场景，在“浏览”模式点击“告警演练”。
2. 选择一台已布置设备及模拟故障，点击“开始演练”。只给该安装实例显示模拟标记和边框，同型号其他实例不跟随变化。
3. “定位设备”主动移动视角并收起面板，订阅继续；用面板右侧箭头展开。面板显示报警、恢复或过期状态。隐藏/未加载的模型不会自动加载。
4. 切换设备或故障、关闭面板或离开场景会停止旧订阅。不会自动保存场景，不代表真实测点映射或现场故障确认。

## 按问题检索已选资料

在固定分析中打开“分析助手”，默认选择最多6份不同类型资料，可自行调整。“查看拟发送摘要”会按当前问题和选择执行只读检索，不调用模型；修改问题或选择后需重新预览。

例如：输入“检索13002，核对触发阈值、2秒延时与模拟事件间隔，并列出缺口”。在已选手册的固定发布版内精确查找故障码，再读取有限关联知识和原文；所选工程对象按UID读取两跳关联。手册没有命中、出现歧义或缺少原因/步骤时明确保留缺口，不用演示规则补造。每轮仍最多8次逻辑读取、2并行、120秒、一次Qwen调用。满额选择8份时不再额外定向查码；减少选择可留出额度。当前一份手册每轮只查问题中的首个五位故障码，多码对比可逐轮进行。

回答的“检索过程”显示E编号、对应资料和查询码，可“定位检索依据”或点击回答中的E引用，打开同一固定文档版本的命中节点与原页。原文优先定位故障码或语义文本，避免落在故障等级等孤立数字上。工单采纳继续由用户选择并编辑条目；固定来源、检索锚点和原建议均保留。暂不启用结论确认，不自动写入工单或发送未选资料。
