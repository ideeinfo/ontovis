# 天气接口操作指南

2026-10-30。入口：项目工作台 → 数据与报警 → 天气接口。首期接入 MET Norway Locationforecast 2.0，无需 API Key；新增配置默认关闭。

1. 用项目管理员账号打开“天气接口”，添加场景查询点。
2. 选择场景，填写便于识别的点名和 WGS84 纬度、经度。每场景一个点，最多 50 点；保存时截取到四位小数。不能把模型局部坐标或投影坐标直接填入经纬度。
3. 联系标识应为可联系技术维护人员的业务邮箱或 HTTPS 页面。默认链接为本项目公开 GitHub，支持问题反馈。此标识随查询发送给 MET Norway。
4. 点击该点“测试查询”。结果只预览，不保存或启用配置；测试只外发查询坐标和联系标识。
5. 核对查询点及预报时段后，勾选“启用本项目天气”，点击“保存配置”。管理员保存会产生新配置修订；版本冲突时重新读取并核对修改。
6. 在驾驶舱打开对应场景，右侧查看天气预报及来源。个人“按预报显示特效”开关不改写场景配置。停用项目天气后，后续读取不再外查。

3/6/12 小时为外部最小更新间隔，不是界面读取周期。刷新和多人打开时优先共用缓存；来源要求更晚更新时继续等待。页面未使用时不在后台定时抓取。限流、不可用、无当前时段或数据过期都会停止动态特效。

这里展示的是模式预报，不是现场实测。温度为近地 2 m，风速为地面以上 10 m，风向为来向。降水与天气类型对应标示的 1/6/12 小时时段。缺值显示“—”。查询点代表天气参考位置，不证明整个场景的测绘精度；不会据此计算风机转速、偏航或变桨。

数据来源与许可显示在天气卡内，数据按时段选择并归一化展示。服务与配置边界见[天气首切契约](../contracts/天气接口首切契约.md)。
