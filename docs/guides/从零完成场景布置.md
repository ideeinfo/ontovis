# 从零开始布置一个可保存的场景

> 2026-10-23：当前流程对应测试站已运行的 `2135e19`。本文是同一最终操作教程的文本维护版。测试数据位于[本批资源目录](../../output/workbench-upgrade-20261023/resources/README.md)，可下载[配套测试包](../../output/workbench-upgrade-20261023/ONTOVis-scene-test-resources-20261023.zip)，或打开[离线操作指南](../../output/workbench-upgrade-20261023/场景布置操作指南.html)。

适用于本批新版ONTOVis工作台。先解压资源包，保留models、terrain、imagery、sources和examples目录。测试中使用“测试场景”及“测试机组”名称，工程设备暂时留空；这些教学模型和合成位置不代表现场机位。

## 1. 登录并创建空场景

打开ONTOVis登录页，从右上角“登录”输入自己的用户名与密码。登录后确认顶部项目是你有管理权限的测试项目，进入左侧“场景与可视化”，点击“创建场景”，名称填“从零布置测试”。创建后先点击右上角“布置”。

如果某项上传、布置或保存按钮因权限禁用，使用项目管理员权限操作；不要为了测试改变其他人的项目授权。

## 2. 导入地形，并给场景设置地理位置

在左栏“模型资源”下切换到“地形”，点击“导入地形”，选择terrain/xiali-copernicus-dsm-3km.tif。填写：

| 字段 | 本测试填写 |
|---|---|
| 名称 | 夏李测试范围 · Copernicus DSM |
| 来源 | Copernicus DEM GLO-30公开DSM，原生窗口裁切，用于可视化测试，非工程测量 |
| 授权说明 | Copernicus DEM许可，来源与完整署名见sources/terrain-source.json和Copernicus-DEM-license.pdf |
| 高程基准 | EGM2008 正高 |
| 高度单位 | 米 |

确认有权在项目内使用，点击“上传并处理”。等待显示“处理完成”，选择该地形，点击“用于当前场景”。

系统会打开“设置地理位置”：局部锚点X=0、Z=0；经度113.183、纬度33.455；朝向0；离地偏移0。采用“各模型重新贴地”策略，点击“预览位置”，确认范围后点击“采用并保存”。本场景此前为空，不会带入其他场景的模型或设备。

## 3. 导入并采用概览影像

左栏“模型资源”切到“影像”，选择“导入影像”，文件为imagery/xiali-sentinel-20261013-20m-3km.tif。填写：

| 字段 | 本测试填写 |
|---|---|
| 名称 | 夏李测试范围 · Sentinel-2 2026-10-13 |
| 来源 | Copernicus Sentinel-2 L2A，2026-10-13，两景同轨真彩色的20米概览派生裁片 |
| 许可依据 | Copernicus Sentinel数据声明，来源链接见sources/imagery-source.json |
| 采集日期 | 2026-10-13 |
| 署名 | Contains modified Copernicus Sentinel data (2026) |
| 质量说明 | 20米概览，保留保守质量透明掩膜，非工程定位精度；地形高程仍来自DSM |

勾选“已核对本文件的使用依据”，点击“导入并校验”。选择完成的影像，点击“采用此版本”，再点击顶部“保存”。透明或覆盖以外区域保留原地形颜色，不补造地物。

## 4. 上传两种模型，各校准一次

切到“模型”子页签，用“上传模型”的加号先上传models/TU-3000-exterior-only.glb。名称填“TU-3000 · 外壳教学模型”，用途选“设备”，来源填写“用户已授权项目使用的TU-3000教学模型外壳派生，仅场景测试，几何/现场身份未核实”。确认使用权限，点击“上传并校验”。

展开这张模型卡片的“模型详情与校准”，点击“校准模型”。本包两模型的已核对输入一致：

| 项目 | 数值 |
|---|---|
| 单位 / 向上轴 | 米 / Y向上 |
| 基点X、Y、Z | 0、0、0 |
| 正面向量X、Y、Z | 0、0、-1 |

核对后勾选已检查单位/向上轴/朝向，保存校准版本。卡片显示“已校准”后即可地理布置。再按相同步骤上传models/TU-3000-full-teaching.glb，名称填“TU-3000 · 完整教学模型”，来源标为完整教学模型，并校准一次。

上传和校准会留下可追溯的资源版本；后续重复放置使用同一个固定版本，每台只新增独立场景实例。无需为每台重新上传或校准。

## 5. 放置并输入精确测试位置

先选外壳模型卡片，可点“预览”检查，再“返回场景”。点击“放置实例”，等画面出现“点击场景放置，Esc取消”提示后，再在地形上点击一个位置。切换到另一种模型时，先等待该模型资料读取完成，不要在提示出现前提前落点。右栏将出现实例属性；模型资源和固定版本在上方，关联设备先留空。

在右栏把“模型名称”改为“测试机组-02”。在“位置”区将坐标方式设为“经纬度”，根据examples/sample-placement.csv中同名行填写经度、纬度，朝向0，高度选“贴地”，离地高度0，点击“应用”。

继续按CSV的模型文件参考，再放其余测试实例。-01和-04使用完整教学模型，其余使用外壳模型。每次修改名称和位置后点击“应用”；模型卡片的版本选择无需重复。CSV坐标仅便于重复测试，不表示工程坐标精度。它是手工输入参考表，当前没有CSV一键导入入口。

只需操作验证时，也可先放一个外壳实例和一个完整实例。按Esc可取消尚未落点的放置操作。位置锁定后先解锁才能拖动/移除；“复制”创建新的实例，设备与内部构件关联不会照搬到新实例。

## 6. 保存、重开并核对

点击顶部“保存”，等待“已保存”。回到场景列表，再打开“从零布置测试”，确认地形、影像、实例数量和名称、位置均恢复。

选中不同实例，查看它们是否共享同一模型固定版本，同时各自名称和位置独立。打开模型卡片“模型版本”可查看资源历史；放置多个实例不应产生新的模型资源版本。场景保存形成的场景修订与模型版本是不同记录。

工程关联需逐台选择本台的独立安装对象，并经现有权限/版本核验；本测试无需创建安装对象或柜体。无几何子设备的分析身份和自身图纸也不应被空间宿主替代。

## 7. 可选：按中心和半径从公开源获取

直接上传本包素材与公开源获取二选一即可，不必重复导入相同区域。另建空场景后，进入“布置”→左栏“模型资源”→“获取公开地形与影像”。

1. “资源名称”填“夏李公开数据获取测试”。中心经度填113.183，中心纬度填33.455，“半径（km）”填3。支持0.5—10公里。也可在弹窗地图上点击，系统会回填中心坐标；填写或点击后再次核对数值及覆盖圆。
2. 同时选中“地形 · Copernicus GLO-30 DSM”和“影像 · Sentinel-2 概览”。地形是DSM，影像仅用于概览；来源日期和质量以实际获取结果为准，不保证自动取得2026-10-13这一景。
3. 点击“获取并加入资源库”，按阶段查看进度。需要取消时点击“停止获取”。重开弹窗或刷新后，可恢复本人最近任务以及中心/半径；它不保证外部公共服务持续可用。
4. 成功后关闭弹窗。资源先进入资源库，尚未替换场景。切到“地形”，选中处理完成的资源，点击“用于当前场景”，按第2节预览地理位置并“采用并保存”。再切到“影像”，选中获取的影像，点击“采用此版本”，最后保存场景。
5. 如需按地名查找，可使用“打开公开地图查找地名”外链确认位置，再回本页点击地图或输入经纬度。本页没有内建地名搜索框。

任务取消或来源失败时保持原场景；不要把资源获取成功当作场景已经保存。1公里范围曾有一次约12.06秒的真实来源获取观察，它不是3公里或所有网络条件下的时间承诺。公开网格及坐标输入都不等于工程定位精度，工程道路与场站边界目前允许留空。
