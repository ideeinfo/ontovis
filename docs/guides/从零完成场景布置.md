# ONTOVis 场景布置操作指南

修订日期：2026-10-24。本版追加环境渲染操作，适用测试站5a8ab58环境配置V1工作台。配图Word版见[本批操作指南](../../output/scene-environment-20261024/ONTOVis场景布置操作指南.docx)。

本指南从空场景开始，完成地形、概览影像、模型实例与观察路线的布置、保存和重开。主流程优先复用项目已有资源，另附公开数据获取、文件上传和设备图纸操作。练习名称使用“从零布置测试”和“测试机组”，工程设备关联先留空。教学模型与合成位置用于操作验证，不代表现场机位或工程精度。

## 开始前先确认

打开[ONTOVis测试站](https://vis.ontobase.ai)，从右上角“登录”输入已授权账号。登录后核对顶部项目；主导航仅显示图标时，可展开查看“模型中心”和“场景与可视化”。按钮禁用时先确认项目权限、布置模式和资源状态，不为练习修改其他人的授权。

最短流程：查看已有模型 → 创建场景 → 采用地形并设置地理位置 → 采用影像 → 放置实例并输入位置 → 保存并重新打开。连续放置、编组、路线和设备关联可在基础流程成功后追加；光照、天空、阴影和水面按第14—16节选配。

## 1 选择可复用的模型资源

进入“模型中心”，搜索“TU-3000”或其他型号。模型中心与场景左栏共用同一个项目资源库，无需再次上传场景中已有的资源。

1. 选中资源，确认状态“已校准”。点击“预览”检查几何，关闭预览后查看详情。
2. 多台布置优先使用“教学外观”或“外壳”资源；单机近景和内部构件测试使用“完整教学”资源。完整与外观模型是不同资源，内部构件能力也不同。
3. 需要历史文件时，展开“模型版本”，通过“选择固定版本”选择；常规重复布置沿用已选的同一已校准版本。
4. 点击“进入场景布置”进入场景列表。此按钮不会自动创建场景或放置刚选的模型，进入场景后仍需点击“放置实例”。

当前示例测试项目已部署20个型号的40个完整/外观资源。已有库接近当前模型容量预算，练习优先复用，不重复上传整套包；新项目确需上传时按第11节操作。

构件预览补充（Q-37）：点击“预览”后，左栏显示源模型构件树，右栏在未选构件时保留模型属性。在树中选择构件，或直接点击三维模型，可双向选中并直接定位；其他构件默认半透明，右栏显示所选构件自身的源属性。点击“仅显示所选”严格隔离，再点击“其他构件半透明”返回上下文；“恢复全部”恢复整机。树支持搜索、展开与收起；无几何节点保留属性，定位/隔离禁用；示意代理明确标识。关闭预览返回资源目录，场景资源的预览同样适用。这些操作不新增模型版本或场景实例。节点层级和属性来自源模型，不确认现场物理层级或设备事实。本段为后续功能补充，链接的17页Word仍为环境V1配图快照。

## 2 读懂资源版本与实例的关系

“场景内容”按“模型资源 → 固定版本 → 实例”分组。选中一台，右栏显示自己的“实例名称”和“实例ID”；“本景同版实例”只统计本场景内引用这个固定版本的实例数。“查看资源”定位到该实例实际引用的资源及固定版本。

| 记录 | 保存什么 | 何时新增 |
|---|---|---|
| 模型资源 | 可复用的模型与用途 | 首次上传新资源 |
| 固定版本 | 具体模型文件及校准结果 | 更新文件或保存校准 |
| 场景实例 | 单台名称、位置和独立关联 | 放置或复制一台 |
| 场景修订 | 地形、影像、实例、路线与环境配置 | 保存场景 |

例如，一份外观资源、一个固定版本放置10次，应得到10个独立实例。放置不增加模型版本，资源卡“模型版本（N）”的N也不是风机数量。型号属性资料另有修订，不作为新几何版本，也不自动改写OntoBase设备属性。

## 3 创建场景并采用已有地形

进入“场景与可视化”，点击“创建场景”，填写“从零布置测试”并确认。新场景先是未设置地理位置的局部场景，点击右上角“布置”。

1. 左栏选“模型资源”→“地形”，搜索覆盖练习范围且已处理完成的资源。
2. 查看来源、高程基准和覆盖范围，点击“用于当前场景”。不要用合成海面平面代替陆地DSM。
3. 首次采用地形时，在“设置地理位置”输入下表参数，点击“预览位置”。
4. 核对后点击“采用并保存”。取消预览保留原场景；已有模型时，应先核对整体变换再采用。

| 夏李练习参数 | 输入 |
|---|---|
| 局部锚点X和Z | 0，0米 |
| 经度和纬度 | 113.183，33.455 |
| 局部正面相对真北 | 0° |
| 离地偏移 | 0米 |
| 高度策略 | 各模型重新贴地 |

本例使用Copernicus GLO-30 DSM，EGM2008正高、单位米。DSM可能包含植被和建筑高度。项目中心和半径仅定义概览范围，不代表工程边界。没有合适地形时用第4节获取，或按第11节上传练习文件。

## 4 按中心和半径获取公开数据

在“布置”→“模型资源”点击“获取公开地形与影像”。复用已有数据、公开获取和文件上传按需要选择，无需重复导入同一区域。

1. 填“资源名称”，例如“夏李公开数据获取测试”；中心经度113.183、纬度33.455，半径3km。
2. 也可点击地图回填中心，再核对坐标和范围。底图不可用时仍能输入经纬度；“打开公开地图查找地名”是外链，本页没有内建地名搜索框。
3. 按需勾选地形与影像，点击“获取并加入资源库”，查看处理阶段与结果。支持半径0.5—10km，可用性受来源和网络影响。
4. 成功后关闭弹窗，到“地形”点“用于当前场景”，按第3节预览并“采用并保存”；再到“影像”点“采用此版本”。
5. 需要停止时点“停止获取”。已完成入库的资源仍保留，地形和影像可能部分成功；失败或取消均不会自动替换当前场景。

重开弹窗可读取本人最近任务。影像日期和质量以获取结果为准，不保证与练习包2026-10-13影像相同。出现未知结果时先查看原任务，避免反复新建相同请求。

## 5 采用影像并核对覆盖

“模型资源”切到“影像”，搜索与地形范围相符的已完成资源。核对日期、坐标、来源和质量，点击“采用此版本”，再点顶部“保存”。

1. 切到“场景内容”，确认地形与影像同时存在。用眼睛按钮先隐藏、再显示影像，对比地表。
2. 调整视角核对实际覆盖；透明掩膜和范围外保留原地表颜色，不补造地物。
3. 本练习使用2026-10-13 Sentinel-2的20米概览裁片，保留画面中的日期、分辨率与“非工程定位精度”标识。

影像提供地表外观，高程仍来自地形。工程道路和边界无权威资料时允许留空。原“场景显示”的选项继续保留；右栏“环境渲染”可设置新光照、天空、雾和局部阴影。陆地影像建议先用“资料原色”，按第16节核对后再选择照明显示。

## 6 放置模型并输入测试位置

在“布置”模式选“模型资源”→“模型”，搜索TU-3000已校准外壳/外观资源，点击“放置实例”。等画面显示“点击场景放置，Esc取消”，再点地形落点；“预览”不会创建实例。

1. 右栏“实例名称”填“测试机组-02”。
2. “位置”→“坐标方式”选“经纬度”，经度113.17762371、纬度33.45509459，朝向0°，高度“贴地”，离地高度0米，点击“应用”。
3. 再放完整教学模型，命名“测试机组-01”，输入经度113.17981199、纬度33.45194773，其他参数相同，点“应用”。
4. 点击顶部“保存”，等待“已保存”。先验证两台即可；完整六点练习见第13节。

重复放置沿用同版，不逐台上传或校准。Esc取消尚未落点的放置。“复制”创建独立实例，设备及内部构件关联不会照搬；锁定后先“解锁位置”才能拖动或移除。练习中设备关联留空。

点位越界或无有效高程时先核对地形范围、坐标，不随意改为“指定高程”掩盖问题。多台概览优先外观资源，完整模型用于需要内部结构的实例。

## 7 连续放置与批量调整

右栏打开“批量布置”。在“连续放置与吸附”勾选“连续放置”，按需选“网格”“角度”，再从模型卡点“放置实例”。连续点击地面会新增多台，Esc结束；吸附仅辅助编辑，不提高现场精度。

1. 用“场景内容”复选框或Shift点选模型，核对已选数量。
2. 输入“组名”，点“将所选编组”。编组管理实例，不合并设备身份。
3. 在“平面批量移动”填ΔX、ΔZ及“各实例朝向增量”，点“整批应用”。ΔX=10、ΔZ=0表示沿局部X平移10米。
4. 核对后保存；一次“撤销”可撤回本次整批操作。包含锁定、越界或无高程成员时整批保留原位，应先处理提示。

朝向增量逐台应用，不是绕组中心公转。新实例应分别核对名称、位置和关联。当前每景最多100实例，这是容量边界，不保证所有设备在100实例下稳定流畅。

## 8 保存命名视点与观察路线

调整整体视角，右栏打开“视点与路线”，输入“视点名称”为“场区远眺”，点“保存当前”。移到另一位置，再保存第二个视点。

1. 在“观察路线”填“路线名称”，点“新建”。
2. 用“选择视点”和加号依次添加，调整顺序、“飞行（秒）”和“停留（秒）”。
3. 点“预览”；播放中可“暂停”“继续”，“取消”恢复预览前视角。手动操作镜头会终止路线，后台期间不计路线时间。
4. 点顶部“保存”。视点和路线随场景保存，“保存当前”视点不能代替保存场景。

远眺默认停留3秒；实际内部定位到构件后保存的构件视点默认2秒。选中整机不会自动成为构件视点。换模型或坐标系后若提示“需重存”，重新定位并重存，再预览路线。

## 9 可选关联设备并查看自身图纸

基础练习无需创建工程对象。需要关联时，选实例→“选择设备”→选择本台独立安装对象→“关联此设备”。保存时若出现“确认设备关联变更”，核对后“确认并保存”。同型号各台不能共用一个安装身份。

1. 内部关联使用完整模型：点“关联内部构件”，从“项目对象”选柜体或子设备，勾选或拾取几何，点“更新构件关联”后保存。
2. 保存后选对象，点“定位对象”；多个表示时选择目标实例。
3. 右栏“图纸”→“打开图纸”，核对弹窗顶部关联对象、定位方式和页码。

无几何子设备通过最近有效祖先柜体定位，分析对象和图纸仍属自身。外观模型不具备完整内部结构。CT、CN1、CN已有演示记录，不重复创建；记录存在不等于现场身份及物理关系已核实。工程对象、资料及事实由OntoBase维护。

## 10 保存重开并完成检查

点顶部“保存”，等到“已保存”，回场景列表重新打开“从零布置测试”，检查以下内容。

- 地形和影像存在，日期、精度与覆盖提示正确。
- 实例数量、名称、坐标、朝向、高度恢复；实例ID各自独立。
- 同版实例归在同一固定版本下，放置没有增加模型版本。
- 编组、命名视点和路线仍在，路线可预览和控制。
- 如有工程关联，应逐台正确，子设备仍打开自身图纸。

“场景已有更新”会保留当前草稿；“重新读取”会放弃它，先判断需保留的修改。若“保存结果尚未确认”，先重试确认或读取服务端结果，不急于另建同名场景。只在“已保存”后退出、刷新或切换环境。

普通场景保存后供有权限的项目成员查看，无需额外发布操作。

## 11 可选上传文件并校准模型

新项目缺资源时才上传。模型中心或场景模型资源中的加号为“上传模型”，当前支持静态自包含GLB，单件上限20MiB。填写名称、用途、来源和使用依据，确认有权使用后“上传并校验”。

上传完成点“校准模型”，按文件清单核对单位、向上轴、基点和正面，保存校准版本；之后重复放置实例。更新几何用“更新模型文件”，不以更新文件代替新增实例。

| 校准项 | TU-3000完整与外壳 | 本包其他TerraUrsa派生型号 |
|---|---|---|
| 单位及向上轴 | 米，Y向上 | 米，Y向上 |
| 基点X Y Z | 0，0，0 | 0，0，0 |
| 正面X Y Z | 0，0，-1 | 0，0，1 |

海上模型Y=0为来源水线，水下基础可为负Y；不用包围盒最低点作基点。按各文件manifest核对，校准不确认现场身份或尺寸。

文件地形：在“地形”点“导入地形”，选`terrain/xiali-copernicus-dsm-3km.tif`。名称填“夏李测试范围 · Copernicus DSM”；来源填“Copernicus DEM GLO-30公开DSM，原生窗口裁切，非工程测量”；授权说明填“Copernicus DEM许可，依据见包内sources/terrain-source.json与许可PDF”。高程基准选EGM2008正高、单位米；确认使用依据，“上传并处理”完成后“用于当前场景”。

文件影像：在“影像”点“导入影像”，选`imagery/xiali-sentinel-20261013-20m-3km.tif`。名称填“夏李测试范围 · Sentinel-2 2026-10-13”；来源填“Copernicus Sentinel-2 L2A，2026-10-13，20米真彩色概览派生裁片”；许可依据填“Copernicus Sentinel数据声明，来源链接见包内sources/imagery-source.json”。日期填2026-10-13，署名填`Contains modified Copernicus Sentinel data (2026)`，质量填“20米概览，保留质量透明掩膜，非工程定位精度”；确认依据，“导入并校验”后“采用此版本”。

## 12 查阅型号属性与来源

在模型中心选资源和固定版本，展开“型号属性与证据”。额定功率、直径、高度等值可有来源声明、程序几何参数、教学模拟参数和推导值；展开“来源与依据”查看来源页面、定位信息及说明。

同一字段可有多条不同值，按用途和来源分别理解；“资料未给出”表示未知。当前风速、转速与输出不作为静态实测规格。型号资料不自动确认GLB为厂商工程模型，也不自动填入设备属性。

后续设备分类属性模板由OntoBase维护。型号资料、场景实例和设备安装身份分别保存，不能因型号相同就合并成同一台设备。

| 现象 | 先检查 |
|---|---|
| 预览后没有实例 | 返回场景，点“放置实例”，等提示后点地面 |
| 放置按钮不可用 | 布置模式、权限、版本是否已校准 |
| 找不到模型 | 项目、搜索词、用途筛选；兼容资源在“已有模型” |
| 想加一台却进入版本列表 | 退出选版，用“放置实例”或实例“复制” |

| 拖动或移除无效 | 先解锁位置；整批另查锁定或无效成员 |
| 加载较慢 | 复用入库版本，多实例优先外观，先少量验证流程 |

公开DSM、概览影像、教学模型和合成机位不能替代现场测量及设备身份核实。TerraUrsa海上示例平面与色板是合成背景，不是真实海图或水深；原色板本身静止，可按第15节另启视觉水纹。

## 14 配置环境并保存

打开场景并切到“布置”，右栏选“属性”，向下展开“环境渲染”。旧场景默认“原有显示”，读取时不会自动升级画面或新增修订。

1. “预设”选“陆地日间”“海上概览”或“黄昏”。“海上概览”仅在符合第15节条件的定位面上可选。
2. 展开需要调整的项目：色彩与曝光、光照与太阳、天空与雾、局部阴影、表面与影像、水面。修改后显示“预览中”，暂不写入共享场景。
3. 太阳方位表示朝向太阳，北0°、东90°；地理场景用真北，局部场景用局部北。太阳高度越低，阴影通常越长。曝光只改变视觉显示。
4. 核对后点“采用环境”，场景变为“未保存”；再点顶部“保存”，等待“已保存”。只点采用并未完成保存。
5. 不满意时点“取消预览”，恢复进入预览前的环境和播放状态，镜头、选择和模型位置保持。已采用后可先撤销，或预览“原有显示”再采用并保存。

局部阴影只覆盖观察点附近，平衡档最多8个投射实例且受三角面预算限制。全景远处没有阴影不表示实例缺失。全景被雾遮住时，拉远雾终点或关闭“距离雾”；海上概览默认关闭雾。

## 15 配置海上水面与播放

在已有的TerraUrsa海上教学场景中，合成定位平面仅用于相对布置，不是测深或现场海平面。确认采用了有效、平坦的相对定位面后，选择“海上概览”预设，或在“水面”勾选“显示水面”。

1. 本批支持平坦的UNKNOWN_RELATIVE定位面。起伏DSM、已知高程基准和局部平面不能直接铺水；“海上概览”不可选时先核对地形，不为开启效果更改工程基准。
2. “波纹行进方向 TO”表示波纹向哪里移动，北0°、东90°。“法线波纹强度”、波长、视觉速度、水色和粗糙度均为显示参数，不代表实测海况。
3. 水面开启时暂时遮蔽原影像，同一处只显示一个表面；原影像引用仍保留。关闭水面后恢复原影像及原来的显隐意图，无需重新上传或采用。
4. 画面下方“暂停水纹”或“播放水纹”只影响本人本次查看；共享默认值在面板“默认播放水纹”设置，采用后再保存。
5. 系统开启减少动画时默认静止，可手动播放。切到后台暂停绘制与计时，返回后继续；关闭或暂停水纹时保持按需绘制。

水纹仅改变表面法线，不移动顶点。模型仍落在原定位基准面，安装位置和高度不会随波纹变化。当前没有波高位移、平面镜面反射或浮体仿真。出现静态回退提示时，当前设备暂不播放动画或计算阴影，场景数据仍保留。

## 16 保持影像资料原色

陆地场景中，展开“环境渲染”→“表面与影像”，选择“资料原色”或“照明显示”。影像的覆盖、掩膜、日期、分辨率和来源标识沿用已采用版本。

1. “资料原色”保持影像原色显示，调整曝光或太阳时不会给资料图叠加光照。核对遥感资料时优先使用。
2. “照明显示”让同一影像表面接收视觉光照和局部阴影，适合空间观察。影像自身可能已有拍摄阴影，开启照明不能自动去除或校正它。
3. 对比两种显示，核对模型与地表关系，再点“采用环境”和顶部“保存”。取消预览会恢复原模式。
4. 地表粗糙度和草纹周期用于地表材质显示；覆盖了影像或水面的区域，草纹通常不可见。新环境中的色彩、太阳与天空设置优先于原“场景显示”的同类选项。

上述操作只改变场景外观，不提高影像或地形精度，不修改地形高程、模型固定版本或设备属性。需要外部PBR纹理集、更高质量反射或位移水面时，当前版本尚不提供导入入口。
