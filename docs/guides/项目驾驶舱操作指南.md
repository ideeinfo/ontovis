# 项目驾驶舱操作指南

2026-10-31更新：大屏分析工作台现为故障相关画布的只读可视化查看，操作见[当前分析查看与查询方法](#大屏分析查看与悬浮查询)。此前关于大屏内编辑、创建或加入分析笔记的流程由此更新覆盖。

2026-10-30。当前支持项目资产、场景总览、设备资料与分析导航，入口位于工作台标题栏右上角“驾驶舱”。

## 进入与返回

在项目内进入时沿用当前项目；从项目中心或模型中心进入时，先选择本人有权访问的项目。一个场景就是一个资产组合，设备数量按已解析的安装身份去重；未绑定、读取失败或身份不一致的模型表示单独提示，不计为已确认设备。

点击场景进入三维视图，从“浏览设备”分页选择设备，使用“定位所选模型”查看近景。“返回工作台”恢复原页面；从场景进入时保留固定版本、选择及镜头，从模型中心进入时保留原模型和镜头。查看偏好不改写场景。

## 模拟运行与轴向核验

首页地球会缓慢自动转动。可直接拖动或缩放，停止操作4.5秒后平缓恢复；地球底部“暂停地球自转”可停住，也可在显示设置暂停可视化。打开参考点或详情时会暂停，系统“减少动态”时不自动转动。

首页右侧“报警”（模拟）直接显示当前项目的模拟案例，列表底部上下按钮翻页。标记“回放 +60s”表示各案例固定回放第60秒，时间为模拟源时间，不是现场实时报警。点击某条先在场景中定位对应演练设备；通过事件条的“报警详情”查看该案例，再选择“进入分析画布”；会锁定对应案例及版本，复发案例独立保留。当前模拟源适用于Demo-PDS，未配置的项目显示空态。

驾驶舱加载场景后，所有现有已适配风机自动进入“均衡运行”，按模型和实例分配转速、叶轮相位及缓慢偏航；无需逐台配置。静态资产采用静态预设，未核验动作的内容不猜测旋转结构。主屏保留简短“模拟”标识。

打开“显示设置 → 演示”或底部模拟按钮，可选择“均衡运行 / 低速展示 / 停机展示”，也可“暂停全场”及“恢复预设”。偏好在当前驾驶舱会话的各场景间沿用；恢复预设同时清除单机微调。

- 设备页可展开“选中模型微调”，调整转速、相对零位的偏航偏移及运动轴线；这些均为演示值，不是设备实测或额定参数。
- 构件和报警定位继续模拟，镜头与定位框按当前显示姿态聚焦。透视及爆炸查看暂停所选模型；返回实体后自动继续。
- 隐藏页面、暂停或系统“减少动态”时不追赶错过的时间；样本失效会冻结动作。

天气预报与模拟源独立，不用天气风速推算转速。模拟只作用于查看副本，不保存工程姿态、不发送控制命令，也不构成工程轴向确认。当前规则见[全场模拟与夜景契约](../contracts/驾驶舱全场模拟与夜景显示契约.md)，取代原单机手动启动流程。

## 显示设置

驾驶舱右上角“显示设置”分为“显示、场景、演示”三类。显示页提供自动、100%、150%、200%，缩放仅保存于当前会话。

以浏览器实际可用空间为准；系统已放大显示时，“自动”不会再按显示器标称分辨率叠加倍率。当前Mac参考测试与4K容器的边界见[性能基线](../references/驾驶舱当前Mac性能基线.md)。

| 选项 | 行为 |
|---|---|
| 自动 | 可用 CSS 视口同时达到 3840×2160 时用 200%；达到 2880×1620 时用 150%；其余用 100% |
| 100% | 较紧凑的信息密度，1920×1080 基准布局 |
| 150% / 200% | 放大驾驶舱导航和信息面板，布局按剩余可用空间重排 |
| 恢复自动缩放 | 重新按当前可用视口选择比例 |
| 全屏显示 | 进入浏览器全屏；按 Escape 退出 |

这里依据浏览器实际可用视口，不按显示器标称物理像素推断。系统显示缩放、浏览器缩放、侧栏和工具栏都会改变可用空间。三维镜头、分析工作区倍率和照片原像素比例独立：照片“100%（1:1）”仍表示图片像素与显示比例，不会随驾驶舱缩放叠加。

显示页还可切换深浅主题、暂停可视化和进入全屏。暂停会冻结流云、水纹、天气粒子及模拟动作，镜头和页面操作仍可用。

场景页可选择跟随场景/预报、白天、黄昏或夜景补光，切换设备模型、地形、影像，以及按有效预报或手动晴、多云、雨、雪、雾。手动天气持续标记“天气演示”，真实预报卡保持原数据；关闭特效不删除天气数据。以上覆盖不保存到工程场景。

夜间预报保留深蓝夜空和稀疏星点，设备使用独立补光；地平线延伸层与夜色协调。星点仅为展示效果。演示页提供全场预设、暂停及恢复，单机微调按需展开。

## 查看设备与资料

设备页左侧按直接下级逐层浏览，使用返回上级和上下翻页按钮；右侧提供模型缩略图、“文档资料”“设备参数”“图纸”。面板空间不足时改为“结构 / 资料”切换。身份与精度放在右上角信息图标中按需查看。子设备没有经核验的独立几何时，空间视图保留所属设备并明确提示。共享定位照片与单台现场照片继续按原有归属显示。

“进入设备分析”会显式创建或续接本人分析。它不是只读预览按钮；不需要分析时直接查看设备资料即可。

## 模拟报警 → 分析 → 工单

当前“查看报警回放”（模拟）使用既有固定模拟来源。首页可选择演练设备并按已采纳柜体角色关联安装目标；这种关联仅用于场景演练。选中报警后，可“进入分析画布”或查看“相关工单”。真实项目报警尚未接入；天气已支持有来源的模式预报，现场观测仍待接入。

同一固定事件、来源版本、时间窗和对象范围匹配时，继续本人已有分析；同故障码的其他事件不会据此合并。原有分析助手、引用与工单流程继续使用既有操作。切页不会自动调用模型、创建工单或确认故障原因。

在驾驶舱内部切换空间、分析及工单时保留未保存草稿。“返回空间”恢复先前空间；退出驾驶舱或替换分析前，需要处理未保存修改。历史资料版本不可用时保留缺口，不能据此改写历史引用。

天气在项目工作台“数据与告警 → 天气接口”设置；选择场景参考点并启用后，场景左侧显示紧凑预报卡，点击卡片查看完整来源、时段和参考点。按有效预报调整的天气视觉效果可个人关闭，原场景配置保持。配置、时间与许可说明见[天气操作指南](天气接口操作指南.md)。

当前仍不含真实设备数据驱动的动作、变桨、现场观测天气、测绘级地球和工程拆解方案。完整设计与后续依赖见[详细设计](../design/项目驾驶舱详细设计.md)、[实施分期](../plans/驾驶舱功能补齐与实施分期.md)。


## 地球导航与模型查看

资产页地球显示当前项目的场景参考点。可旋转、缩放、恢复视角，点击参考点后选择场景；密集点数字表示场景数。搜索同时过滤列表与点位，没有地理锚点的场景仍从列表进入。底图是 NASA SVS 历史合成影像，云层/光照为示意，场景位置精度未核实。

进入场景会先准备目标资源，期间可取消或改选。资源失败保留资产页并显示重试；准备完成后飞入并交接到场景视角。返回项目资产可继续选择其他场景。

如果地球图形暂不可用，仍可从场景列表选择；场景自身资源失败会保留重试和取消入口。

设备三维视图底部提供“实体 / 透视 / 爆炸示意”。当前内部查看仅支持固定完整 TU-3000 教学合并版，其他模型会禁用并说明。透视显示源模型实际内部；爆炸只是分组位移示意，不是拆解步骤或测量依据。选择实体、换设备、换页或隐藏表示会复位。进入内部查看时所选模型恢复静态姿态，返回整机实体后自动继续模拟；所有操作只影响当前查看，不保存源模型或场景。


## 展示面板与详情

资产卡、场景设备和设备层级通过上下按钮分页。主屏只保留摘要和关键状态；完整名称、身份、精度、来源与时间在设备身份图标、场景详情或天气详情中查看。分析列表恢复紧凑行样式，底部上下按钮可翻动列表；返回空间会回到进入分析前的场景或设备。完整长资料仍允许必要滚动。

首页左侧统计显示橙色“报警”及数量，来源沿用右侧固定回放。驾驶舱不再常驻显示地球说明或影像英文署名长条。右上角“数据与来源”可查看NASA底图链接、参考位置说明，以及当前场景影像的名称、采集时间、署名与许可；“来源与质量说明”按需展开。工作台保留资源核验信息。

实现范围与验收见[展示层级契约](../contracts/驾驶舱展示层级与显示设置契约.md)。

## 场景近景与结构定位

首页左栏至少显示3个场景，设备结构至少5条（数据不足时显示实际数量）；用下方上下按钮翻页。首次进入场景使用该场景已保存的默认视角，工具栏“显示全部”可回到全场总览。需要调整默认镜头时，在工作台进入场景的“布置”模式，调整视角后点击“保存”；驾驶舱本次会话的往返仍保留浏览位置。

进入设备后，点击结构名称会聚焦并隔离相应模型部件。点击模型部件也会选中对应结构项并翻到所在页。“显示全部”恢复模型；有下级的结构项可通过右侧箭头进入，再从上方返回。无独立几何的项目会显示“所属设备”，仍可打开所选工程对象的资料。

设备底部模拟入口直接显示“运行中”“已暂停”或“停机”。整机与构件定位使用适中的俯视角，避开原地形；半透明装配保留正常遮挡关系。定位只调整本次查看，不修改场景已保存的默认视角。

如果 OntoBase 已更新设备采用，而共享构件绑定仍指向旧修订，在工作台“设备层级 → 构件绑定 → 接续采用修订”选择新采用。系统核对对象身份和修订，保留原模型/映射，保存为新采用的独立绑定；旧记录与历史场景保持。若对象不一致，需要先核对映射。

## 报警定位与半透明隔离

首页右侧可选择“演练设备”。报警卡显示对应柜体，点击后会进入该设备所在场景，选中柜体并隔离显示；上方事件条可打开报警详情。当前为明确标注的模拟回放，演练关联只在本会话生效。未匹配安装设备时不能定位，可切换演练设备或打开回放。

隔离时所选部件保持高亮，周边外壳与其他构件分别保留原不透明度的32%与50%，增强轮廓并保留装配位置关系。“显示全部”即时恢复材质且不重复移动镜头。点击另一结构项重新定位，模型反选继续沿固定构件绑定回到结构列表。

返回项目资产页恢复缓慢自然自转；暂停、拖动和减少动态仍有效。

### 告警与选中高亮

首页和场景的“报警”卡使用橙色警示图标、摘要与边线，严重事件保留红色区分；“模拟”小标识说明当前来源。场景摘要显示设备数和活动报警数，模型表示数在场景详情中查看。点卡片进入关联安装设备并隔离，报警详情继续打开固定案例回放。

设备结构当前项显示浅橙底、橙色名称/图标及左侧强调条，对应三维构件也使用橙色反馈；右侧“进入设备分析”为橙色入口。选中其他对象不会继承原报警的等级标识。

场景设备选择弹窗也会标出当前安装实例。进入分析工作台后，报警来源卡以橙色边框与标题突出，发生、恢复时间仍使用固定来源。

### 报警名称标签与全部风机取景

首页显示项目“风机总数”，不把柜体或测试样本算作风机。相同已绑定安装风机跨场景只计一次，未绑定部分按布置实例计，完整说明在“数据与来源”。

进入场景后，默认正好覆盖全部可见风机，左右面板保留观察空间。“显示全部”可随时重新取景，返回已浏览场景会恢复本次镜头。工作台仍会保存场景视角，主动设备或报警定位继续优先聚焦目标。

报警风机和部件上会显示高亮名称标签。多条事件合并为一个对象标签；点击仍能定位隔离同一设备。部件锚点依据当前有效绑定，无法定位的部件不会凭名称标在模型上。


## 大屏分析查看与悬浮查询

1. 从报警详情或已定位设备进入“分析工作台”，顶部确认当前故障。页面推荐本人可读的相关已有画布，并自动打开首个固定修订；可从“推荐分析画布”切换。没有故障时先选故障，没有相关画布时可去后台新建。
2. 图纸、照片、模型和正文在卡片中直接加载。用卡片右上角放大查看；资料较多时用“上一组/下一组”翻页。点击连线标签查看关系依据；“经对象”表示经过其他页工程对象的间接关联，可逐个查看链上对象或“展开并定位”到目标资料。候选/人工关系用虚线区分。按住资料卡标题栏或六点移动图标可拖动位置，连线和标签同步跟随；图标聚焦后也可用方向键微调。正文仍用于图片平移/模型旋转，右上角仍可放大。下方“恢复布局”回到默认排布。翻页、主题和界面缩放保留本次查看的位置；切换故障、画布、刷新或离开分析页时重置。调整仅用于大屏查看，后台原画布坐标和修订保持。历史参考、无权和版本变化状态保持原含义。
3. 右侧查看已保存的助手或人工分析记录，使用翻页或“查看完整记录”阅读。底部“向助手查询当前故障”打开可拖动的悬浮查询窗口；按当前项目策略选择资料、预览拟发送摘要并发送问题，可定位引用。窗口支持关闭及上下翻看，不提供修改画布、加入笔记或整理到工单操作。
4. “后台编辑”读取所选画布最新修订后进入原后台分析界面；“新建画布”进入后台空白草稿，保存前不创建记录。后台已有未保存修改时仍先处理离开确认。完成后可回到驾驶舱继续查看与空间定位。


## 设备参数、文档资料与图纸

“设备参数”默认显示型号属性，可切换到单台属性。型号页展示固定采用的型号修订、名称、属性值和单位；未知值保持“未知”。当前部件没有独立型号，但有可靠整机采用关系时，明确显示“所属整机型号”及整机名称，不能把这些数值当作部件自身规格。整机或有独立型号的设备显示“本设备型号”。单台页读取该设备自己的源端属性上下文，不提供编辑。长列表使用上下分页。

“文档资料”按当前设备型号和部件角色读取适用PDF与照片，点击“预览”后可缩放、平移、适应窗口或1:1查看；PDF沿用页码翻页。关闭预览回到原资料清单和分页，设备选择与镜头保持。

“图纸”默认查看“本对象及下级”：汇总本对象、固定共享定义和已登记下级对象的图纸，同一张图纸只显示一次。可切换“仅本对象”核对直接关联。点击“关联对象”查看命中的部件名称及关系类型；“共享定义下级（用户登记）”表示型号定义中已登记的成员，不能据此认定为这台设备已核实的独立安装对象。

图纸使用服务端上下翻页；点击“预览”打开受保护的整页图纸，支持缩放、平移、适应窗口和1:1。关闭后回到原清单和页码，设备选择与空间镜头保持。下级关系、图纸或文件变化时先刷新清单，不自动替换成另一份来源。没有关联时如实显示空态，不按名称/位号猜测，也不拿父级或其他安装的图纸填充。此前柜体空清单仅是直接关联范围的结果，不能据此判断下级对象没有图纸。
