# 项目驾驶舱操作指南

2026-10-30。当前支持项目资产、场景总览、设备资料与分析导航，入口位于工作台标题栏右上角“驾驶舱”。

## 进入与返回

在项目内进入时沿用当前项目；从项目中心或模型中心进入时，先选择本人有权访问的项目。一个场景就是一个资产组合，设备数量按已解析的安装身份去重；未绑定、读取失败或身份不一致的模型表示单独提示，不计为已确认设备。

点击场景进入三维视图，从“浏览设备”分页选择设备，使用“定位所选模型”查看近景。“返回工作台”恢复原页面；从场景进入时保留固定版本、选择及镜头，从模型中心进入时保留原模型和镜头。查看偏好不改写场景。

## 模拟运行与轴向核验

首页地球会缓慢自动转动。可直接拖动或缩放，停止操作4.5秒后平缓恢复；地球底部“暂停地球自转”可停住，也可在显示设置暂停可视化。打开参考点或详情时会暂停，系统“减少动态”时不自动转动。

首页右侧“模拟报警”直接显示当前项目的模拟案例，列表底部上下按钮翻页。标记“回放 +60s”表示各案例固定回放第60秒，时间为模拟源时间，不是现场实时报警。点击某条先在场景中定位对应演练设备；通过事件条的“报警详情”查看该案例，再选择“进入分析画布”；会锁定对应案例及版本，复发案例独立保留。当前模拟源适用于Demo-PDS，未配置的项目显示空态。

在驾驶舱中打开夏李场景，选择一台 TU-3000 风机，点击底部“运行演示”，或打开“显示设置 → 演示”，再点击“开始模拟”。默认不会自动播放，主屏保留模拟标记；关闭设置后继续演示。当前支持已核验固定内容的 TU-3000 合并版及外观版，其他模型保持静态。

- “模拟转速”设为 0 rpm 时叶轮停转；4、8、12、20 rpm 为演示值，不是设备额定参数。
- “偏航偏移”相对模型零位，90° 时机舱和叶轮共同转动，塔筒保持不动；359°→1° 走最短路径。它不是真北航向。
- 展开“轴向核验与异常演练”，可显示青色 +Y 偏航轴、金色 +Z 叶轮轴，并切换正常、质量异常、过期和断连。后三者冻结姿态，恢复后不补转。
- “暂停”冻结当前姿态，“继续演示”恢复；“复位”恢复原模型结构和姿态。换机、换页、隐藏模型、浏览器隐藏或退出驾驶舱会结束演示。

动作只作用于当前一个模型表示。进入子部件资料仍显示整机模拟作用范围；CN1 示意机舱柜随偏航，CT 塔基柜保持固定。天气预报与本机模拟源互相独立，不用天气风速推算转速。演示不保存工程姿态、不发送设备控制命令，也不构成工程轴向确认。完整约定见[模拟遥测与动作契约](../contracts/模拟遥测与风机动作首切契约.md)。

## 显示设置

驾驶舱右上角“显示设置”分为“显示、场景、演示”三类。显示页提供自动、100%、150%、200%，缩放仅保存于当前会话。

以浏览器实际可用空间为准；系统已放大显示时，“自动”不会再按显示器标称分辨率叠加倍率。当前Mac参考测试与4K容器的边界见[性能基线](../references/驾驶舱当前Mac性能基线.md)。

| 选项 | 行为 |
|---|---|
| 自动 | 可用 CSS 视口同时达到 3840×2160 时用 200%；达到 2880×1620 时用 150%；其余用 100% |
| 100% | 较紧凑的信息密度，1920×1080 基准布局 |
| 150% / 200% | 放大驾驶舱导航和信息面板，布局按剩余可用空间重排 |
| 恢复自动缩放 | 重新按当前可用视口选择比例 |
| 全屏显示 | 进入浏览器全屏；按 Escape 退出 |

这里依据浏览器实际可用视口，不按显示器标称物理像素推断。系统显示缩放、浏览器缩放、侧栏和工具栏都会改变可用空间。三维镜头、分析工作区倍率和照片原像素比例独立：照片“100%（1:1）”仍表示图片像素与显示比例，不会随驾驶舱缩放叠加。

显示页还可切换深浅主题、暂停可视化和进入全屏。暂停会冻结流云、水纹、天气粒子及模拟动作，镜头和页面操作仍可用。

场景页可选择跟随场景/预报、白天或黄昏光照，切换设备模型、地形、影像，以及按有效预报或手动晴、多云、雨、雪、雾。手动天气持续标记“天气演示”，真实预报卡保持原数据；关闭特效不删除天气数据。以上覆盖不保存到工程场景。

演示页集中提供模拟转速、偏航偏移、开始/暂停/复位，以及按需展开的轴向和异常核验。与透视/爆炸查看互斥。

## 查看设备与资料

设备页左侧按直接下级逐层浏览，使用返回上级和上下翻页按钮；右侧提供模型缩略图、图纸与资料、设备参数和对象详情。面板空间不足时改为“结构 / 资料”切换。参数按当前单台设备的源端上下文读取，资料按型号与部件角色解析。子设备没有经核验的独立几何时，空间视图保留所属设备并明确提示。共享定位照片与单台现场照片继续按原有归属显示。

“进入设备分析”会显式创建或续接本人分析。它不是只读预览按钮；不需要分析时直接查看设备资料即可。

## 模拟报警 → 分析 → 工单

当前“查看报警回放”（模拟）使用既有固定模拟来源。首页可选择演练设备并按已采纳柜体角色关联安装目标；这种关联仅用于场景演练。选中报警后，可“进入分析画布”或查看“相关工单”。真实项目报警尚未接入；天气已支持有来源的模式预报，现场观测仍待接入。

同一固定事件、来源版本、时间窗和对象范围匹配时，继续本人已有分析；同故障码的其他事件不会据此合并。原有分析助手、引用与工单流程继续使用既有操作。切页不会自动调用模型、创建工单或确认故障原因。

在驾驶舱内部切换空间、分析及工单时保留未保存草稿。“返回空间”恢复先前空间；退出驾驶舱或替换分析前，需要处理未保存修改。历史资料版本不可用时保留缺口，不能据此改写历史引用。

天气在项目工作台“数据与告警 → 天气接口”设置；选择场景参考点并启用后，场景左侧显示紧凑预报卡，点击卡片查看完整来源、时段和参考点。按有效预报调整的天气视觉效果可个人关闭，原场景配置保持。配置、时间与许可说明见[天气操作指南](天气接口操作指南.md)。

当前仍不含真实设备数据驱动的动作、变桨、现场观测天气、测绘级地球和工程拆解方案。完整设计与后续依赖见[详细设计](../design/项目驾驶舱详细设计.md)、[实施分期](../plans/驾驶舱功能补齐与实施分期.md)。


## 地球导航与模型查看

资产页地球显示当前项目的场景参考点。可旋转、缩放、恢复视角，点击参考点后选择场景；密集点数字表示场景数。搜索同时过滤列表与点位，没有地理锚点的场景仍从列表进入。底图是 NASA SVS 历史合成影像，云层/光照为示意，场景位置精度未核实。

进入场景会先准备目标资源，期间可取消或改选。资源失败保留资产页并显示重试；准备完成后飞入并交接到场景视角。返回项目资产可继续选择其他场景。

如果地球图形暂不可用，仍可从场景列表选择；场景自身资源失败会保留重试和取消入口。

设备三维视图底部提供“实体 / 透视 / 爆炸示意”。当前内部查看仅支持固定完整 TU-3000 教学合并版，其他模型会禁用并说明。透视显示源模型实际内部；爆炸只是分组位移示意，不是拆解步骤或测量依据。选择实体、换设备、换页或隐藏表示会复位。进入内部查看会结束模拟运行，返回实体后需要主动重新开始模拟；所有操作只影响当前查看，不保存源模型或场景。


## 展示面板与详情

资产卡、场景设备和设备层级通过上下按钮分页。主屏只保留摘要和关键状态；完整名称、身份、精度、来源与时间在对象详情、场景详情或天气详情中查看。分析列表恢复紧凑行样式，底部上下按钮可翻动列表；返回空间会回到进入分析前的场景或设备。完整长资料仍允许必要滚动。

实现范围与验收见[展示层级契约](../contracts/驾驶舱展示层级与显示设置契约.md)。

## 场景近景与结构定位

首页左栏至少显示3个场景，设备结构至少5条（数据不足时显示实际数量）；用下方上下按钮翻页。首次进入场景会靠近中心附近的设备，工具栏“显示全部”可回到全场总览。

进入设备后，点击结构名称会聚焦并隔离相应模型部件。点击模型部件也会选中对应结构项并翻到所在页。“显示全部”恢复模型；有下级的结构项可通过右侧箭头进入，再从上方返回。无独立几何的项目会显示“所属设备”，仍可打开所选工程对象的资料。

如果 OntoBase 已更新设备采用，而共享构件绑定仍指向旧修订，在工作台“设备层级 → 构件绑定 → 接续采用修订”选择新采用。系统核对对象身份和修订，保留原模型/映射，保存为新采用的独立绑定；旧记录与历史场景保持。若对象不一致，需要先核对映射。

## 报警定位与半透明隔离

首页右侧可选择“演练设备”。报警卡显示对应柜体，点击后会进入该设备所在场景，选中柜体并隔离显示；上方事件条可打开报警详情。当前为明确标注的模拟回放，演练关联只在本会话生效。未匹配安装设备时不能定位，可切换演练设备或打开回放。

隔离时所选部件保持高亮，其余部件半透明，保留装配位置关系。“显示全部”即时恢复材质且不重复移动镜头。点击另一结构项重新定位，模型反选继续沿固定构件绑定回到结构列表。

返回项目资产页恢复缓慢自然自转；暂停、拖动和减少动态仍有效。
