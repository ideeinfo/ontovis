# 项目驾驶舱操作指南

2026-10-30。当前支持项目资产、场景总览、设备资料与分析导航，入口位于工作台标题栏右上角“驾驶舱”。

## 进入与返回

在项目内进入时沿用当前项目；从项目中心或模型中心进入时，先选择本人有权访问的项目。一个场景就是一个资产组合，设备数量按已解析的安装身份去重；未绑定、读取失败或身份不一致的模型表示单独提示，不计为已确认设备。

点击场景进入真实三维视图，从模型列表选择设备，使用“定位所选模型”查看近景。“返回工作台”恢复原页面；从场景进入时保留固定版本、选择及镜头，从模型中心进入时保留原模型和镜头。查看偏好不改写场景。

## 显示设置 → 界面缩放

驾驶舱右上角“显示设置”提供自动、100%、150%、200%，只保存于当前会话。

| 选项 | 行为 |
|---|---|
| 自动 | 可用 CSS 视口同时达到 3840×2160 时用 200%；达到 2880×1620 时用 150%；其余用 100% |
| 100% | 较紧凑的信息密度，1920×1080 基准布局 |
| 150% / 200% | 放大驾驶舱导航和信息面板，布局按剩余可用空间重排 |
| 恢复自动缩放 | 重新按当前可用视口选择比例 |
| 全屏显示 | 进入浏览器全屏；按 Escape 退出 |

这里依据浏览器实际可用视口，不按显示器标称物理像素推断。系统显示缩放、浏览器缩放、侧栏和工具栏都会改变可用空间。三维镜头、分析工作区倍率和照片原像素比例独立：照片“100%（1:1）”仍表示图片像素与显示比例，不会随驾驶舱缩放叠加。

主题切换与界面缩放独立；浅色、深色不会改变工程身份或数据状态。

## 查看设备与资料

设备面板提供信息、参数和资料。参数按当前单台设备的源端上下文读取，资料按型号与部件角色解析。子设备没有经核验的独立几何时，空间视图保留所属设备并明确提示。共享定位照片与单台现场照片继续按原有归属显示。

“进入设备分析”会显式创建或续接本人分析。它不是只读预览按钮；不需要分析时直接查看设备资料即可。

## 模拟报警 → 分析 → 工单

当前“查看明确模拟的报警回放”使用既有固定模拟来源，与所选场景设备不自动关联。选中报警后，可“进入分析画布”或查看“相关工单”。真实项目报警尚未接入；天气已支持有来源的模式预报，现场观测仍待接入。

同一固定事件、来源版本、时间窗和对象范围匹配时，继续本人已有分析；同故障码的其他事件不会据此合并。原有分析助手、引用与工单流程继续使用既有操作。切页不会自动调用模型、创建工单或确认故障原因。

在驾驶舱内部切换空间、分析及工单时保留未保存草稿。“返回空间”恢复先前空间；退出驾驶舱或替换分析前，需要处理未保存修改。历史资料版本不可用时保留缺口，不能据此改写历史引用。

天气在项目工作台“数据与告警 → 天气接口”设置；选择场景参考点并启用后，驾驶舱右侧显示预报与来源。按有效预报调整的天气视觉效果可个人关闭，原场景配置保持。配置、时间与许可说明见[天气操作指南](天气接口操作指南.md)。

当前首切尚不含真实数据驱动的偏航、转子、变桨、观测天气、高精度地球及正式透视/爆炸。完整设计与后续依赖见[详细设计](../design/项目驾驶舱详细设计.md)、[实施分期](../plans/驾驶舱功能补齐与实施分期.md)。
