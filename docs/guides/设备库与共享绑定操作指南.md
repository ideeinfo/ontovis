# 设备库与共享绑定操作指南

适用2026-10-29测试发布。登录 [ONTOVis](https://vis.ontobase.ai/) 后，在“项目中心”选择项目并“进入项目”，再打开“设备层级”。型号、分类、属性模板、项目采用和设备台账在 OntoBase 管理；ONTOVis 维护模型几何与项目构件绑定。

## 查看项目设备

默认打开“项目设备”，左侧可搜索、展开整机并选择内部设备；“隐藏设备树 / 显示设备树”可独立收起或召回列表。右侧为概览、共享工程资料、现场照片、构件定位四个页签。

Demo-PDS有15台整机，1及4—14号12台已布置，15、16、18号留待用户测试。每台13个关键子设备，共210条活动设备记录；这不是210台风机。原7号额外接口子对象已停用，保留历史引用。共享工程目录1145个定义不随15台重复复制。

CN1是机舱动力柜，CN2是机舱信号柜，CT是塔基信号柜。型号参数读取本台采用的固定源端规格，新修订不会悄悄覆盖已采用内容；制造商等未登记信息保持未知。

## 在 OntoBase 管理型号和设备

点击“在 OntoBase 中管理”，在新标签页进入[源端设备库](https://demo.ontobase.ai/#/equipment)，选择 Demo-PDS。当前源端保留自己的项目选择，不会自动选择本台设备；原ONTOVis页面保留。

源端“设备”模块内包含“设备库”“型号库”“分类与属性”。基础型号、分类及参数模板、规格修订、项目采用、单台属性与现场照片在这里维护。ONTOVis概览及规格详情为只读，不能在构件绑定中修改这些权威字段。

当前TU-3000为教学规格，采用齿轮传动教学变体；9项已知参数保留TerraUrsa来源，制造商和未确认参数不补猜测值。它不代表现场厂家型号确认。

## 一次配置，同项目同型号共用

进入“构件绑定”，选择已有共享绑定。新建时先“选择项目采用”，读取OntoBase已经建立的固定规格与角色映射；尚无项目采用时先到源端建立。

1. 左侧选择共享工程对象，中间查看固定模型，右侧选择构件并保存映射。
2. 一个对象可对应多个构件；多个对象共用柜体或总成时，通过工程归属定位，不抢占同一直接构件键。
3. 点击“保存构件绑定”生成新修订。写入由后端检查本人权限、项目、原修订及对象/模型来源。
4. 单台设备采用哪个规格/项目应用在OntoBase配置。同一项目、同一固定应用共用一份映射，跨项目分别保存。

Demo-PDS原配置已经接续到项目应用01f713de-c170-48f7-9e54-264fa22f891f，新绑定修订73902177；原13项映射、12项直接几何和历史修订保留。模型中心继续管理文件、版本、几何、构件树及校准。

## 两种照片分别使用

| 页签 | 查询依据 | 用途 |
| --- | --- | --- |
| 共享工程资料 → 定位照片 | 项目/型号适用关系、柜内共享工程对象、固定照片版本 | 同项目同型号共享柜内照片与原对象标注 |
| 现场照片 | 当前单台设备或子设备身份 | 本台检修、缺陷或现场状态记录，不自动借用其他设备或共享照片 |

CN2定位照片汇总正面90、右侧15、左侧6个原对象区域。点击照片后通过“原对象区域”选择具体器件；正面超过50个区域时可“更多区域”。区域仍属于原工程对象，柜级入口不复制或改写它们。

照片先显示快速预览，支持滚轮缩放、按住鼠标左键平移和定位标注；“原尺寸”按需读取完整图片。同一面板重复打开固定照片可复用已加载内容。

现场照片通过OntoBase设备库明确关联到具体设备，本批4号和7号CN2各为空。ONTOVis已关闭原现场照片写入口；不会把柜内定位照片当成本机实拍。

## 布置预留设备

打开“场景与可视化 → 夏李 · 公开影像概览（非工程定位）”，切换“布置”。在“项目对象 → 设备树”搜索15、16或18号，将设备拖到有效地形上。系统使用该设备采用的型号配置和固定模型，并关联原设备UID；拖入只新增场景表示。

调整位置后保存。既有演示落点见[预留编号与坐标](从零完成场景布置.md#32-夏李12台已布置与3台预留测试)，这些是图示配准估计，非现场测量。也可先放置模型，再选择同项目、配置支持该固定版本的设备。

场景“查看共享构件配置”提供查看与跳转，内部映射在设备层级修改。同一设备已在场景中表示时，拖入会选择已有表示。全选同型号后“加载所选”可同时查看，不必逐台加载；查看操作不保存新场景修订。

## 精度和历史

CN1与CT保持示意代理，CN2采用既有控制器分组。没有独立几何的对象保留所属柜体或总成定位；叶轮/转子暂没有独立整组构件键，不推定精确位置。

场景及画布固定引用仍可读取原绑定修订。新画布模型保存映射修订和设备采用范围，后续修改配置不会改写旧画布。既有工程变更或证据缺口继续显示，未启用自动确认分析结论。

瞬时网络故障不再清空当前工作区；提示出现时可重试会话检查。真正退出、权限拒绝或会话变更仍会清理旧账号内容。

完整设备更换、资产履历及真实现场接入不在本批范围。服务边界见[实施契约](../plans/设备库与共享绑定服务契约.md)，本批验收见[记录§128](../plans/开发执行记录.md#128-设备库接续联合验收与会话恢复2026-10-29)。
