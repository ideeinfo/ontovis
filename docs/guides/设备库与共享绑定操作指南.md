# 设备库与共享绑定操作指南

适用2026-10-28测试发布。登录 [ONTOVis](https://vis.ontobase.ai/) 后，在“项目中心”选择项目并“进入项目”，再打开“设备层级”。设备数据来自 OntoBase 设备库；工程定义、分类、图纸和柜内定位照片来自 OntoBase 工程对象库。

## 一次配置，同型号共用

进入“型号配置”，选择项目内的配置及固定模型版本。Demo-PDS现有“TU-3000 · 项目共享配置”，由15台演示风机共同采用。

1. 左侧选择共享工程对象，中间查看模型，右侧选择对应构件。可以展开“模型构件树与属性”交叉定位。
2. 需要其他工程对象时，点击左栏“＋”，按名称或位号搜索。选择对象只打开资料；点击“更新构件映射”才修改当前配置。
3. 一个对象可关联多个构件；一个构件不能同时直接映射到不同对象。“解除”只移除映射，不删除模型、工程对象或设备。
4. 点击“保存并应用”。采用此配置的设备共同使用新的当前映射，无需逐台重做。切换前先保存或放弃未保存修改。
5. “应用到设备”用于为同项目、同类型设备指定这份配置；新建配置可用于其他型号或结构变体，不凭同名自动应用。

模型中心管理文件、版本、几何、构件树及校准；项目工程映射在设备层级维护。跨项目可复用同一模型文件，工程对象和映射分别保存。

## 查看具体设备

切到“项目设备”。Demo-PDS按15台整机列出，当前12台已布置，15、16、18号未布置。选择一台后展开其13个关键子设备；选择其他整机时切换到该台身份。

CN1为机舱动力柜，CN2为机舱信号柜，CT为塔基信号柜。选择柜体后，柜内工程对象沿原共享成员关系分页读取，不为15台重复创建全部工程定义。旧7号额外接口子对象已停用，保留历史引用。

设备库共210个有效设备对象，包含15个整机与195个关键子设备；这不是210台风机。共享工程目录为1145个定义，其中1144个原有来源保持，另增加1个明确的TU-3000整机工程定义。

## 布置预留设备

打开“场景与可视化 → 夏李 · 公开影像概览（非工程定位）”，切换到“布置”。在左栏“项目对象 → 设备树”搜索15、16或18号，将设备拖到有效地形上。系统采用该设备的型号配置和固定模型版本，并关联设备库身份；拖入不新建设备台账或工程对象。

调整位置后保存场景。需要精确复用既有演示落点时，参见[预留编号与坐标](从零完成场景布置.md#32-夏李12台已布置与3台预留测试)。这些坐标为图示配准估计，非现场测量。

也可以先从模型资源放置模型，再“选择设备”关联同项目、配置支持该固定版本的设备。场景右栏“查看共享构件配置”用于查看与跳转；修改内部映射回到设备层级完成。同一设备已在本场景表示时，拖入会选择已有表示，避免误建重复实例。

当前保留1、4—14号12台的原实例、模型固定版本、位置、朝向、地形、影像与视点。正式测试站尚未替用户布置15、16、18号；开发验收的额外拖入在隔离副本完成。

## 两种照片分别使用

| 页签 | 查询依据 | 用途 |
| --- | --- | --- |
| 对象定位照片 | 当前共享工程对象及固定照片版本 | 同项目同型号共享柜内照片和标注区域；例如1B4的位置 |
| 现场照片 | 当前具体设备或子设备身份 | 本台检修、缺陷或现场状态记录；不自动共享给其他设备 |

照片先显示快速预览，支持滚轮缩放、按住鼠标左键平移及定位标注；“原尺寸”按需读取完整图片。同一面板重复打开固定照片可复用已加载内容，设备现场照片清单按当前设备独立查询。

添加现场照片：先选具体设备，切到“现场照片”，点击“关联已有项目照片”，从本项目已有照片中选择，并“保存关联”。关联归属当前设备，不依据文件名猜测拍摄设备；同一文件可有不同明确用途，底层无需复制文件。本批没有可确认的本机现场照片，因此保留空状态，没有把柜内定位照片冒充为本机实拍。

## 定位精度与历史

CN1与CT在当前TU-3000中使用示意代理；CN2采用已登记的控制器分组。没有独立几何的柜内对象按已有工程归属定位到柜体。叶轮/转子暂未登记有效的独立整体构件键，保留工程对象并使用整机范围；不将示意范围称作精确实物位置。

当前场景采用配置当前修订；保存场景会保留当时使用的配置修订。新分析中引用的模型同时记录映射修订及设备采用范围，后续修改配置不重写已保存分析。旧画布继续读取原固定来源，不自动追加新绑定事实。

完整设备更换、序列号和资产履历维护不属于本批交付。源系统设备库领域及接口已独立，本批可操作入口在ONTOVis“项目设备”，没有另行发布OntoBase Web资产维护工作台。服务边界见[实施契约](../plans/设备库与共享绑定服务契约.md)，验收见[执行记录§124](../plans/开发执行记录.md#124-设备库与共享绑定配置实施2026-10-28)。
